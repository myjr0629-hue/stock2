## 2. 계열별 복제 규격

### A. 두 대상 + 시간 누적  ← **구현 완료** (`src/remotion/kit/Race.tsx`)

```
상단 고정 띠   제목 2줄 (흰 줄 + 앰버 줄). 첫 프레임부터 끝까지 1픽셀도 안 바뀐다
중앙          두 기둥이 나란히. 로그축 (선형은 격차가 크면 선두가 천장에 붙어 멈춰 보인다)
좌·우 가장자리 연도별 금액이 한 줄씩 쌓인다  ← Jeremy 의 «움직임의 본체» 가 이것이었다
하단          연도 하나 + 시작 조건 한 줄
컷            0
소리          해 넘어갈 때마다 틱 (합성 · 권리 문제 없음)
```

**검증 완료 3편**: NVDA/INTC 55.9배 · AMD/INTC 25.5배 · NVDA/AAPL 12.0배

### B. 남의 실사 클립 + 상단 프레이밍  ← **미구현**

```
상단          검은 띠 + 제목 1~2줄, «핵심어만» 색 (Wealthrive 는 노랑)
아래          남의 실사 클립 통째로
자막          원본 대사 2~3단어씩 (Life in Focus) 또는 없음 (Wealthrive)
컷            1~5 (원본 클립의 컷)
```

⛔ **막힌 것**: 쓸 수 있는 실사 클립 조달 경로가 아직 없다.
   기존 음원 6개가 전부 깨져 있던 것처럼, 이쪽도 «있다고 가정»하면 안 된다.
   → 다음 과제: 권리 안전한 실사 소스를 «실제로 받아서» 목록화한다.

### C. 선택 질문 정지화면  ← **미구현**

```
상단          흰 띠 + 질문 한 줄
중앙          선택지 2개 (초록/빨강 문) + 각각 조건 2~3줄 + 가운데 캐릭터
컷            0 · 거의 정지 · 5~7초
목적          댓글 유발 (우리 댓글율이 사실상 0이다)
```

⛔ 우리 `ax-` 캐릭터 클립 40개가 여기 쓰인다. 촬영 불필요.

### D. 랭킹 상하분할  ← **미구현 · 앵커 문제**

측정상 배수 1위(1.38배 · z=5.14)지만, 실제 구현은 **말하는 얼굴이 하단에 계속** 있다.
우리에겐 얼굴이 없다. → A 계열의 «기둥» 을 얼굴 자리에 넣는 변형을 시험해야 한다. **미검증.**

## 3. 브랜딩 — 이 뼈대 안에서 어디에 넣는가

⛔ 대표 질문: *"이런것 올려야만 조회수가 나온다면 이렇게 올리면서도 브랜딩이 가능하게 하려면"*

### 레퍼런스가 실제로 하는 것 (실측)

| 채널 | 브랜드 표시 | 크기 |
|---|---|---|
| Life in Focus | `YOUTUBE | @LIFEINFOCUS-1` 손글씨체, 제목 바로 아래 | 아주 작고 흐림 |
| TheWealthrive | 반투명 「W」 모노그램, 클립 하단 중앙 | 거의 안 보임 |
| Jeremy · Rolex · Value Signals · Asset vs Time · Finvesto | **없음** | — |

**8편 중 6편은 브랜드 표시가 아예 없다.**

### 그럼 이 채널들의 브랜딩은 무엇인가

**템플릿 자체다.** Life in Focus 는 매 편 「흰 대문자 줄 + 노란 대문자 줄 + 이모지」다.
Wealthrive 는 매 편 「흰 글자에 핵심어만 노랑」이다. 스크롤하다 보면 **글자만 보고 안다.**

> ⛔ 결론: **로고를 키우는 것은 브랜딩이 아니라 콘텐츠 자리를 뺏는 것이다.**
>   브랜딩은 «매 편 똑같은 상단 띠» 로 한다. 그게 우리 서명이다.

### 우리 브랜딩 3단 (실측 근거 있는 것만)

| 층 | 내용 | 근거 |
|---|---|---|
| **① 템플릿 서명** | 상단 띠 = 흰 줄 + 앰버(#FFB020) 줄, Montserrat 900, 매 편 동일 | 레퍼런스 8/8 이 상단 고정. 브랜딩은 여기서 난다 |
| **② 핸들 각인** | 제목 아래 `@SIGNUMHQ` 작고 흐리게 | Life in Focus 선례 (유일하게 검증된 표시 방식) |
| **③ 앱 유도** | 설명 첫 줄 + 고정 댓글 | 화면을 안 건드린다 |

⛔ **하지 말 것**: 큰 로고 · 하단 티커바 · 섹션 헤더 · 워터마크 배지.
   전부 우리가 하던 것이고, 그 영상들이 42회였다.
