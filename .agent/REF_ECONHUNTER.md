## 5. 차용할 것 / 우리가 더 할 것

### 차용 (흐름은 이들이 옳다)

1. **훅에서 답을 감춘다** — 이상값만 던지고 중반에 공개
2. **개수를 먼저 말한다** — 「이유는 두 개야」
3. **사실 뒤 해석 한 문장** — 「마트 돈은 줄고 공장 돈은 늘었다」 같은 «번역»
4. **중반 재훅** — 「근데 여기서 이상한 게 하나 있어」를 명시적으로 신호
5. **오늘 볼 것 N가지** — 가져갈 것을 번호로
6. **출처 스크린샷 + 빨간 박스** — 우리는 앱 화면만 썼다. 외부 기사·차트에 박스 치는 방식을 안 썼다

8. **다음 예고로 닫는다** — 다음 편을 볼 이유를 만든다
