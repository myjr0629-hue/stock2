## 1. 왜 이관했나

2026-08-28, massive.com 계정이 약관 위반으로 시세 권한을 잃었다(snapshot 403).
같은 키로 aggregates 는 200 이 나와서 **코드 문제로 오진하기 쉬웠다** —
「403 이 $0.00 으로 위장돼 보인다」가 이 사건의 지문이다.

대안 검토 결과 **Intrinio Startup $333/월** 채택:

| 후보 | 결과 |
|---|---|
| Databento | 탈락 — 파생지표까지 「재배포」로 봄 · $2,550/월 |
| **Intrinio Startup** | **채택** — Display+Commercial 명시, 맥스페인 실측이 Databento 와 완전일치, 비용 1/8 |

> 벤더 선택 기준 두 개: ① 파생지표를 재배포로 보는가 ② Display 가 어느 티어인가.

부수 효과로 **약관 걱정 없이 상업적으로 쓸 수 있게 됐다** — 대표가 가장 크게
평가한 부분이고, 앱 사업화의 전제가 해소됐다.

### ★ 8-K — 「완전 대체 불가」였는데 원본으로 완전히 되살렸다

Polygon 의 `supporting_text` 정체는 결국 **SEC 8-K 문서 그 자체**였다.
FMP 의 보도자료·실적콜 녹취록은 402(플랜 밖)지만, SEC 원본은 공개다.

| | 실측 |
|---|---|
| SEC submissions API | 키 불필요 · **0.097초** · `items: "2.02,9.01"` |
| SEC 원문 문서 | **0.089초** · 26KB · "Item 2.02 … issued a press release announcing its results …" |

- Item 코드 21종 → 소비처 분류 체계로 매핑. 대표 분류는 **고영향 항목 우선**
  (한 공시에 여러 Item: `1.01+2.03+7.01` 이면 중요계약이 핵심).
- 본문은 원문에서 직접 추출(태그 제거 → `Item X.XX` 이후 1,200자).
- 고영향 정규식 확장: restatement(4.02) · auditor_change(4.01) ·
  control_change(5.01) · acceleration(2.04) · material_agreement(1.01)
  — 예전엔 전부 「보통」으로 떨어졌다.

콜드 검증(MPWR): `governance/shareholder_vote` → **"6월 11일 정기주주총회에서
클래스 I 이사 2명 선출"** — 원문을 읽지 않으면 나올 수 없는 구체성.
**벤더보다 정확하다**(원본이므로).

### 신규 지표 — 의회 거래 공시 (다크풀·공매도잔고 상실의 대체)

`src/services/congressTrades.ts` · `/api/flow/congress`

성격이 기존 축과 다르다: 내부자=회사 임원(내부 정보) · 13F=분기 보유(느림) ·
**의회=정책 결정권자(정책·규제 정보 우위)**. STOCK Act 로 45일 내 공시 의무.

정직성 설계 — 이번 이관에서 배운 것을 그대로 적용:
- 금액은 **구간** 공시다("$100,001 - $250,000") → 중간값을 쓰되 `amountIsEstimate`
  로 밝힌다. 구간을 단일 숫자처럼 보이면 없는 정밀도를 주장하는 것이다.
- 파싱 실패는 **null**, 0 이 아니다.
- ★ **«건수»가 아니라 «사람 수»를 같이 센다.** 실측이 바로 증명했다:
  GS 17건이지만 **의원 1명**, TKNO 32건도 **1명**. 건수만 보면 한 사람의 행동이
  집단 신호로 둔갑한다. INTC 는 3건인데 **2명**이라 오히려 의미가 크다.
- 매매일→공시일 지연(`lagDays`)을 노출 — 신호의 신선도가 그 자체로 정보다.

지금은 데이터 계층 + API 까지. 화면 배치는 별도 결정.

### 애널리스트 «변화 이벤트» — 이미 쓰던 데이터의 빈 절반

★ **컨센서스·목표가는 원래 쓰고 있었다**(`/api/live/analyst` → Command).
   프로덕션: NVDA BUY · 79명 · 76% 강세 · $345.21. 「안 쓰던 데이터」가 아니다.
   빠져 있던 건 **변화 이벤트** — 스냅샷은 정지 화면이라 「방금 무슨 일이
   있었나」가 없었다. 컨센서스는 천천히 움직이므로 움직임 자체가 정보다.

| FMP 엔드포인트 | 실측 |
|---|---|
| `grades?symbol=` | NVDA 1138건 {maintain 1023 · upgrade 71 · downgrade 44} · 실명 기관 · prev→new |
| `price-target-summary` | NVDA 1M 343.95(21명) · 분기 343.32 · 1Y 298.28(97명) |

- ⚠️ 대부분이 `maintain` 이다 → **상하향만** 이벤트로 센다. 아니면 매일 무슨
  일이 일어나는 것처럼 보인다.
- 목표가 리비전 = 1M 평균 vs 1Y 평균. ±3%p 안쪽은 잡음(종목별 분산이 크다).
  1Y 평균이 없으면 방향을 **말하지 않는다**(null).
- ★ 이벤트를 라우트의 `swrFetch` **밖**에 붙였다 — 안에 넣으면 DynamoDB 히트
  경로에선 영영 안 나온다(이번 이관에서 반복해 만난 유형).

프로덕션 실측 · 실화면 확인(AMD):

때만** 강조된다(AMD 실측: 녹색 40% + inset). 평소엔 조용하다.
데이터가 없거나 추세가 FLAT 이면 블록 자체를 안 그린다(TKNO·SERV 로 확인).

### 구성 변화 — 만들었다가 «펼침»을 뺀 기록

대표 판단: *「빽빽하면 굳이 안 넣어도 의미 전달이 되면 넣지 않는 것도 좋다.
UI/UX 관점에서 판단해줘」* — 월별 미니 막대 토글을 구현한 뒤 실데이터로 보니 맞았다.

| 뺀 이유 | 근거 |
|---|---|
| 펼쳐도 보이는 게 없다 | 커버리지 30~50명에서 3개월 이동은 대개 ±1~2. LRCX 강세 30→30·약세 2→0 → **미니 막대 4개가 육안으로 구분 안 됨**(폭이 1px도 안 움직인다) |
| 카드가 이미 8개 섹션 | 토글을 둘 두면 조작 요소만 늘고 위계가 흐려진다 |
| 한 줄로 충분 | 「강세 +4 · 약세 −2」면 의미가 다 전달된다 |

→ «펼칠 게 없는 펼침»을 없애고 한 줄로. 관련 CSS 3개도 같이 삭제(죽은 코드 방지).

**★ 같이 잡은 것 — 잡음이 신호처럼 보이고 있었다.** 임계값 없이 「변화 0 이
아니면 표시」로 짜 놨더니 LRCX 의 강세+1·약세−1 이 「구성 이동 중」으로 떴다.
30~50명 커버리지에서 한 명이 등급을 바꾸는 건 상시로 일어난다.

```
MU    강세 +4 · 약세 −2  (총 이동 6 / 커버리지 46)  ← 신호
INTC  강세 +1 · 약세 −3  (총 이동 4 / 커버리지 49)  ← 신호
LRCX  강세 +1 · 약세 −1  (총 이동 2 / 커버리지 36)  ← 잡음 → 안 그린다
AVGO  0                                            ← 변화 없음 → 안 그린다
```
총 이동 **3명 이상**일 때만 값을 준다. 실화면 검증(NXPI): 「구성 변화 3개월 ·
강세 −3」 한 줄이 「▼ UBS Buy → Neutral」과 같은 이야기를 한다.

**교훈: 엔드포인트를 「쓰고 있다」와 「응답을 다 쓰고 있다」는 다르다.**
새 벤더를 붙일 때 응답 필드를 전부 찍어 보고, 안 쓰는 필드에 이유가 있는지 확인할 것.

### 4-1. 가격 — 가장 심각 (16커밋)

|---|---|---|
| 기준선이 **오늘 종가** | 2025-12-30 「보합 가드」 이후 | **전 종목 등락률 ≈ 0.00%** |

### 4-2. 「없는 값」이 「0 이라는 사실」로 둔갑 (13커밋)

에러를 안 내기 때문에 **틀린 값보다 나쁘다** — 사용자가 판정 결과로 읽는다.

| 코드 | 화면이 하던 말 |
|---|---|
| `let pcr = 1` | 옵션 데이터가 없는데 「PCR 균형」 |
| `analysis.gex \|\| 0` | GEX 미수집이 「감마 0」 |
| `stock.gex \|\| 0` | Intel 타일 전 종목 0 |
| `rvol \|\| 1.0` | 엔진을 고쳐도 계속 「거래량 저조」 |
| `grade \|\| 'B'` · `score \|\| 55` | **평가받지 않은 종목에 등급** |
| `gamma_regime \|\| 'NEUTRAL'` | 감마 미측정이 「중립 판정」 |
| **`avgDarkPool \|\| 48 + \|gammaPulse\|*0.18`** | **감마에서 다크풀을 합성** ← 최악 |

마지막 것은 새로고침마다 값이 바뀌었다. API 만 봐서는 안 보이고 **실화면 DOM 에서
역추적**해야 나왔다.

→ `TickerSnapshot` 타입부터 null 을 허용하게 바꿔 **소비처 62곳이 타입체커에 걸리게**
한 뒤, `|| 0` 을 되붙이지 않고 하나씩 「없으면 없다고 말하는」 방식으로 처리.
AI 프롬프트에는 N/A 로 넘기고 「N/A 는 미측정이며 0·중립이 아니다」 규칙 추가.
상시 검사기 `scripts/check-fake-defaults.js`.

### 4-3. 죽은 데이터가 살아 돌아옴 (다크풀 6갈래)

캐시를 지워도 크론·Lambda 가 **새 타임스탬프로 다시 채워** 나이 검사까지 무력화.
