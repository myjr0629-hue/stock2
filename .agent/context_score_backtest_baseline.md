# [SIGNUM HQ] M7 Context Score 57일 백테스트 기반 엔진 튜닝 전략 베이스라인

이 문서는 AWS DynamoDB `signum-alpha-history` 내부의 과거 점수와 주가 등락 데이터를 분석한 통계를 기록합니다. 향후 `alphaEngine.ts` 로직(Context Score 파라미터) 튜닝 시 이 데이터를 베이스라인(Baseline)으로 삼아 모델 성능을 최적화합니다.

## 0. 분석 개요
* **분석 기간:** 2026.02.03 ~ 2026.04.09 (가장 오래된 57일 전체 데이터 대상)
* **분석 대상:** M7 (AAPL, MSFT, GOOGL, AMZN, NVDA, META, TSLA)
* **데이터 소스:** AWS DynamoDB `signum-alpha-history` 테이블 V4.6 퀄리티 티어(SSR_V46) 기준.
* **평균 수익률(Base Return):** 분석 기간 내 M7 일일 홀딩 시 평균 수익률 `-0.08%`

---

## 1. 튜닝 전제 (검증된 백테스트 지표)

### 🟢 강세 시그널 (Context Score >= 65점)
* **발생 횟수:** 19회 (전체 거래일 중 4.7% 출현율 - Scarcity)
* **평균 수익률:** **`+0.27%`** (평균장세 대비 **+0.35% 아웃퍼폼**)
* **승률 (Hit Rate):** 평균 47.4% (AMZN, AAPL 등 대형 우량주는 100% 승률 기록)
* **의미:** 가짜 시그널(노이즈)을 배제하고 매우 엄격한 기준으로 강세 점수를 부여하므로 포지티브 기댓값을 보유함.

### 🔴 약세/방어 시그널 (Context Score <= 45점)
* **발생 횟수:** 249회
* **평균 수익률:** **`-0.20%`** (평균장세 대비 **-0.12% 초과 하락**)
* **적중률 (Hit Rate):** 52.6%
* **의미:** 하방 압력(방어선 붕괴, 기관 매도세, GEX 악화)을 방어적으로 경고하는 지표로써 우수한 성능을 냄.

## 2. 엔진 최적화 및 튜닝(Maximize) 전략 프레임워크

### 💡 전략 1: 종목 성향(Beta) 기반 가중치 어져스터(Adjuster) 도입
M7 내부에서도 기관과 개인의 수급 비율에 따라 점수의 예측력이 파편화됨을 확인했습니다. 향후 `alphaEngine.ts`는 종목의 성향을 판단하는 파라미터를 추가해야 합니다.
* **AMZN, AAPL, GOOGL 그룹:** 현재의 V4.6 로직(기관 플로우 + GEX 옵션 구조 중심)과 최고의 궁합을 보여줌 (승률 50~100%, 평균수익 1% 이상). **현재 가중치 유지.**
* **TSLA 그룹:** 개인 투자자의 밈(Meme) 성향과 과도한 투기 옵션이 몰리는 종목으로 현재 승률 25%, 평균수익 -1.87%로 **최악의 궁합**을 기록함.
  * **튜닝 방안:** 테슬라와 같은 종목은 기관 옵션 수급 지수(Flow)의 가중치를 낮추고, 단기 모멘텀(Momentum/가격 변동성) 가중치를 부여하는 **다이나믹 가중치 할당**이 반드시 필요합니다.

### 💡 전략 2: 1-Day -> 3-Day 스윙 보유 수익률 분석 체계화
* Context Score는 당일 데이트레이딩용 틱 지표가 아닌 기관 옵션 자금 흐름에 기반을 둡니다. 즉, 점수가 발동된 후 옵션 만기일이나 기관 수급이 실제 가격에 반영되기까지 보통 1~3일의 지연이 발생할 수 있습니다.
* **튜닝 방안:** 향후 튜닝 시 백테스트 로직은 다음 날(Next Day) 하루의 수익률만 보는 것이 아니라 `Forward 3-Day Average Return`을 기준으로 테스트 로직을 재작성하여 Score Threshold(임계점)를 60점, 65점 등 다양하게 테스트해야 합니다.

### 💡 전략 3: 사용자 인터페이스(UI) 환류 - AI 애널리틱스 활용
* 백테스트가 튜닝을 통해 완성되면, 유저 화면에 다음과 같이 통계 기반의 신뢰 문구를 띄웁니다.
  > "현재 TSLA의 Context Score는 68점입니다. TSLA는 이런 구조가 나왔을 때 과거 3일 보유 승률이 80%였습니다."
* 이 문구를 통해 유저가 체감하는 점수의 신뢰도를 폭발적으로 증가시킬 수 있습니다. 매일 DynamoDB에 적재되는 SSR_V46 데이터는 이 문구 생성의 핵심 원천 자원입니다.
