## 0. ★ 스토어 «안»의 무료 도구 — 지금 하나도 안 쓰고 있다

가장 저평가된 구간이다. **이미 우리 손에 있고, 전부 무료고, 심사도 없다.**

| 도구 | 위치 | 상태 | 무엇을 하나 |
|---|---|---|---|
| **App Store 피처링 요청** | ASC → 피처링 | ✅ 제출(7/10, 창 8/31까지) | 에디터 추천 후보 |
| **Google Play 피처링 노미네이션** | Play Console → Grow users | ❌ **미제출** | 동일 |
| **앱 내 이벤트 (In-App Events)** | ASC → 성장 및 마케팅 | ❌ 0건 | **App Store 검색·Today 탭에 «이벤트 카드»로 별도 노출.** 「장마감 브리핑」 같은 정기 이벤트를 걸 수 있다 |
| **Play 마케팅 활동 (Marketing activity)** | Play Console | ❌ Upcoming 0 · Live 0 | Play 스토어 내 프로모션 배너 |
| **맞춤형 제품 페이지 (CPP)** | ASC → 성장 및 마케팅 | ❌ 0건 | **채널별 전용 랜딩.** 유튜브 유입엔 A페이지, 토스 유입엔 B페이지 — 전환율이 갈린다 |
| **제품 페이지 최적화 (PPO)** | ASC | ❌ 0건 | 스크린샷·아이콘 **A/B 테스트**. 현재 페이지→설치 38%를 더 올릴 수 있다 |
| **프로모션 코드** | ASC | ❌ | 리뷰어·인플루언서에게 Pro 무료 제공 |

> **노출 1,170회 → 페이지 107 → 설치 41.** 페이지 전환 38%는 이미 좋다.
> 병목은 «노출»이고, 위 도구들이 정확히 노출을 만드는 장치다.

## 5. 실행 순서

**1주차 — 스토어 안 (무료·즉효)**
```
Play 피처링 노미네이션 · 앱 내 이벤트 · CPP 채널별 · PPO A/B · 프로모션 코드
```

**1~2주차 — 등록형 일괄 (하루에 몰아서)**
```
BetaList → Uneed → Peerlist → Microlaunch → Fazier → Dev Hunt
→ Tiny Startups → AlternativeTo → Launching Next → StartupBase
```

**2주차 — 한국 (실사용자가 있는 곳)**
```
디스콰이엇 메이커로그 · 토스 피드 · 요즘IT 기고 · 보도자료(플래텀·벤처스퀘어)
```

**2~3주차 — 일본 (개간)**
```
Zenn 기술기사 · note 서사 · みんかぶ · Qiita
```

**3주차 — 미국**
```
Stocktwits 일일 포스팅 · FinTwit 협업 DM · r/sideproject
```

**3~4주차 — 큰 것 (준비 완료 후)**
```
Product Hunt (평생 1회) · Show HN
```
