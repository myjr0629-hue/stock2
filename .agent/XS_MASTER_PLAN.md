# XS 마스터 플랜 — "실시간 능동 판단, 무결한 최고의 스코어"로 가는 틀 (정본)

> 2026-07-30 수립. 대표 지시: "3일 구조가 기본틀이지만 목적은 실시간으로 능동 판단하는 현시점 가장 정확한 스코어. 백테스트만 반복할 게 아니라 완벽한 틀을 먼저 잡아라."
> 이 문서가 스코어 고도화의 **틀(frame)** 정본이다. 모든 후속 개선은 이 틀 안의 어느 단계인지 명시하고 진행한다.

## 0. 현재 위치 — 정직한 판정 (2026-07-30 실측)

**자동매매 사용 가능? 아니오.** 15일 게이트에서 상위데실 실측 α = -0.103% → FAIL → calib-contra가 오토 엔진 신규 진입을 자동 차단 중. 시스템이 설계대로 스스로 멈춘 상태.

**이전(V8)과의 차이 — 질적 전환은 실재:**

| | V8 (7월 초까지) | XS 현재 |
|---|---|---|
| 배포 근거 | 인샘플 r=+0.165 (과적합) | 사전등록 레이스 실측만 |
| 실전 성적 | r=**-0.019** 소멸, 밴드 역전 | 적응 0 / **고정류 +0.03~0.07, 라이브 반적응 +0.128(6d)** |
| 실패 감지 | 없음 (몇 달 방치) | **15일 만에 자동 차단** (calib-contra) |
| 측정 기반 | 팩터 저장 0.4~16% (분석 불가) | z벡터+라벨 전수 저장, 30일 관측 고고학 |

= "가짜 양수"에서 "진짜 0~약양수 + 자기교정"으로. 진보는 실재하나 실전 기준(게이트 3종) 미달. 페이퍼 트랙 +5.97%(3주)는 상승장 수혜 포함 — 스코어 실력으로 셈하지 않는다.

## 1. 틀의 핵심 — 목표의 정확한 재정의 (창의적 핵심)

"실시간 정확한 스코어"는 **일배치 스코어를 더 자주 다시 계산하는 것이 아니다** (입력 자체가 일 단위·5분 단위라 물리적으로 불가). 정답은 **2계층 분리**:

```
Live Score(t) = Base Score(일 1회) × Live Modulation(실시간)
```

- **계층 1 — Base Score (선별, T+3 지평)**: "무엇을 살 만한가". 일 1회, 크로스섹션, 레이스로 검증. **T+1 재구성에서 전 변형 무신호 실측** → 신호는 T+3에만 존재. 3일 구조는 한계가 아니라 실측된 신호 지평이다.
- **계층 2 — Live Modulation (상태, 실시간)**: "지금 행동해도 되는가". 이미 실시간으로 아는 것들로 Base를 실시간 변조:
  - 레벨 상태: 가격 vs 감마플립/풋플로어/콜월 (딜러 감마 = 변동성 상태변수, Ni-Pearson-Poteshman-White RFS 2021 — 세션 리서치로 검증됨)
  - 플로우 확인: 다크풀%·스윕 방향 (5분 신선도, 자체 파이프라인)
  - 레짐: SPY 넷감마 부호(가동 중) + FRED NFCI/HY (월드모니터 조사로 소스 검증)
  - 실행 상태: 스프레드bps·세션 (RT 엔진 계측 중)
- 콘솔의 VERDICT(점수+구조 판정)가 이 2계층의 원형이며, 오토 엔진의 [일배치 코호트 + 실시간 리스크(북스톱·킬)]도 동형. **틀은 이미 절반 서 있다 — 남은 것은 계층 2를 수치화·사전등록·채점하는 것.**

## 2. 마스터 플랜 — 5단계

### 1단계. Base 교체: XS-2.0 앙상블 (이번 주)
- 유일하게 안정적인 실측("고정류 3종 전부 > 적응")만 사용: **메인 = mean(동결, 반적응, 클린)**. 단일 승자 선택(주마다 1위가 바뀜 = 선택 과적합)을 구조적으로 회피.
- 절차: 앙상블을 변형으로 사전등록·병행 채점 → 라이브 확인(레이스 10일차) → 메인 교체. 개별 3종 레이스는 지속 — 훗날 확정 승자가 나오면 그때 좁힘.

### 2단계. Live Modulation 수치화 (Base 교체 직후)
- `mod(t) = w1·레벨상태 + w2·플로우확인 + w3·레짐` — 성분·가중을 **사전등록으로 동결** (근거: 각 성분의 세션 검증 문헌·자체 전적만. 인샘플 튜닝 금지).
- 채점 방법(핵심): 계층 2의 라벨은 T+3가 아니라 **RT 쌍둥이의 실현 손익** — 오토 엔진의 진입~청산 실측이 곧 Live 레이어의 스코어보드다. (쌍둥이 구조가 이걸 위해 이미 존재)
- 산출: 콘솔 VERDICT가 정적 판정 → **실시간 숫자 스코어**로 승격. 오토 엔진 v2의 사이징 입력 후보.

### 3단계. 신팩터 파이프라인 (상시, 레이스로만)
- 대기열: **Form4 인사이더 군집**(1순위 — top-10 구조에서 희소·정밀 신호의 지렛대 최대, EDGAR 공공 실측 검증) → COT 극단(지수 레짐) → 13F QoQ·핵심광물(후순위).
- 규칙: 모든 신팩터는 앙상블 Base 위 단일 변형으로 등록, 15~20라벨일 후 채택 판정. 동시 등록 변형 수 ≤ 2 (다중비교 억제).

### 4단계. 측정 고도화 (틀의 유지보수)
- 관측 고고학 월 1회 정례화 (Z_RING 30 활용): D9 해부·팩터 비정상성 추적 → 3단계 대기열 갱신.
- 버리는 것도 기록: **T+1 지평 = 실측 무신호로 폐기(2026-07-30).** 재도전하려면 새 근거 필요.
- RT 실행품질(스프레드bps·소멸률)로 쌍둥이 NAV 갭 원인 분해 → 실행 개선은 별도 트랙.

### 5단계. 승격 사다리 (불변)
게이트 3종(IC≥+0.03 롤링 15일+ · V8 우위 · 상위데실 α>0) → B단계 1주 배관 → C 실전. **앙상블 교체 후 게이트 시계는 재시작** — 새 Base의 실측으로만 통과.

## 3. 하지 않을 것 (틀 보호 조항)
1. 인샘플 발견의 라이브 직행 (V5·V8 5회 반복 사고의 원인)
2. 단일 승자 조기 선택 (주간 순위 뒤집힘 실측)
3. T+1 추격·일중 자체 알파 발명 (실측 무신호·데이터 부재)
4. 레이스 판정 전 다변형 남발 (검정력 분산)
5. Base 재계산 주기 단축으로 "실시간" 흉내 (물리적 무의미 — 실시간성은 계층 2의 몫)
