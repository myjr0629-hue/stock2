## 7. ★ 콜드스타트 시퀀스 (딥리서치 검증 2026-07-16, 103에이전트·9확정/16기각)
> **원앤던은 "먼저 데운 뒤" 발사.** 진공에 쏘면 낭비 — PH 상승세의 40~60%가 "내가 미리 데운 청중"에서 나옴(*"PH는 모멘텀을 만들지 않고 증폭만 함"*). 미리 시딩한 런치가 팔로워 더 많은 콜드 런치를 ~4순위 앞섬.

### 타이밍 결론 (지금 vs 애드몹 후)
- **무료 마케팅 = 지금.** airtight한 근거는 "**시딩은 광고 상태와 무관하게 지금 시작해야 한다**"(시딩이 몇 주 걸리므로). ⚠️정직: "설치-먼저-수익-나중"을 증명한 깨끗한 연구는 없음(관련 주장 다수 근거부족 기각) → "지금이 낫다"보다 "지금 시작 안 하면 손해"가 더 정확한 프레이밍.
- **유료 마케팅(스폰서·ASA·UAC) = 애드몹 수익 후.** (기존 규칙 유지)

### ★ 교정: 시딩은 "며칠"이 아니라 "몇 주" (4~6주 컨센서스, 최소 30일)
원앤던 발사는 **~4~6주 시딩 후**. 계정 나이가 게이팅 항목이라 **시딩 시계는 오늘 시작**.

### 90일 순서 (마케팅 싫어하는 솔로 기준)
- **Day 0~30 씨뿌리기**: 앱별 *가장 좁은* 청중 1개 지정(SIGNUM=US 옵션플로/GEX 트레이더 / UC=서학개미·新NISA) → 주 1편 알맹이 포스트. 유료 0. Reddit/커뮤니티=**가치우선**(홍보 전 신뢰 베이스라인: 계정 30일+·카르마 200~500·비홍보 댓글 10~20). **링크 투척 금지**("X를 만드는 도움 되는 사람"이 목표).
- **Day 30~60 키우기**: 주 3~5편 확대 + 타깃 서브레딧 2곳 주 2시간 "답변만"(홍보 X).
- **Day 60~90 증폭**: 되는 채널 1개 집중, 나머지 정리 → **이때 원앤던(PH/Show HN/디스콰이엇/note) 발사** — 업보트해줄 커뮤니티 있을 때만.

### PH 발사 기계적 최적화 (무료·즉효)
- 스케줄러로 **12:01 AM PST**(태평양 자정 직후) · **화~목**. 8AM에 쏘면 24시간 창에서 ~8시간 손해.

### ⚠️ 정직한 공백 (미해결)
- **KR/JP 커뮤니티 = 검증 실패.** 후보(미주갤/DCinside·토스증권·네이버카페·카톡 주식방·5ch) 전부 근거부족/모순으로 기각. 착수 전 **직접 가입→고정공지 규칙 확인** 필수. KR은 디스콰이엇 외 검증 채널 없음이 실제 갭.
- **크로스앱 리퍼럴 루프(SIGNUM↔UC)** · **괴리 공유카드 바이럴 루프** = 검증된 전술 없음(오픈 질문).
- 근거 전반이 마케팅 블로그(+PH 공식문서 1차) → 수치('3-5x','200-500 카르마' 등)는 **방향성 heuristic**, 하드타깃 아님.

## 8. ★★ 발사 트리거 — 확정 (대표님 결정 2026-07-17)
- **시딩(포스팅·댓글) = 지금 계속** (조용히·가치우선). ⚠️이건 "적극적 홍보"가 아니라 **활주로**.
- **적극적 홍보(원앤던 발사 + 유료) = 광고(애드몹) ON + 업데이트(SIGNUM v1.1 / UC 1.0.1) 라이브 후.** 그 전까진 **준비만**(초안·계정·자산 완성해두기).
- **극대화 구간 = 3조건 수렴 순간**: ①업데이트 라이브 ②애드몹 ON(런치 스파이크가 돈이 됨) ③시딩으로 데워진 청중.
- **핵심 설계 = 병렬**: ①②를 기다리는 동안 ③을 지금부터 만들어 **동시 도달**. 순차로 하면 몇 달 밀림.
- **함정 방지**: "홍보를 뒤로" ≠ "시딩도 뒤로". 시딩은 4~6주 걸리므로 **오늘 시작**(안 하면 애드몹 승인 후 또 4~6주 공백).
- 타이밍 추정: 애드몹 경로(세금→애드몹→UC 1.0.1)가 롱폴 ~4~8주 ≈ 시딩 4~6주 → 오늘 시딩 시작 시 자연 수렴.

## 9. 추가 적극 홍보처 조사 결과 (딥리서치 검증 2026-07-17, 103에이전트·16확정/9기각)
> **핵심 교훈: "오가닉 도달 ≠ 홍보 허용."** 큰 핀테크 커뮤니티는 거의 다 자기홍보를 명시 금지 → 링크 던지기=위반. 도달은 "진짜 공감되는 콘텐츠"에만 열림(= 결국 §7 가치우선 시딩으로 회귀). 깨끗한 원앤던 신규 채널은 사실상 **긱뉴스 1개**.

### ✅ 추가 확정 (넣을 것)
- **긱뉴스(GeekNews, news.hada.io)** — 한국판 Show HN. "Show GN"에 직접 만든 서비스 원앤던 게시, 게이트=무료가입 1회뿐(카르마/나이 없음). **SIGNUM 기술각 최적**(청중=개발/스타트업, 일부 투자자). → §1 매트릭스 KR·SIGNUM에 Show HN 짝으로 편입 완료.

### ⚠️ 조건부/제약 (알고 쓸 것)
- **Stocktwits(US·SIGNUM)** — 자기 콘텐츠 링크 공유 *가능*하나 규칙 빡셈: 홍보 <10%·첫 50포스트 홍보태깅 금지·페이월/구독전용 링크 금지·대량반복·콜드DM=스팸. → **원앤던 아님**(가치우선 유기 게시만). 봇 자체는 금지 아님(복붙/대량만 차단).
- **PR TIMES(JP)** — 무료 스타트업 챌린지는 **일본 株式会社(설립24개월내)만** → **US LLC 자격 미달**(무료 불가). 유료 ~¥30k/건은 열려있으나 ROI 미검증.
- **아웃스탠딩(KR·SIGNUM)** — IT/스타트업 전문 매체. 셀프서브 PR 아님(릴리스 메일=보도 보장 X) → **에디토리얼 피칭**만.
- **DCinside 미주갤(KR·UC/서학개미)** — 최대 익명 미국주식 커뮤(장중 분당 1-2글·밈 전파력 큼) BUT 자기홍보 적대 → **링크는 반사 못 받음**. 유기 콘텐츠만.

### 🚫 SKIP (허수·불가)
- **TradingView** — 일반유저 외부링크 전면금지. 링크 홍보 불가.
- **런치 디렉토리 대부분**(Dev Hunt·Fazier·Peerpush·TAAFT·TopAI.tools) — 설치기여 주장 전부 기각 = **백링크/허수**. PH/Show HN 외 검증된 미국 신규 디렉토리 = 0.
- **하테나 북마크(JP)** — 셀프/공모 북마크=스팸. 부스팅 레버 아님.

### 📋 미검증 공백 (나쁘다는 게 아니라 미조사 — 착수 전 직접 규칙 확인)

### 결론 (한 줄)
**신규 "설치 소방호스"는 없었다.** 큰 커뮤는 죄다 유기 콘텐츠 보상형(→ §7 시딩과 동일 논리). 순증 원앤던 = **긱뉴스** 1개. 나머지는 가치우선 참여 or 허수 → 전략 무변경, 채널 하나 보강 + 헛발질 방지.
