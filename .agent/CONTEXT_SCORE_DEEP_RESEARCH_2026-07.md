## 0. 경영 요약 (Executive Summary)

1. **현행 스코어의 3일 예측력은 통계적으로 0이다.** 전 기간 일별 크로스섹션 IC(Spearman) = **+0.016 (t=0.73)**. 5개 엔진 세대(V4.6→V8) 어느 것도 유의미한 아웃오브샘플 예측력을 달성하지 못했다.
2. **V8의 근거(grid search r=+0.1652, 90,965쌍)는 인샘플 과적합이었다.** 배포 후 실데이터(n=9,814)에서 r = **-0.019**로 완전 소멸. V5(87% 적중 주장)→실측 38.5%에 이어 **두 번째 "인샘플 승리 → 실전 소멸" 사이클**.
3. **스코어의 상위 밴드가 오히려 역예측한다.** 70-79 밴드: 시장조정 후 **-0.56%/3d, 적중 47%** (V8 시대는 -1.6%, 41.5%). 최고 성과 밴드는 50-59. 즉 "점수가 높을수록 좋다"가 꼬리에서 붕괴 (inverted-U).
4. **스코어가 일별 노이즈다.** 종목별 스코어의 하루 자기상관 = **0.043**. "3일 이상의 구조적 체력(Macro Core)"이라는 제품 포지셔닝과 정면 모순 — 오늘 68, 내일 45가 일상.
5. **데이터 인프라가 연구를 막고 있다.** 레코드의 74%가 engineVersion 없음, V5.0이 약속한 입력 벡터 저장은 커버리지 0.4~16%로 사실상 실패(whaleIndex/ivSkew/return3D ≈ 0%), 두 라이터(Vercel SSR vs Lambda)가 서로 다른 필드를 기록해 **팩터 간 교차 검증이 불가능한 구조**.
6. **그러나 원석은 있다.** 개별 팩터에 약하지만 실재하는 역발상 신호 확인: GEX IC -0.073(t=-1.69), VWAP이격 -0.073, PCR -0.034. 동일 일자 맞대결에서 **단순 3팩터 크로스섹션 랭크 합성(IC +0.047, 70% 양성일)** 이 현행 스코어(**IC -0.120, t=-2.85**)를 압도. → 재료가 아니라 **조합·정규화·검증 방법**이 문제다.

**결론: "절대 스코어"는 달성 가능하지만, 현재의 수제 포인트-게이트 튜닝 반복으로는 도달 불가. §6의 방법론 전환(크로스섹션 정규화 + IC가중 합성 + 보정된 확률 표기 + 워크포워드 검증)이 필요하다.**

## 5. 근본 원인 5가지

1. **크로스섹션 정규화 부재.** RSI<35, PCR>1.3 같은 **절대 임계값**은 시장 전체가 함께 움직일 때 전 종목이 동시에 점수 상승/하락 → 스코어가 "어느 종목이 상대적으로 좋은가"가 아니라 "오늘 시장이 얼마나 빠졌나"를 측정. 크로스섹션 IC가 0인 직접적 이유.
2. **목적함수 오설정.** pooled Pearson vs 원수익률 = 시장 베타 + 아웃라이어에 지배됨. 절대 스코어의 올바른 목적함수는 **일별 크로스섹션 랭크 IC vs 시장조정 수익률**.
3. **수제 스텝-게이트의 과적합 표면적.** 수십 개의 if-then 포인트(+8, +10, cap65…)는 자유도가 높고 상호작용이 비선형 → 그리드서치가 노이즈를 학습. Bailey & López de Prado의 "Probability of Backtest Overfitting" 이 경고하는 전형.
4. **검증 프로토콜 부재.** 인샘플 최적화 → 즉시 배포 → 실측 실패 → 재튜닝 루프. 워크포워드/퍼지드 홀드아웃/배포 전 페이퍼 기간이 없음.
5. **데이터 파이프라인 분열** (§2) — 연구 가능한 원장(ledger)이 없어 매 튜닝이 부분 데이터 위에서 수행됨.

## 6. 학술 근거 (핵심 문헌)

- **Grinold & Kahn, *Active Portfolio Management*** — IC/IR 프레임워크. IR ≈ IC×√breadth. 일별 2,000종목이면 IC 0.03-0.05로도 탁월한 전략 성립. **좋은 단일 팩터 IC 0.02~0.05, 상위 멀티팩터 0.05~0.10이 현실적 상한** — "적중률 87%" 류 주장은 문헌상 존재하지 않는 수준.
- **Jegadeesh (1990), Lehmann (1990)** — 단기 리버설(1주~1개월)은 가장 견고한 크로스섹션 이상현상. 현 데이터의 vwapDist/chg 역방향 신호와 정합.
- **Harvey, Liu & Zhu (2016), "…and the Cross-Section of Expected Returns"** — 팩터 다중검정 문제, **t>3.0** 기준 권고. 현 엔진의 어떤 성분도 이 기준 미달.
- **Bailey & López de Prado — Deflated Sharpe Ratio / PBO** — 그리드서치 시도 횟수를 반영해 성과를 디플레이트해야 함. V8 r=0.165는 시도 횟수 감안 시 기대 노이즈 범위.
- **López de Prado, *Advances in Financial Machine Learning* (2018)** — Purged K-Fold + Embargo(중첩 라벨 누수 방지), 메타라벨링(방향 vs 사이징 분리). Phase 2의 교과서.
- **Gu, Kelly & Xiu (2020), "Empirical Asset Pricing via Machine Learning"** — 개별주 수익률 예측의 현실적 OOS 상한(월간 R²oos ~0.4%, 부스티드 트리/NN 우위). 기대치 설정의 벤치마크.
- **Barbon & Buraschi (2021), "Gamma Fragility" / SqueezeMetrics GEX 백서** — 딜러 감마 포지셔닝의 수익률·변동성 예측력. 현 데이터의 GEX IC -0.073과 방향 일치 — **이 팩터가 시스템의 가장 유망한 원석.**
- **보정(Calibration): 등화회귀(Isotonic) / Platt scaling** — "스코어 80 = 실제로 무엇이 몇 %인가"를 데이터로 보장하는 표준 기법. "절대 스코어"의 수학적 정의가 바로 이것.

## 7. 로드맵 — 절대 스코어로 가는 길

### Phase 0 — 측정 기반 복구 (1주, 코드 소규모)
1. **원장 통일:** Lambda·Vercel 라이터가 **동일 스키마**로 전 입력 벡터+engineVersion을 매일 기록 (지금의 74% 무버전, 0.4% 벡터로는 어떤 연구도 불가).
2. **목적함수 고정:** 일별 크로스섹션 Spearman IC vs T+3 **시장조정** 수익률. 자동 리포트 크론(주 1회 .agent/에 IC 리포트 적재).
3. **검증 헌법:** 배포 전 최소 [워크포워드 3분할 + 2주 페이퍼 트래킹] 통과 의무화. 인샘플 grid search 단독 배포 금지.

### Phase 1 — 스코어 재설계 (2~4주, 규칙 기반 유지 — 설명가능)
1. **크로스섹션 랭크-z 정규화:** 매일 유니버스 내 랭크 → z. 절대 임계값 전면 대체.
2. **팩터 셋 (자체 데이터 실증 순):** ① GEX/감마 레짐(역) ② 단기 리버설 번들(chg·vwapDist·RSI 역) ③ PCR 극단 ④ IV-RV 스프레드 ⑤ (커버리지 복구 후) 다크풀·숏볼륨·whale.
3. **IC-가중 합성:** 가중치 = 직전 60일 롤링 IC (수축추정으로 균등가중과 블렌딩). 부호가 뒤집히는 팩터(GEX 서브샘플 반전 확인)는 자동으로 가중치↓ — 수제 재튜닝 루프 종식.
4. **시장 성분 분리:** 크로스섹션 스코어(종목 선택)와 **마켓 레짐 게이지(시장 타이밍)를 별도 지표로 분리**. 현 V8은 사실상 후자 — 섞으면 둘 다 죽는다는 것이 이번 실증.
5. **평활화:** 스코어 EMA(3~5일) → 자기상관 0.04 → 0.7+. "구조적 체력" 서사와 UX(점수 널뛰기) 동시 해결.
6. **절대성 = 보정:** 합성 백분위 → 등화회귀로 "기대 3일 알파·적중률" 매핑. **스코어 80의 정의 = "과거 12주 기준 상위 10%, 시장 대비 평균 +X%, 적중 Y%"** — 저장된 이력으로 매주 자동 재보정. 이것이 요청하신 "절대적인 스코어"의 조작적 정의.

### Phase 2 — ML 승격 (원장 3~6개월 축적 후)
- LightGBM(단조 제약) → 크로스섹션 랭크 예측, Purged K-Fold + Embargo, 메타라벨링으로 신뢰도(사이징) 분리, 레짐 피처(VIX·시장 3일 수익률·breadth) 투입.
- 기대: 문헌·유사 시스템 기준 **IC 0.03~0.06, ICIR 0.3~0.6** 도달 가능선.

### Phase 3 — 제품 환류
- `alpha_track_records` 크론 복구 → 실시간 트랙레코드 → "이 점수 구간의 최근 90일 실측 적중률 N%" UI 문구 (베이스라인 문서 전략 3의 완성).
- 마케팅 수치는 OOS 트랙레코드만 사용.

### 개선 시 기대효과 (정량)
현 상태 IC +0.016 → 목표 IC 0.04, ICIR 0.5 달성 시:
- 상위 데실 기대 알파 ≈ IC × σ(3d수익률≈4.5%) × 1.75 ≈ **+0.3%/3일 (시장 대비)**, 적중률 55~58%
- 연환산 롱숏 그로스 ≈ +20~25% (비용 전), **일별 양성 IC 비율 ~60%** — 정직하게 지속 가능한 수준
- 스코어 자기상관 0.7+ → 사용자 신뢰(점수 일관성) + "구조적 체력" 서사 정합
- 보정된 절대 스코어 → "80점 = 검증된 통계적 의미"를 상시 보장, 버전 튜닝을 해도 의미가 불변 (재보정이 흡수)
