⛔ 이건 «제작이 무의미하다»는 뜻이 아니다. **19편이 전부 같은 틀로 만들어져 변산이 없다.**
   못 가린 것이지 없는 것이 아니다. 다만 **없는 근거로 제작을 뜯어고치지는 않는다.**

**우리가 잰 것 중 조회를 실제로 가른 유일한 것은 «제목의 수요 어휘»였다**
(22편 중 수요어 없는 21편 조회 중앙 42).

⇒ **우선순위: 소재·제목 > 끝맺음 > 제작 디테일.**

## 세 소스가 «합의»하는 단 하나

| | 마지막에 무엇을 남기는가 |
|---|---|
| 경제사냥꾼 | 「10년물 **4.7%**」 「PMI 높으면 금리 튄다」 |
| 외부 분석 | 「맥스페인 **128달러** 지지」 |
| 우리 GOLD821 | 「통화 베팅이다」 ← **쓸 숫자가 없다** |

**경제사냥꾼의 「기승전결이 완결됐다」는 구조 때문이 아니다. 끝에 «숫자»가 있기 때문이다.**

⇒ **모든 편은 「오늘 밤 확인할 수 있는 숫자 하나」로 끝낸다.**
   일본 1호는 이미 했지만 **3개**를 줬다 (감마 220 / 주가 216.85 / 맥스페인 210). **1개로 좁힌다.**

## 적용 — 3단계

### A. 즉시 (근거 있음)

1. **기준선 하나로 끝내기** — 3소스 합의 + 우리 결함 확인
2. **루프를 훅 앞부분으로 실제 연결** — 기능은 있고 연결이 끊겼다
3. **밝게** — 레퍼런스 YAVG **174** vs 우리 92.8. 이미 `finish-video` 에 넣음
4. **첫 화면 심볼** — 이미 게이트로 박음

### B. 실험 (근거 없음 → 사전등록하고 잰다)

| 항목 | A안 | B안 |
|---|---|---|
| 훅 | 반전을 앞에 다 보여준다 | **답을 감추고 중반에 공개** |
| 진행 | 그냥 흐른다 | **개수 명시** 「이유는 둘이다」 |
| 중반 | 없음 | **재훅 신호** 「그런데 이상한 게 하나」 |
| 자막 숫자 | 0% (카드가 나른다) | 레퍼런스는 **4.8%** 인데 좋아요율 4.68% |

⛔ **한 번에 하나만 바꾼다.** 넷을 동시에 바꾸면 무엇이 효과였는지 영원히 모른다.

### C. 기각

15초 강제 · 「완청률 120% 강제 달성」 · 「38초 물리적 한계」

## 놓치면 안 되는 것 — 진짜 격차는 제작이 아니다

| | 경제사냥꾼 | 우리 |
|---|---|---|
| 발행 | 14개월 **2,414편** = 하루 **5.7편** | 2개월 24편 = 하루 **0.4편** |
| 소재 | **당일 밤에 터지는 것** | 개념·구조가 섞임 |
| 숫자 출처 | 전부 남이 발표한 것 | **우리가 계산한 것** |

**물량이 14배다.** 제작 디테일을 아무리 다듬어도 이 격차는 안 메워진다.
3슬롯/일 체제가 맞는 방향이고, 거기에 **당일 시의성**을 붙이는 것이 핵심이다.

우리가 이기는 지점은 하나뿐이다 — **숫자를 우리가 만든다.**
그들이 「노무라가 103.8이래」로 채우는 자리에 「우리가 3,396개 금요일을 세봤더니」를 넣는다.
