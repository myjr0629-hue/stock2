## 3. 3단계 비교 (최종 정리)

| 항목 | ① 현재 V8 (실측) | ② 기본 튜닝 Phase 0~1 | ③ 퀀텀점프 융합 |
|------|:---:|:---:|:---:|
| IC (T+3) | ≈0 (-0.024~+0.016) | +0.035~0.045 | +0.065~0.08 |
| t-통계 | 0.7 (무의미) | >3 | >4 |
| 상위 데실 3일 알파 | **-1.6%** (역예측) | +0.5~0.8% | +0.9~1.2% |
| 적중률(고득점) | 41% | 56~58% | 59~61% |
| 점수 자기상관 | 0.043 | 0.7+ | 0.7+ |
| 점수 의미 | 버전마다 변동 | 보정으로 고정 | 고정+신뢰도 게이지 |
| 정보 원천 | 가격·옵션 1계열 | 동일 (정비) | +내부자·기관·애널·AI 5계열 |
| 시장 위치 (10점) | 2점 (미검증 리테일) | 7점 (개인용 최상위, 애널리스트급) | 8.5점 (퀀트 단일알파~복수알파급) |
| 추가 데이터 비용 | — | 0원 | 0원 (재배선) |

**②③은 택일 아닌 직렬**: Phase 0 스키마에 ③의 팩터 필드를 처음부터 포함 → 재작업 없음.

## 4. 실행 경로 (승인 대기)

1. **Phase 0 (1주)**: 기록 스키마 통일(전 입력벡터+engineVersion 필수, 융합 팩터 필드 포함) · xsScore 그림자 기록 · 주간 IC 자동 리포트 크론
2. **Phase 1 (2~4주)**: 랭크-z 정규화 → IC-가중 합성 → 시장 게이지 분리 → EMA 평활 → 등화회귀 보정
3. **융합 점등 (각 1~3일)**: 우선순위 1→4 순서로 팩터 추가, 그림자 IC로 채택/기각
4. **8~12주**: 챔피언/챌린저 자동 승격 + 보정 테이블 제품 노출

## 5. 검증 헌법 (모든 후속 에이전트 필수 준수)

1. **목적함수 고정**: 일별 크로스섹션 Spearman IC vs T+3 시장조정 수익률. pooled Pearson·1시점 스냅샷·인샘플 grid search 단독 근거의 배포 **금지**.
2. **배포 조건**: 워크포워드 3분할 통과 + 최소 2주 그림자(병행 기록) 실측 우위.
3. **성과 주장**: OOS 트랙레코드 수치만 사용. "적중률 8~90%" 류 인샘플 수치 사용 금지.
4. **스키마 불가침**: alpha-history 기록 필드 제거/개명 금지 (추가만 허용). engineVersion 필수.
