## 0. 왜 과거 13채널 스프레이가 트래픽 0이었나 (전체 재프레임)
- **발행 자동화 자체는 벌점 없음** — "스케줄러 페널티"는 미신(Buffer·Hootsuite 2025.4·Agorapulse 실험 모두 동일/우위 도달).
- **진짜 원인 ①**: 소셜 도달은 **"첫 30~60분 사람 인게이지먼트(공유/전송/답글)"에 게이트**됨 — 봇이 못 만드는 신호. 팔로워 0 채널은 그 신호를 **구조적으로 못 만듦** → 0. (Mosseri 2025.1: Reels 최상 신호 = 시청시간·좋아요·**전송(sends)**, sends가 비팔로워 도달 열쇠.)
- **진짜 원인 ②**: **동일 콘텐츠 다채널 복붙 = 이제 강등** (IG 비독창성 2026.4 확장, TikTok **FYF 표준 2025.9.13**, YouTube "비진정성" 2025.7.15). "같은 자산 다 뿌리기" = 강등 패턴 그 자체.
- **∴ 전략 피벗: 자동화를 "청중이 소셜 알고리즘이 아닌 곳 = 크롤러·LLM·기존유저"에 집중.** 거기만 사람 없이 복리. 콜드 소셜 피드 의존은 소량 사람 시드 필요.

## 1. 벽 + 불가결 사람 최소치 (정직·정량)
- **완전 자동이 이기는 곳**: SEO/GEO 페이지 · 뉴스레터 아카이브 · 유저기반 공유루프 (청중이 소셜 알고리즘이 아님 → 첫시간 게이트 없음).
- **벽**: 모든 콜드 소셜 피드. 첫 시간 인게이지먼트 게이트를 **봇으로 못 뚫음.** (반례 못 찾음.)
- **불가결 사람 = 하루 ~20~40분** 두 가지: ①청중이 이미 있는 1~2 커뮤니티에서 **진짜 답글**(X reply 가중 13.5 vs like 0.5) ②그날 최고 괴리 1개를 **사람 첫줄로 네이티브 앵커** 포스팅. 나머지 전부 자동.
- 지평: **12~24개월** 플라이휠(첫 4~12주 사람 시드 프론트로드). **90일 완전수동 버전은 없음.** 정상상태 바닥 = **~30분/일**(0 아님). 페이스리스 유튜브 90%가 1천 구독 전 포기 — 생존편향 주의.

## 3. 자동 아키텍처
```
사건탐지(자동·상시)  괴리 시그널 발화(헤드라인 X vs 플로우 Y) → 강도/주목도 랭크
   │
   ▼
생성(자동)  ├─ 티커별 SEO/GEO 페이지(고유 실데이터)  ← 사람 없이 복리
           ├─ OG "괴리 영수증" 공유카드
           ├─ Remotion 세로영상(우리 독점데이터 = 리포스트 아님, 오리지널)
           └─ AI 캡션 플랫폼별·언어별(en/ko/ja) — 동일복붙 금지
   │
   ▼
┌──────── 사람 게이트(유일) ────────┐
│ ~20분: 그날 히어로 괴리 1개 + 훅 첫줄 │
│ 주간 20분: 배치/큐 승인             │
└────────────────────────────────────┘
   │
   ▼
발행(자동)  ├─ SEO페이지+뉴스레터/RSS: 100% 자동(게이트 불필요)
           ├─ TikTok+Shorts: 히어로 드롭, 플랫폼별 각색(절대 동일X)
           ├─ Bluesky/note/네이버블로그: 자동 신디케이션
           └─ 네이티브 앵커 1/일 = 사람이 포스트, 사람 첫줄
   │
   ▼
사람 시드(불가결 ~20~30분/일)  1~2 커뮤니티 진짜 답글(JP fintwit·SIGNUM=Reddit/Discord·KR=토스/네이버카페)
   │
   ▼
측정(자동)  어느 티커페이지 랭크·어느 카드 공유·웹→설치(딥링크/스마트배너 1개) → 승자 피드백
```
**두 사람 게이트가 상시 비용 전부.** SEO페이지·카드·영상·신디케이션 발행은 100% 자동·무벌점.

## 4. TOP 5 (오가닉 트래픽 / 자동화 노력 순)
1. **프로그래매틱 "괴리" 페이지 + GEO** — 최고 레버리지, 한번 세팅→크롤러/LLM으로 복리, **일일 사람 0.** 티커/사건별 1페이지(헤드라인+플로우+괴리, **페이지마다 고유 데이터** = 구글 스케일남용 통과). FAQ스키마+용어허브. **LLM 유입 19개월 ~10배↑(ChatGPT 92%)**, 구조화 데이터 선호 — 우리가 moat 보유.
2. **자동 "괴리 영수증" 공유카드 루프** — 유저가 배포(Spotify Wrapped/Monzo 실증, 설치 유도). 원탭 스샷카드 "뉴스는 BUY, 큰손은 반대 →". ⚠️유저 손익 암시/수익 조작 금지(사후사실만).
3. **자동 뉴스레터 + RSS** — 소유·LLM급식 복리 자산. "Divergence Brief"(beehiiv 색인+사이트맵). 알고리즘 게이트 면역.
4. **반자동 TikTok + Shorts** — 유일하게 사람손 가치있는 소셜 베팅. Remotion=독점데이터 오리지널이라 originality 단속 생존. 규칙: **1~3/일/플랫폼 MAX**(100 아님·볼륨=함정), 플랫폼별 각색(워터마크X), AI 공개, 사람이 훅/첫프레임. 싼 렌더비용은 **A/B·en/ko/ja 현지화에** 쓰기(볼륨 덤핑 아님).
5. **지역 자동 신디케이션** — 카드/브리프를 Bluesky(무료·괴리 커스텀피드)·note マネー(JP)·네이버블로그(KR)에 자동. 거의 공짜. 과투자 금지.
