## 2. 「경제사냥꾼」 화면 구조 (프레임에서 직접 읽음)

```
┌──────────────────────────────┐
│ 최태원이 무너지는            │ ← ★ 제목 배너 «영상 내내 고정»
│ 하이닉스 주가 끌어올리는 방법│    노란 바탕 · 검정+빨강 굵은 글씨
├──────────────────────────────┤
│ 🟢경제 사냥꾼   2026년 08월 04일 │ ← ★ 채널명 + 날짜 «고정»
├──────────────────────────────┤
│                              │
│      [중앙 이미지 영역]       │ ← 마스코트 / 실인물 / 자료캡처가 번갈아
│                              │
├──────────────────────────────┤
│  시장이 듣고 싶었던 건        │ ← 자막. 굵은 검정 + 핵심어만 빨강/초록
│  번 돈 중에                   │    3초마다 교체
├──────────────────────────────┤
│ ※본 영상은 투자 참고용이며…   │ ← 면책 고정
└──────────────────────────────┘
```

### 2-A. 이 채널이 «몰입»을 만드는 6가지 장치

1. **마스코트가 화자다.** 탐정 모자 쓴 초록 지폐 캐릭터가 매 컷 다른 포즈·상황
   (사무실/법정/컴퓨터 앞/국기 앞). 데이터가 말하는 게 아니라 **누군가 설명해준다.**
   → 이게 «몰입»의 정체다. 정보 전달이 아니라 «대화».
2. **제목 배너 고정.** 중간에 유입된 시청자도 3초 안에 «뭘 보는지» 안다. 리텐션 장치.
3. **날짜 고정.** 대표 지적("언제 뉴스인지")과 정확히 일치. 이 채널은 이미 하고 있다.
4. **자막이 곧 대본.** 자막만 이어 읽으면 완전한 이야기. 한 화면 한 문장, 3초마다.
   핵심 단어만 **빨강/초록**으로 강조 → 눈이 그 단어에 꽂힌다.
5. **자료 원본을 보여준다.** 영문 공시 원문에 **빨간 밑줄**, 실적 표에 **빨간 네모**.
   "내가 직접 찾아봤다"는 신뢰. 요약된 숫자보다 원본이 세다.
6. **마지막 컷 = 댓글 유도.** 「궁금했던거 있으면 '댓글'에 많이 남겨줘」 → 참여율.

### 2-B. 이야기 흐름 (②번 영상)
```
최태원 등장(실인물) → 마스코트가 "싹 다 정리해왔다"(약속)
→ 실적 표: 매출 79조 (자료)
→ "시장이 듣고 싶었던 건 번 돈 중에…"(질문 전환)
→ 영문 공시 원문 + 빨간 밑줄 (증거)
→ 주주환원 방안 표 → "딱 3개야" (정리)
→ 발행주식 7억2,900만 주 (숫자)
→ "주주환원이 눈에 보이는 순간이야" (결론)
→ 댓글 유도
```
**약속 → 자료 → 질문 → 증거 → 정리 → 결론 → 참여.** 163초를 이 리듬으로 끈다.

## 3. 영어권 조사 결과

같은 «마스코트+크림배경+3초컷» 조합의 대형 채널은 검색으로 특정하지 못했다.
영어권 금융 숏폼의 주류는 **인물이 직접 말하는 형식**(Humphrey Yang, Graham Stephan,
Andrei Jikh)이고, 페이스리스는 대체로 **B롤+자막** 조합이다.

다만 조사에서 나온 «구조 원칙»은 경제사냥꾼과 정확히 일치했다:
- 첫 **1~3초**가 재생 여부를 결정. TikTok/YouTube 공식 입장
- 골격 = **Hook → Context → Value → Payoff → CTA**
- **역순 구성**: 결론(페이오프)을 먼저 던지고 «어떻게 거기 도달했는지»를 설명
- **buried lede가 리텐션 킬러** — 제일 흥미로운 걸 15~20초에 두면 70%가 이미 떠났다
- 자막·훅은 후순위 작업이 아니라 **생산 시스템의 1급 산출물**

⇒ **경제사냥꾼은 영어권 원칙을 한국식 캐릭터 포맷으로 구현한 것.** 원칙은 이식 가능하다.

| 항목 | 경제사냥꾼 | 우리 V5 | 판정 |

| 자료 원본 노출 | ✅ 밑줄·네모 | ❌ 가공된 숫자만 | 없음 |

| 배경 | 크림 | 다크 | 정반대 |

### 우리가 이미 나은 것
- **데이터 층**: 옵션 max pain·gamma flip·dealer premium은 저쪽에 없다
- **자동화**: 저쪽은 사람이 만든다. 우리는 API→렌더가 자동
- **다국어**: 구조상 3언어 동시 생산 가능

## 5. 차용 판단 — 무엇을 가져오고 무엇을 버릴까

### 🟢 가져온다
1. **제목 배너 + 날짜 고정** — 즉시 적용 가능, 효과 확실
2. **자막 밀도 3초** + **핵심어 색 강조** — 무음 시청 85%에 직접 꽂힌다
3. **자료 원본 + 빨간 표시** — 우리는 «앱 화면»이 그 역할을 한다. 지금은 그냥 보여주는데,
   **빨간 네모로 «여기를 보라»** 를 찍어야 한다
4. **CTA를 댓글/참여로** — 앱 설치만 걸면 광고가 되고, 질문을 던지면 콘텐츠가 된다
5. **역순 구성** — 결론을 먼저, 그다음 «어떻게»

### 🟡 검토
6. **길이 163초** — 이야기가 길어야 이 밀도가 산다. 다만 우리 소재가 그만큼 두꺼운지는 별개.
   → **90~120초**를 시험해볼 만하다(42초는 너무 짧아 «흐름»이 안 생김)
7. **밝은 배경** — 브랜드가 다크인데 영상만 크림으로 갈지. **A/B로 검증할 문제**

### 🔴 안 가져온다
8. **마스코트 캐릭터** — 우리 포지셔닝(기관급 인텔리전스)과 충돌한다.
   다만 «화자가 있다»는 효과는 필요하다 → **대안: 1인칭 화법 자막**
   ("I pulled the options data. Here's what it showed.") + ElevenLabs 음성
