# 데이터 공급사 이전 — 우리가 실제로 쓰는 것 전수 목록
(2026-08-29 작성 · massive.com 계정 제한 사태 대응)

## 왜 이 문서가 필요한가
massive(구 polygon)가 Individual 플랜 약관 위반으로 계정을 제한.
Business 플랜은 Stocks $2,499 + Options $1,999 = **월 $4,498** 로 감당 불가.
→ 대안 공급사로 이전해야 하며, 아래가 **대안이 반드시 충족해야 할 요구사항**이다.

## 마이그레이션 규모
- polygon/massive 를 **직접 호출하는 파일: 21개**
- 데이터를 소비하는 화면/모듈: 30개 이상
- **WebSocket 미사용 — REST 전용** ✅ (스트리밍 재작성 불필요, 이전 난이도 크게 낮음)

## A. 반드시 대안이 제공해야 하는 것 (자체 대체 불가)

| # | 데이터 | 엔드포인트 | 쓰이는 곳 | 중요도 |
|---|---|---|---|---|
| 1 | **실시간 주식 스냅샷** | `/v2/snapshot/locale/us/...` | 34개 파일 — 현재가·VWAP·전 화면 | 🔴 최상 |
| 2 | **옵션 체인** | `/v3/snapshot/options/{t}` | 7개 파일 — 감마·맥스페인·총프리미엄·IV스큐 | 🔴 최상 (앱 정체성) |
| 3 | **일봉 aggregates** | `/v2/aggs/ticker/...` | 33개 파일 — 차트·전일종가·기준선 | 🔴 최상 |
| 4 | **다크풀/숏볼륨** | `/stocks/v1/short-volume` | 7개 파일 — 다크풀 % | 🟡 중 (차별화 지표) |
| 5 | **13F 공시** | `/stocks/filings/vX/13-F` | 14개 파일 — 기관 보유 | 🟡 중 |

## B. 자체 계산·무료 대체 가능 (대안 요구사항에서 제외 가능) ⭐

| 데이터 | 현재 | 대체 방법 |
|---|---|---|
| SMA / MACD 등 기술지표 | `/v1/indicators/*` (11개 파일) | **일봉으로 직접 계산** — 단순 수식, 외부 API 불필요 |
| 시장 개장 상태 | `/v1/marketstatus/now` (7개 파일) | **거래소 시간표로 자체 판정** (휴장일 테이블만 관리) |
| 종목 기본정보(회사명 등) | `/v3/reference/tickers` (5개 파일) | 정적 데이터 — 무료 소스 또는 자체 테이블 |
| 시가/종가 | `/v1/open-close/*` (5개 파일) | 일봉 aggregates 로 대체 가능 |

→ **요구사항을 8종에서 5종으로 줄일 수 있음.** 대안 선택지가 넓어진다.

## C. 대안 공급사 판정 기준 (이 순서로 거른다)
1. **재배포(consumer 앱에서 최종 사용자에게 표시) 허용?** ← 여기서 대부분 탈락. 실패 시 즉시 제외
2. **옵션 체인 + 그릭스 제공?** ← 두 번째 관문. 앱 정체성이 걸림
3. 실시간 vs 15분 지연 — 지연 허용 시 라이선스 비용 급감 가능. 검토 대상
4. 가격 (목표: 월 $500 이하, 이상적으로 $200 이하)
5. 거래소 수수료(exchange fee) 별도 청구 여부

## D. 주의
- 마케팅 페이지의 "commercial use OK" 문구를 믿지 말 것. **ToS 원문 확인 필수.**
  massive 도 가입 시엔 문제없어 보였다.
- 계약 전 «모바일 앱에서 일반 사용자에게 표시» 를 명시적으로 문의하고 **서면 답변 확보**.
