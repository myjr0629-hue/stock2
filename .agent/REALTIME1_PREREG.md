# REALTIME-1 사전등록 (PREREG) — 실시간 오토 트레이딩 엔진

> 등록일 2026-07-18. **이 문서의 규칙은 동결(frozen)이다.** 수치·규칙 변경은 새 버전으로 재등록하고 그 시점부터의 실측만 새 버전 성적으로 집계한다 (검증 헌법 §42.3 — 인샘플 튜닝 금지). 가동 전 확정본.

## 0. 성격 — 쌍둥이 트랙

- **REALTIME-1은 데일리 페이퍼 트랙(signum-xs-paper)의 전략을 그대로 상속하고 실행 레이어만 실시간화한 병행 트랙이다.** 알파 규칙 변경 0건. 데일리 트랙은 종료하지 않고 대조군으로 계속 가동 — **두 트랙의 NAV 차이 = 실행비용(슬리피지·스프레드) 실측치.**
- **모드: PAPER 전용.** `scripts/ec2-auto-engine.js`에는 실주문 경로가 존재하지 않는다 (주문 POST 0건 — 구조적 차단). 실전 승격은 §5 게이트 + 운영자 승인 + 별도 커밋으로만.
- **인간 개입 수단: 킬스위치 하나** (`trade:killswitch`, 매 틱 검사). 종목·타이밍 개입 불가.
- 위치: 고정 IP EC2, pm2 `signum-auto-engine`. 토스 접근은 전부 로컬 실행기(8090) HMAC 경유 — **자체 토큰 발급 절대 금지** (클라이언트당 유효 토큰 1개 정책; 위반 시 수동 콘솔 토큰 무효화).

## 2.5 운영자 파라미터 (규칙 아님 — RT-1.0.1)

- **투입 자본**: `trade:auto:config.capital` ($100–$1,000,000) — 콘솔에서 설정, 엔진이 다음 틱에 적용. 입출금 델타만큼 킬 기준선(dayStartNav/weekStartNav/prevCloseNav)을 함께 이동시켜 **현금 이동이 -2%/-3% 스톱을 절대 격발하지 못하게** 한다. 인출은 가용 현금 한도(센트 내림)로 클램프, 잔여분은 포지션 청산에 따라 자동 소진. 성과 비교는 % 기준이므로 쌍둥이 대조 유효성 유지.

## 2.6 실전 적합성 레일 (C단계 실주문 전용 — 2026-08-07 사전등록)

> 성격: **알파 필터 아님, 체결 안전 레일.** 실측 근거 — 코호트 픽 일거래대금 중앙값 $633M·p10 $60M (선별이 자연히 대형주 쏠림), $1M 자본까지 슬롯이 일거래대금의 0.4% 미만.

- 조건 (전부 충족 시 적합): **현재가 ≥ $5 · 실시간 스프레드 ≤ 50bps · 시총 ≥ $500M · 호가/시세 존재**.
- **부적합 슬롯은 그날 현금 유지 — 차순위 재배분 금지** (페이퍼 트윈과 코호트 동일성 유지, 제외는 저널 기록).
- 관측상 통과율 100% (19/19픽) — 레일이 코호트를 재구성하지 않음을 확인. 통과율이 유의미하게 떨어지면 선별 유니버스 자체를 점검할 것 (레일 완화 금지).

## 2.7 자본 → 포트폴리오 구성 (C단계, 페이퍼 트윈 동일)

- **슬롯 = 자본/30** (센트 내림) · 일일 투입 = 당일 top10 ∩ 적합성 × 슬롯 · 3거래일 사다리로 정상상태 30슬롯.
- 주문 방식: **금액 지정 시장가 매수 (정규장 전용)** · 청산 = 소수점 시장가 매도 (정규장 전용 — 스펙 422 제약) · 데이마켓 제외 유지 (§3).
- 스톱/킬 (R1-R5)·자본 변경 기준선 이동 (§2.5) 실계좌 동일 적용.
- 실주문 활성화 = 게이트 3/3 + §4 조건 + **운영자 수동 스위치** (자동 활성화 없음). UI: 콘솔 개요 "실전 포트폴리오 플랜"이 이 스펙의 미리보기 (`/api/admin/trade/plan`).

## 3. v1 명시적 제외 (v2 후보 — 재등록 필요)

- **변동성 타게팅 사이징 (v2 최우선 후보)**: 균등가중 대신 역변동성(1/ATR14%) 가중 — 리서치 R8 (균등가중은 고변동 종목이 리스크를 지배). v1은 **섀도 계측만** (RT-1.0.2): 코호트 스테이징마다 균등 vs 역변동성 가중을 저널 기록(`shadow vol-sizing`) — 15일+ 축적 후 가상 성과 비교로 채택 판단 (병행 기록 — 인샘플 튜닝 아님). 실행 품질(체결/소멸/평균 스프레드bps)도 상태에 상시 노출.
- 장중 시그널 발명 금지 (틱/분봉 기반 자체 알파 없음 — XS는 일 단위).
- 종목별 스톱 (X2), 단일종목 GEX (OI-부호 추정 노이즈), 콜월/풋플로어 출구존, 맥스페인(근거 최약), 옵션·레버리지·공매도.
- **데이마켓(Blue Ocean ATS) 거래**: 토스는 4세션 ~23h50m 거래 지원 (스펙 실측: 캘린더 `dayMarket` 세션, 주문 API에 세션 파라미터 없음 — 서버가 시각으로 판정, 접수 불가 시 422 `order-hours-closed`+retryAfterAt). v1 엔진은 정규장 전용 유지 — BOATS 유동성 얇음(호가 깊이 제한·LP 소수), 2024-08-05 중단 사고 이력, 체결 사후 취소 사례. 확장 시 별도 재등록 + 유동성 가드 설계 필요. 참고: 금액 주문·소수점 시장가 매도는 정규장 전용(422 명문), LOC = LIMIT+CLS 지원.

## 4. 승격 게이트 (Stage B → C)

기존 3게이트 전부 + ①REALTIME-1 페이퍼 ≥15거래일 가동률·저널 무결 ②동기간 데일리 트랙 대비 비열위 ③실행비용(쌍둥이 NAV diff) 정량화. 추가로 Stage B 전 해결 필수: 킬 플래튼 최악 주문수(진입10+청산10+플래튼30=50) > 실행기 일 40건 캡 — 리스크-축소 예외 설계.

## 5. 검증 기록

- 2026-07-18 시뮬레이션 (scratchpad/sim-auto-engine.js, 실제 엔진 모듈 구동): **37 어서션 전부 통과** — 코호트 스테이징/신선도 fail-closed·10종목 NAV/30 진입·중복 차단·스프레드/저가 가드+lapse·**캘리브 정합 게이트(15일 미만 비무장, 이상 무장)**·감마 NEG 반로트·3거래일 창 청산·일중 -2% 북스톱+당일 잠금·주간 -3% 킬+월요일 자동 재가동·킬스위치 차단·코호트 스태킹(동일 종목 복수 로트)·데일리 트랙 halted 시 미스테이징·일일 리포트·주말 하트비트·**저널 ASCII 무결**.
- 시뮬레이션이 발견해 수정한 결함: 개장 직후 재시작 시 신규 코호트 스테이징 누락 → 진입창 중 갱신 추가.
