## 0. 소재는 감으로 고르지 않는다 — 깔때기를 돌린다

```bash
node scripts/market-wants.mjs us     # 또는 jp
```

4단으로 거른다. **점수는 정렬용이지 판정이 아니다** — 근거 수치를 항상 같이 본다.

| 단 | 무엇 | 왜 |
|---|---|---|
| ① 수요 | 검색 상위 쇼츠의 조회 중앙 | 사람이 실제로 보는 양 |
| ② **여지** | 상위권에서 **소형 채널(구독 10만↓)** 비중 | **수요가 커도 거대 채널이 독식하면 우리 자리가 없다** |
| ③ 신선도 | 최근 30일 상위작 비중 | 지금도 도는 소재인가 |
| ④ 실증 | 우리 데이터로 숫자를 만들 수 있는가 | 지어내지 않는다 (사람이 판단) |

### ⛔ 「수요」만 보면 틀린다 — 우리가 이미 틀렸다

| 소재 | 수요 | 여지 | **소형 채널 조회 중앙** |
|---|---|---|---|
| why gold is going up | 64,907 | 31% | **580** |
| mortgage rates explained | 69,035 | **88%** | **69,035** |

수요는 비슷한데 **소형 채널이 실제로 받는 조회가 119배 다르다.**
금은 거대 채널이 상위를 채우고 있어 신규가 들어가도 580회가 천장이다.
**2026-08-21 에 만든 GOLD821 이 바로 그 자리였다** — 조회 10회의 구조적 이유다.

## 2. 논조 — 다섯 줄로 고정

레퍼런스 실측(영어 7편 32만~84만회 · 일본 429편)에서 뽑은 «공통 문법»이다.

### ① 훅은 «반박»이거나 «질문»이다. 선언이 아니다

우리 과거 32편은 **100% 선언**이었다 — 그래서 「자료」로 들렸다.
레퍼런스는 3/7 이 반박·질문으로 연다.

```
✔  "Hold on. Gold is not at a record."          ← 반박
✔  "Are we going to enter a recession?"          ← 질문
✔  "Inflation this, inflation that. Babe, you
    are worried about the wrong thing."          ← 통념 반박
✗  "Micron closed up 6.23%."                     ← 선언 (우리 과거)
```

### ② 훅에 숫자를 넣지 않는다

레퍼런스 훅에는 숫자가 없다. **훅은 긴장을 만들고, 숫자는 근거로 뒤에 온다.**
말의 숫자 밀도: 레퍼런스 중앙 **1.0%**, 우리 과거 2.6%.

### ③ 숫자는 «말»이 아니라 «화면»이 나른다

조회 240만 편은 화면 텍스트행 밀도 **38%** 인데 말의 숫자는 1.0% 였다.
⇒ 자막은 긴장·해석, 카드가 수치.

### ④ 「너」에게 말한다

우리·너 비율: 레퍼런스 중앙 **3.9%**, 우리 과거 1.9%.
`Your option`, `the move you noticed`, `we measured` — 남 얘기로 들리면 안 넘어온다.

### ⑤ 닫을 때 권유하지 않는다 — 질문으로 닫는다

`"A record, or a rebound?"` — 컴플라이언스이자 리텐션(루프)이다.

## 3. 「떠먹여준다」의 실제 구조 — 8비트

레퍼런스 흐름을 우리 포맷에 맞춘 것이다. **유니크하게 가지 않는다.**

```
1 훅       반박|질문 · 숫자 없음 · <=12단어
2 통념     사람들이 믿는 것을 «먼저» 말해준다
3 반전     우리 데이터가 다르게 말하는 지점
4 근거     여기서 처음 숫자 — «화면»으로
5 메커니즘 왜 그런지 한 겹만
6 인사이트 우리가 «직접 계산»한 값 (게이트 필수 항목)
7 한계     과장하지 않는다. 반전을 유지한다
8 질문     권유가 아니라 질문으로 닫는다
```

각 비트는 `say`(단정) + `ask`(다음 비트로 미는 질문) 두 줄이다.
**`ask` 가 「떠먹여주는」 장치다** — 시청자가 스스로 궁금해할 것을 대신 물어준다.

## 4. 인사이트가 없으면 만들지 않는다

`scripts/insight-check.mjs` 가 막는다. 넷을 다 갖춰야 인사이트다.

| | |
|---|---|
| ① 우리가 «계산»한 수치 | 남의 발표 숫자를 옮긴 건 인사이트가 아니다 |
| ② 비교 기준 | 수준값만으로는 「드물다」를 못 말한다 |
| ③ n >= 20 | 소표본 결론 금지 |
| ④ p<0.05 또는 백분위 <=10/>=90 | 평범한 값은 인사이트가 아니다 |

그리고 **그 문장이 자막에 그대로 나와야 한다.**

`.agent/JP_MARKET.md` 429편 실측. 미국과 같은 틀을 쓰되 세 가지를 바꾼다.

| | 미국 | **일본** |
|---|---|---|
| 원하는 것 | 해석·메커니즘 | **실물·타이밍** (금괴·매입가·「지금 살 때인가」) |
| 제목 | Why/How 로 여는 선언 | **질문형** (`は上がり続けるか`) · **과거대비** (`年前は`) · **답 감추기** (`答えは○○○`) |
| 프레임 | 데이터 리포트 | **경고·판정** — 1위작(570만)이 「미국 주식은 위험한가」 |
| 길이 | 25~30초 | **21~40초** (61초↑는 1/222) |

**우리 색**: 엔 기준 환산. 실측해보니 금 1년 상승 **+45.9%(엔) vs +35.1%(달러)** —
**10.8%p 는 금이 오른 게 아니라 엔이 약해진 것**이다. 아무도 이걸 화면에 안 띄운다.
