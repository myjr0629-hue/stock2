## 0. 한 줄 정의 + Go/No-Go

**정의**: 초보자가 앱을 열어 *오늘 실제로 움직인 주식 1개*에 대해 "왜 움직였나?"를 8초 안에 찍으면, 우리 **move-attribution AI**가 그 직관을 채점하고 원인을 설명한다 — 오늘의 시세를 매일 30초짜리 **인과(因果) 수업**으로 바꾸는 **교육(Education) 카테고리** 앱.

**판정: GO (조건부)**
- **강한 근거(실측)**: 재사용 자산 전부 배포·검증됨(§5) → 신규 파이프라인 0, 만들 건 네이티브 퀴즈 셸 하나.
- **리스크(추정)**: 초보 금융교육 앱의 리텐션은 미증명(Zogo/Finny 무덤). 데이터 장벽은 넘었으나 "매일 돌아오는가"는 데이터로 해소 안 됨.
- **조건**: 성공 지표를 **매출이 아니라 리텐션(D1/D7/D30)**으로 정의. §8·§9 분리선 준수.

## 2. 핵심 학습 루프 (the "pull ladder")

**습관**: 찍는다 → 채점받는다 → 왜인지 이해한다. **매일 여는 이유**: 시장이 매일 새 실사례를 공짜 공급(정적 교육앱이 구조적으로 못 하는 콘텐츠 트레드밀).

**원자 단위 = "오늘의 무브"**: 오늘 **±2% 이상** 움직인 실제 종목 1개(우리 엔진이 이미 그 임계에서 발동 → 신규 파이프라인 0, 설명가능 원인 자기선별, 하루 수십 개라 안 마름, 난이도 조절 가능).

**풀 사다리 (전부 옵트인, 어느 단에서 나가도 완결감):**

| 단 | 탭 | 보이는 것 | 재사용 소스 | 시간 |
|---|---|---|---|---|
| 0. 추측 | 보기 4개 중 탭 | ✅/❌ + 한 줄 판정 | move-attribution | 8s |
| 1. 왜 (자동공개) | — | 2문장 평이 설명, **원인 카테고리 볼드** | Bedrock move-attribution | +15s |
| 2. 영수증 | "보여줘" | 실제 뉴스 헤드라인 / 8-K 태그 / GEX 리딩 | Polygon 뉴스·8-K·GEX | +20s |
| 3. 라이브로 | "See it live" | 실제 차트 + GEX/콜월/다크풀 패널(주석) | intel/guardian/command 라우트 | +45s |
| 4. 용어 학습 | 볼드 용어 탭 | 용어집 카드(ko/en/ja) | `metricGlossary.ts` | +20s |

**중앙값 세션 = 30초.** 8초 만에 나가도 **1단(왜)은 무조건 자동 노출** → "사실"이 아니라 **인과 프레임**을 심음.

**설계 규칙(하드)**: 1단 카피는 **항상 2문장 이하 + 원인 카테고리 볼드**. 그 볼드 단어 = 수업이자 4단 탭 타깃.

**예시 흐름(NVDA):**
> Q: NVDA 오늘 4.1% ↓ 왜? 🅐실적 🅑경쟁사뉴스 🅒감마매도 🅓애널하향
> 0: 🅐 탭 → ❌ "NVDA는 오늘 실적발표 안 함"
> 1(자동): "자기 뉴스가 아니라 경쟁사 헤드라인 + 딜러가 **숏 감마**에 물려 하락 증폭" (정답 🅑+🅒, 부분직관 보상)
> 2: 10:42 ET 실제 헤드라인 + "딜러 감마 종일 음(-)"
> 3: 헤드라인 핀 꽂힌 실제 차트 + 라이브 GEX 타임라인
> 4: "감마" 볼드 → 실제 gammaFlip 용어 카드

## 4. 원인 택소노미 + 오답보기 뱅크 (신규 작성)

**8개 원인 카테고리** (모든 무브가 여기 매핑, 레벨 게이팅):
1. 자기 실적 (own earnings)  2. 경쟁사/섹터 뉴스  3. 애널리스트 액션  4. 8-K 이벤트  5. **옵션 구조(감마/딜러 헤징)**  6. 섹터 로테이션  7. 내부자/기관 플로우  8. 매크로

**난이도 게이팅**: Level 1 = 1·2·3만. **옵션 구조(감마·다크풀)는 Level 3부터.** 커리큘럼은 실사례 난이도 태깅에서 *창발*(수동 저작 아님).
**오답보기 생성**: 정답 카테고리 + 그럴듯한 오답 3개를 카테고리 뱅크에서 추출(예: 실적 정답 → 오답은 애널/경쟁뉴스/감마).

## 7. 시장 위치 · 해자 · 위협

**2×2 (실데이터 × "왜" 설명)**: 우상단(실+왜) 중 **"라이트+초보+데일리+AdMob" 가격점이 비어있음**. Bloomberg(프로·고가)·Khan(타임리스≠타임리)·Zogo(정적)가 인접하나 안 무너짐.
**해자(정직 B–)**: 초보는 옵션·13-F 안 씀 → 그건 SIGNUM 해자지 이 앱 해자 아님. **이식가능 해자 2장 = ①move-attribution AI ②한계비용 0 트리링궐 콘텐츠 파이프라인.**
**최대 위협 = Robinhood**(실데이터·초보청중·Learn·CAC0·AI 전부 보유). **막아주는 유일한 것**: 브로커는 이해충돌·규제·단일언어로 **중립·비거래·트리링궐·관찰자 교육을 구조적으로 못 만듦** → **카테고리 분리 = 4.3 위생이 아니라 실제 경쟁 포지션.**

## 8. App Store Guideline 4.3 안전 (바이너리로 판정 — 필수 체크리스트)

> 카테고리·관객이 달라도 **"URL만 다른 WebView 껍데기"면 리젝**. 기존 2앱이 빈 `<body>` 원격 웹뷰라 특히 조심.

**바이너리에 반드시:**
1. ☑ 네이티브 퀴즈 UI (기존 `app-view/*` DOM 재사용 금지 — 리뷰어가 Web Inspector로 `app-view/dash` 보면 실패)
2. ☑ 구조적으로 다른 IA (파이낸스=5탭 터미널 / 본앱=퀴즈 우선: 오늘의퀴즈→정답→WHY→스트릭→용어집)
3. ☑ 앱 소유 로컬 상태 (스트릭·이력·점수 온디바이스 → 오프라인 "어제 복습" 가능)
4. ☑ 자체 온보딩 (파이낸스 `AppFirstRunOnboarding` 재사용 금지)
5. ☑ 별도 번들ID·아이콘·이름·스크린샷·비중복 키워드
6. ☑ 용어집·퀴즈뱅크를 앱 1급 콘텐츠로 서빙

**로드베어링 규칙: "같은 뇌(데이터·AI 재사용), 다른 얼굴(프레젠테이션 신규)." 데이터 파이프라인은 재사용(안 보임), 프레젠테이션 레이어는 재사용 금지.**
**제출 전략**: SIGNUM·UC 2개가 동시 심사 중일 때 제출 금지(배치 제출=트리거). 앞 2개 안착 후 수주 뒤.

## 9. 컴플라이언스 (투자자문 회피 — 종교적 준수)

**선(線)**: 과거/현재 설명 = 교육 ✅ / 전방·행동유발 = 자문 ❌. "왜 오늘 +3% 움직였나" = 안전 / "내일 오를까·사야 하나" = 금지.
**베이크인 규칙:**
- (a) 모든 AI 출력은 컴플라이언스 필터 통과 후 퀴즈 도달
- (b) 정답은 "신호"가 아닌 "원인/관찰"("~와 시점이 일치했다")
- (c) 결과 화면 트리링궐 디스클레이머 상시
- (d) **포트폴리오·예측추적·페이퍼트레이딩 P&L 금지** (스트릭은 *학습일*을 셈, *정답 콜* 아님)
- (e) AI는 판단 아닌 인용, (f) 연령 17+
**자기유발 실패 3금지**: 예측 게임 메카닉 / 트랙레코드 기능 / 필터 우회. 이 셋만 막으면 SIGNUM보다 깨끗.

## 10. 사업성 (AdMob)

- **배너/인터스티셜 = 무승부**: 교육 eCPM(~$4–8 US)은 파이낸스의 40–50%, 청중 KR/JP 편중으로 더 낮음. **파이낸스 RPM으로 모델링 금지.**
- **진짜 엔진 = 리워드 영상**(US ~$10–15+, 옵트인이라 리텐션 무해): "깊은 WHY 언락", "추가 퀴즈"(무료 N개/일 → 희소성).
- **하드 금지**: 퀴즈 *정답 사실 자체*를 리워드 뒤에 가두지 말 것(다크패턴+컴플 약화). 가두는 건 **깊이·수량**뿐. 콜드오픈 인터스티셜 금지(D1 사살). 인터스티셜=퀴즈 완료 후 세션당 1회.

## 11. 선행 확인 2건 (착수 전 — 미검증)

1. **Polygon/Massive 소비자 재배포·display 조항**: 본앱은 **원시 피드 재판매 아님 + 100% 가공물(퀴즈·AI해설)** → 표준상 허용 방향(사용자 확인: 최고티어). **가공물 = 표준 허용**이라 사실상 통과 예상이나, 사업 관문이므로 문구 1회 확인 권장.
2. **실제 데이터 월 청구액**: AdMob 자립 판정용. 단, **데이터비는 SIGNUM 때문에 이미 매몰** → 스핀오프 AdMob은 순수 증분 회수라 재무적으로 유리.

## 12. MVP 컷라인 + 페이즈

**MVP (Phase 1)**: 플래그십 무브-어트리뷰션 카드 + 0~1단(추측·왜) + 스트릭 1개 + 용어집 탭.
**Phase 2**: 2~4단 깊이 패널(영수증·라이브·용어) + 캘리브레이션 스파이더 + 개념 컬렉션 + 위클리 리캡(Remotion).
**Phase 3**: 개인화(약한 카테고리 공급) + IAP(광고제거/무제한 퀴즈).

## 13. 기술 스택 (기존과 동일 재사용)

- **프론트**: Capacitor(iOS/Android) + 네이티브 퀴즈 화면(신규). 데이터는 `signumhq.com` API 라우트 경유(소스 은닉 유지: cron→Redis→API route).
- **개발 환경**: **iOS 빌드·시뮬레이터·심사 = 맥 전용**. 로직·구조 코드는 git 공유(PC/맥 병행). 배포 전 항상 `git fetch`→rebase.
- **데이터 은닉**: 앱은 우리 API만 호출, Polygon 직접 호출 0(보안+해자).

## 15. 가장 큰 리스크 (정직하게)

**리텐션은 미증명 축이고 데이터가 그걸 못 없앤다.** 방어 = 원인 설명 자체가 아니라 **습관 루프·큐레이션 페다고지·트리링궐 신선도**. 프론티어 LLM이 "왜"를 공짜 상품화하기 전에 **습관을 먼저 지어야** 함.
