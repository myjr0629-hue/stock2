## 1. 찾은 것 — 에러 없이 틀리던 것들

### ① 티커 SEO 페이지가 모든 종목을 「기관 매도」로 표기 ★가장 심각
```js
const dp = inst?.darkPool?.percent || 0;                 // 항상 0
const instLabel = dp > 40 ? 'ACCUMULATION'
                : dp < 20 ? 'DISTRIBUTION' : 'NEUTRAL';  // 0 < 20 → 전 종목 DISTRIBUTION
```
없는 데이터가 «그럴듯한 약세 주장»으로 위장돼 **SSR HTML 에 박혀 나가고** 있었다.
구글이 그 상태로 색인한다. → 판정하지 않도록 수정.

### ② 가디언 섹터 IFS 가 전 섹터 −12점
`dpScore = (avgDP - 30) * 2` 에서 `avgDP` 가 영구 0 → −60 고정 → 가중치 0.2 →
**모든 섹터에 −12점이 무조건 더해졌다.** divergence 판정과 stealthAlert 서사가 이 값을 쓴다.
→ 다크풀 항을 빼고 남은 가중치를 재정규화 (0.4/0.3/0.1 ÷ 0.8).

### ③ 고래지수가 30~70 안에 갇혀 있었다
활동도 분모가 75 고정인데 세 축(GEX·다크풀·블록딜) 중 둘이 영구 0 →
최대 25/75 → 배수가 0.6~0.9 밖으로 못 나가 **극단값이 영영 안 나온다.**
→ 분모를 «가용 축의 합»으로. 있는 정보로 0~100 전 구간을 쓴다.

### ④ 죽은 다크풀이 캐시에 「살아 있는 숫자」로 남아 있었다
```
XLE DP=67  XLV DP=71  XLF DP=41  XLRE DP=65 …  15개 섹터 전부
```
2026-08-28 권한 상실 **이전에 굳어진** 값이고 앞으로 영원히 변하지 않는다.
「200 OK 인데 어제 값」보다 나쁘다 — **영원히 어제 값**이다.
캐시를 비워도 하베스트 Lambda 가 다시 채운다 → **읽는 쪽 한 곳**(`applyXs`)에서 잘라냈다.

### ⑤ RVOL 이 밤·주말 내내 「거래량 저조」라고 단언
```
토요일 01:40 ET →  { rvol: 0, status: "PRE_MARKET" }   ← 토요일인데 «장 전»
```
화면이 `rvol > 1.0 ? 보통 : 저조` 로 읽어 게이지에 「저조」가 상시 표시됐다.
→ 주말 인식 추가 + 미측정은 **null**. 기본값 1.0 도 제거(«평소만큼 거래됨»이라는 거짓말).

### ⑥ flow-harvest 가 배포될 때마다 자기 API 키를 지우고 있었다 ★파급 최대
```
CloudWatch · 2026-08-28 정규장 전 구간
    [shard-0] Universe complete: 0/501 in 1s (fail=501)   ← 종목당 1~2ms
```
`deploy-flow-harvest.js` 가 Environment 에 4개짜리 객체를 그대로 보냈다.
Lambda 의 Environment 는 **전체 치환**이라 `INTRINIO_API_KEY` 가 매번 삭제됐다.
(6개 Lambda 중 `signum-flow-harvest` 만 키가 없었다)
게다가 배포 스크립트가 PowerShell 전용이라 macOS 에선 실행조차 안 됐다.

**피해**
```
GEX 이력 정지:  NVDA/AAPL 2026-08-19 (9일)   SPY 2026-08-10 (19일)
→ GEX 타임라인이 옛 데이터로 그려지고
   /api/flow/enhanced-metrics 는 UOA·스마트머니 전 필드 null (sampleSize 0)
```
**수정 후 실측: `ok=119 fail=1 · 10초`** (직전 `ok=0 fail=501`)

### ⑦ 벤더 벌크가 T+1 — 금요일 마감 후 30시간 시장지표 공백
```
토요일 실측:  intrinio:eod:snapshot 최신 거래일 = 2026-08-27  ← 금요일이 없다
```
EC2 적재기는 정상이었고 **벤더 게시가 늦은 것**이다. 시간외에는 호가 스프레드
1% 게이트를 13,064 중 1,212 만 통과해 대부분 종목이 탈락한다. 그 결과
Market Breadth 0↑0↓, 가디언 섹터 16개 중 **9개가 구성종목 0개**(에너지·금융·헬스케어…).

- **즉시**: `DIRECT_BACKFILL_MAX` 30 → 150. 요청이 30종목을 넘는다는 이유로 개별 보완을
  아예 건너뛰고 있었다. → 배포 후 실측 **구성종목 0개 섹터: 없음**
- **근본**: `scripts/intrinio-session-close.js` — 15:57 ET 에 우리가 직접 종가를 확보한다.
  마감 «직전»인 이유: Startup 플랜은 TRADE PRICE 가 비어 있어 호가 미드에 의존하는데,
  미드는 스프레드가 좁은 정규장에만 가격 대용이 된다.
  (검증: 시간외 실행 → 유효 103종목 → 게이트가 적재 거부. 의도대로 동작)

|---|---|---|
| **ATR** | 7.663 (3.52%) | 실현 변동폭. 지금은 IV 기반 «예상 변동폭»뿐이었다 |
| **ADX +DI/−DI** | 16.84 (26.59/21.55) → RANGE | TREND PHASE 는 SMA 교차만 봐서 «추세가 있나»를 못 말한다. ADX<20 구간의 골든크로스는 대부분 무의미 → **신뢰도 게이트** |

### 합성 지표 (우리만 가능)

**변동성 프리미엄 (IV − RV)** — NVDA: IV 36 vs RV 43.3 → **−7.3 (FAIR)**
ATM IV 는 옵션 체인, RV 는 20일 종가 로그수익률 표준편차의 연율화.
방향이 아니라 **옵션 가격의 적정성**을 말한다. 둘 다 가진 서비스는 드물다.
> ⚠️ RV 를 ATR 로 근사하지 **않았다.** ATR 은 갭을 포함해 종가 기준보다 체계적으로 크고,
> 그러면 «비싸다/싸다» 판정이 통째로 밀린다.

**볼린저 스퀴즈** — 밴드폭을 자기 130일 분포와 비교한 백분위. NVDA 12 → **SQUEEZE**
→ **공매도 403 으로 죽어 있던 「SHORT SQUEEZE」 카드를 이걸로 되살렸다.**
  그 카드는 값 «-» · 배지 «LOW» 로 떠 있었는데, 「LOW」는 «공매도 압력이 낮다»는
  사실 주장이다. 실은 재지 않았을 뿐이다. 라벨(변동성 압축)·팝업 설명 ko/en/ja 전면 교체.
  설명에 «방향은 알려주지 않는다»를 명시했다 — 압축은 폭발의 전조일 뿐이다.

### 매크로 새 축 — 신용 스프레드

기존 축은 NQ·VIX·US10Y·DXY·TLT·GLD 로 **전부 주식 아니면 금리**였다.
`$BAMLH0A0HYM2` (BofA HY Master II OAS) 실측: `08-27 2.63 · 08-26 2.67 · 08-25 2.70`
> ⚠️ 이 계열은 앞선 조사에서 «갱신 150일 지연»으로 분류해 안 쓰고 있었다 — **오판이었다.**
> 문서가 아니라 호출로 판정할 것.

TIGHTENING(위험선호) / STABLE / WIDENING(위험회피) + 20일 변화 + 1년 백분위.
**주가는 오르는데 스프레드가 벌어지면 신용시장이 그 상승을 확인해 주지 않는 것** —
가디언 다이버전스의 새 축이 된다.

## 5. 이번에 얻은 판정 규칙 (다음에도 쓸 것)

1. **0 과 «없음»을 절대 섞지 않는다.** 0 은 «재 봤더니 0» 이라는 주장이다.
   이번 6건 중 5건의 뿌리가 이것이었다.
2. **문서가 아니라 호출로 판정한다.** `indices/economic` 을 «갱신 느림»으로 잘못 분류해
   두 번이나 안 쓰고 지나쳤다.
3. **파생 지표는 입력이 사라지면 가중치를 재정규화한다.** 안 그러면 지표가
   조용히 한쪽으로 밀리거나(IFS −12) 범위가 잘린다(고래지수 30~70).
4. **배포 스크립트의 env 는 병합이다.** 전체 치환하면 다른 스크립트가 넣은 키가 지워진다.
5. **«비어 있는 곳» 스캐너를 상시로 둔다.** `scripts/audit-empty-fields.js` —
   면제 목록(못 재는 게 맞다고 확인된 것)을 코드로 들고 있어, 거기 없는데 비어 있으면
   그 자체로 버그다. 이번 ⑥번도 이걸로 찾았다.
