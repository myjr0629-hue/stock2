## 4. 아직 없는 것 — 정직하게

- **OPRA 체결 데이터**(옵션 거래량·체결가·체결규모·이상거래) — Enterprise 상품.
  `options/chain/.../realtime` · `unusual_activity` → **403**.
  화면에는 `dataFreshness.volume/premium = 'EOD'` 로 **정직하게 표기**돼 있다.
- **옵션 WS 클라이언트** — 서버는 3,100만 건 수신 중이나 **구독을 보내는 화면이 없다.**
  개별 계약 가격을 표시하는 UI 가 생기면 그때 붙인다. 같은 FMV 를 REST 가 이미 준다.
