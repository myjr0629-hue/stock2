## 1. ⛔ 교체 전에 반드시 고쳐야 하는 것 — 내가 만든 구멍

**9차 게이트에 구독 진입점이 없다.**

기존 `ValueWall` 은 `IAP_LIVE` 가 켜지면 광고 CTA 아래에
`proCta`(SIGNUM Pro · 광고 없이 보기) + `proRestore`(구매 복원) 를 그린다.
9차 게이트를 시안대로 다시 만들면서 **그 블록을 안 옮겼다.**

```
지금 페이월이 열리는 곳 :  설정 · ValueWall(cmd·flow·가디언)
9차 대시보드 게이트      :  ⛔ 없음 — 광고 CTA 뿐
```

`IAP_LIVE=true` 로 켜는 순간 **대시보드만 구독 버튼이 없는 화면**이 된다.
게다가 대시보드는 앱의 **첫 화면**이고, 게이트는 「광고가 실제로 방해한 자리」라
`.agent/SUBSCRIPTION-STATUS.md` 가 «전환이 일어나는 자리» 로 지목한 곳이다.

→ 교체 전에 e9Gate 에 `proCta` + `proRestore` 를 시안 톤으로 복원해야 한다.

## 3. 디자인 일관성 — 「뚱뚱함」을 숫자로

기준: 상자 높이 − 실제 내용 높이 = **빈 공간**. 390px 실측.

| 화면 | 만든 방식 | 카드 패딩 | 행/카드 빈 공간 | 최대 글자 | 판정 |
|---|---|---|---|---|---|
| **9차** (dash·히트맵·랭킹·실적·무버) | CSS 모듈 `e9/hm/rk/ec/mv` | 9~12px | **0** | 19px | 기준 |
| **설정** | CSS 모듈 `settings` | 14×16px | **29px — 행의 절반** | 17px | ⚠️ 가장 뚱뚱 |
| **커맨드** | CSS 모듈 `cmd` | **16px** | **34px** | **32px** | ⚠️ 카드가 큼 |
| **가디언** | **Tailwind 인라인** | 10px | 22px | **30px** | 밀도는 OK · 체계가 다름 |
| 플로우 · 인텔 | Tailwind 인라인 | — | — | — | 미측정(4.7k·5.9k줄) |

읽어낸 것:
1. **설정이 가장 심하다** — 아이콘 44px 상자 + 상하 14px 패딩으로 한 행이 **59~61px**,
   내용은 **30px**. 절반이 빈칸이다. 9차 같은 성격의 행은 32~34px 이다.
2. **커맨드는 카드 패딩이 16px** — 9차의 1.5배. 글자도 32px 까지 올라간다.
3. **가디언은 밀도 자체는 괜찮다**(패딩 10px). 다만 **Tailwind 인라인**이라 9차의
   CSS 모듈 체계와 «만드는 방법»이 다르다. 색·성격은 페이지마다 달라도 되지만,
   토큰(패딩·모서리·글자 단계)이 공유되지 않으면 일관성을 유지할 방법이 없다.
4. 모서리 반경이 화면마다 제각각이다(커맨드만 9·10·14·999·50% 혼재).

## 4. 권고 — 「대시보드 단독」도, 「전부 다」도 아니다

되돌릴 수 있는 배포이므로 **단계적으로 올린다.** 다만 대시보드 «단독»은 아니다.

### 1차 (교체와 같이 나가야 함)
1. **9차 게이트에 구독 진입점 복원** — §1. 안 하면 IAP 켤 때 첫 화면만 구멍
2. **설정 행 높이만 축소** — 대시보드 헤더의 유일한 버튼(톱니)이 설정으로 간다.
   새 화면에서 **한 번 탭이면 닿는 화면**이라 이음매가 바로 보인다.
   구조·색은 그대로 두고 «행 높이/아이콘 크기»만 내용에 맞춘다.

### 2차 (교체 뒤, 순서대로)
3. **커맨드** — 카드 패딩 16→12, 글자 단계 정리 (탭바로 가는 화면 중 가장 많이 쓰임)
4. **플로우 · 인텔** — 측정 후 같은 기준
5. **가디언** — 밀도는 이미 괜찮다. 손댄다면 «토큰 공유» 목적이지 급하지 않다

### 왜 이 순서인가
- 대시보드는 **첫 화면**이라 먼저 좋아지는 효과가 가장 크다
- 설정은 대시보드에서 **한 탭** 거리라 같이 가야 이음매가 안 보인다
- 커맨드·플로우·인텔·가디언은 **탭바를 눌러 들어가는** 화면이라 한 박자 뒤여도 티가 덜 난다
- 전부 고치고 한 번에 올리면 그동안 대시보드 개선이 **사용자에게 0** 이다

### 안 할 것
- 색·성격 통일 (대표 지시: 페이지 성격대로 두는 게 맞다)
- 가디언 갈아엎기 (밀도 문제가 아니다)
