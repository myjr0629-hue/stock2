## ⛔ 발주할 때 지켜야 할 3가지

### ① 「상태」가 아니라 「변화」를 담는다 — 가장 중요하다

우리 인사이트는 **언제나 「A와 B의 관계가 바뀌었다」** 이다. 클립도 **앞 → 전환 → 뒤** 가 있어야 한다.

| | |
|---|---|
| ✔ | 금괴·비트코인이 **경쟁하며 달리다 → 악수 → 함께 걸어감** (`gold-btc-race`) |
| △ | 황소와 곰이 **계속 대치만** 함 — 전환이 없어 한 번밖에 못 쓴다 |

전환이 있으면 `startFrom` 으로 **앞 장면과 뒤 장면을 따로 쓴다. 한 클립이 두 비트를 먹여살린다.**

### ② 화면 안에 「읽히는 숫자·글자」를 넣지 않는다

`ani-bull-bear` 모니터에 `BEOC 93.0%`, `GUTS.483` 같은 **깨진 가짜 수치**가 보인다.
우리 무기는 «직접 계산한 진짜 숫자»다. 배경의 가짜 숫자가 그 무기를 무디게 한다.
→ 모니터·차트는 **글자 없는 추상적인 선·막대**로만.

### ③ 실제 기업 상표를 쓰지 않는다

`ani-surf-megacap` 의 은색 캐릭터 머리가 **애플 로고(잎 달린 사과)** 로 읽힌다.
→ 색·형태로만 구분(은/초록/파랑). **티커 이름은 우리가 자막으로 붙인다.**

### ④ 규격
```
길이   8~12초        컷   내부 전환 1회 이내
밝기   130 이상 선호   해상도  720x1280 그대로 주셔도 된다 (우리가 업스케일)
주인공 화면 «가운데»에 — 우하단 20% 는 워터마크 크롭으로 잘려나간다
```
