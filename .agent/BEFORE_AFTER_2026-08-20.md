## 0. 왜 이 표가 필요했나

조사는 했는데 **개념편에만 적용하고 브리핑 템플릿은 감사하지 않았다.**
게이트를 만들어 돌리자 3편 전부에서 위반이 나왔다 — 그중 두 개는
**우리 채널에서 유일하게 살아남은 신호(첫컷↔지속률 −0.90)** 를 어긴 것이었다.

그래서 이제 문서가 아니라 **업로드 경로**에 규격을 박았다.
`yt-upload.mjs` 가 `shorts-gate.mjs` 를 자동 호출하고, 불통과면 업로드가 멈춘다.

## 2. 구조를 바꾼 것 — «다시 만들지 않는다»

### 끝 장면을 고정 자산으로 (대표 지시)

```
전:  영상마다 CtaBlock 을 다시 조립           → 매번 레이아웃이 깨졌다
후:  src/remotion/kit/Outro.tsx  →  public/shorts/outro/outro.mp4
     브리핑·개념편이 그 «클립»을 튼다. 외부 영상엔 ffmpeg concat 으로 붙는다
```

- 폰 폭 **290 → 400** ("공간은 많은데 너무 작자나")
- 지표 칩 4개가 **한 줄** (전에는 wrap 되어 2개만 보였다)
- 고칠 곳이 **한 파일** — 다시 구우면 모든 영상에 반영

### 자막을 «한 슬롯, 한 줄» 로

```
전:  say 상자 + 그 아래 ask 상자 = 두 상자가 쌓임 → say 가 52~65% 로 밀렸다
후:  같은 자리에서 교차 페이드 (18프레임)
     레퍼런스 9편 전부 «한 번에 한 줄» 이다
```

### 티커를 상단으로

```
전:  하단 y1400~1458 → 자막을 밴드로 내리자 ask 문구가 티커에 잘렸다 (프레임 확인)
후:  상단 y152. 레퍼런스 3계급 어디에도 하단 스크롤 티커는 없다
```

### 아웃트로 겹침·소멸

```
전:  <Sequence from={hookF}> 에 durationInFrames 가 없어 마스트헤드가 «끝까지» 그려짐
     → 아웃트로의 SIGNUM HQ 를 덮었다
     루프백이 CTA 를 통째로 덮어 «나왔다 사라짐»
후:  CTA 시작에서 배너 종료 + 루프백에 폰 목업 + FREE 유지
```

## 6. 다음부터 이 사고가 안 나는 이유

```bash
node scripts/yt-upload.mjs .agent/plans/YYYY-MM-DD.json
  → 내부에서 shorts-gate.mjs 를 호출
  → 17항목 중 하나라도 어기면 «업로드 중단»
```

스킬에도 `SKILL.md §8-B` 로 등재하고 `references/gate.md` 에 전체 표와 측정 함정을 남겼다.
**게이트 숫자를 통과시키려고 낮추지 않는다 — 바꾸려면 새 실측이 있어야 한다.**
