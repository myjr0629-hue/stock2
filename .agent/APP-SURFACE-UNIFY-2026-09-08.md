# 앱 표면 통일 — 가디언·플로우·인텔 (2026-09-08)

대표 지시:
> 작업안한 나머지 페이지 가디언 플로우 인텔 도 모두 작업해놔 성격에 맞게
> 그리고 페이지안의 모든 페이지를 완벽하게 만들어

그리고 앞선 지시:
> 그렇다고 모든 페이지가 일관된색상을 유지하는것은 싫다 분명 그 페이지에 맞는 테마는 있어야 된다

**공유하는 것은 «색»이 아니라 «방식»이다.** 이 문서는 그 방식을 적는다.

## 1. «떠 있다»의 원인은 셋이었다

대시보드 카드가 세련돼 보인 이유를 역산하니 세 가지였다.

| # | 원인 | 대시보드 | 나머지 페이지(전) |
|---|---|---|---|
| 1 | 테두리 | 없음 | `border-slate-800` 등 중립 1px |
| 2 | 바깥 그림자 | 없음 | `0 4~22px 24~52px rgba(0,0,0,.24~.4)` |
| 3 | 윤곽 | `inset 0 1px 0 rgba(255,255,255,.055)` | 없음 |

테두리와 검정 그림자는 카드를 «페이지 위에 얹힌 판»으로 만든다.
상단 안쪽 빛선은 같은 카드를 «페이지에서 솟아오른 면»으로 만든다.
대표가 「페이지에 녹아든다」고 한 것이 이것이다.

## 2. 사례가 아니라 «종류»를 고쳤다

컴포넌트를 하나씩 고치면 반드시 빠진다. 실제로 첫 시도에서 5곳을 빠뜨렸다.

`src/styles/app-view.css` 끝에 앱 전역 규칙을 넣었다:

```css
.app-main [class*="rounded-lg"][class*="border-slate-"], …(lg|xl|2xl|3xl × slate|white)
{ border-color: transparent; }
.app-main [class*="rounded-xl"][class*="border-slate-"], …
{ box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.055); }
```

`.app-card`(인텔·플로우 34곳)도 같은 처리를 했다. 테두리는 **투명으로 두고**
지우지 않는다 — 박스모델을 유지해야 1px 도 밀리지 않는다.

### ★ 클래스를 고쳐도 인라인이 남으면 화면은 안 고쳐진다
인텔 섹터 상세 히어로는 `.app-card` 클래스를 쓰면서 인라인으로
`boxShadow: '0 8px 32px 0 rgba(0,0,0,.4)'` 를 덮어쓰고 있었다.
**소스 grep 이 아니라 화면 실측으로만 잡혔다.**

## 3. 남긴 것 — 이것이 «성격»이다

| 남긴 것 | 왜 |
|---|---|
| 섹터색 테두리·글로우 (인텔 26곳) | 섹터마다 다른 색이 인텔의 정체다 |
| 보라·시안·인디고 테두리 (플로우) | 콜/풋·감마 의미색 |
| 앰버 링·글로우 (ValueWall) | 잠긴 프리미엄 면임을 알리는 신호 |
| 팝오버·툴팁·모달의 그림자 | **떠 있어야 하는 것은 떠 있어야 한다** |
| 점·핸들·아이콘원의 그림자 | 카드가 아니다 |

검출기가 카드와 팝오버를 가르는 기준: `position: absolute|fixed` 면 제외.

## 4. 라벨 3단

같은 slate 한 계열인데 **알파만 .62~1.0 으로 흩어져** 라벨색이
가디언 27 · 플로우 29 · 인텔 14가지였다. 역할 토큰 셋으로 수렴시켰다(41곳).

```css
--app-lbl-signal: rgba(226, 232, 240, 0.92);  /* 값·주도 라벨 */
--app-lbl-anchor: rgba(148, 163, 184, 0.90);  /* 지표 이름 */
--app-lbl-aux:    rgba(148, 163, 184, 0.62);  /* 단위·시각·부연 */
```

결과: 가디언 14 · 플로우 13 · 인텔 11.
**목표는 «3»이 아니라 «대표가 승인한 화면과 같은 대역»이다** — 대시보드 9 · 커맨드 12.
의미색(초록·빨강·섹터색)은 이 사다리에 넣지 않는다.

## 6. 이번에 또 밟은 함정

1. **프리뷰 URL 을 SHA 로 확인하지 않았다.** `vercel ls --meta githubCommitRef` 의
   첫 Ready 를 잡았더니 15분 전 배포였고, 이미 고친 것이 «안 고쳐졌다»고 나왔다.
   → `--meta githubCommitSha=$(git rev-parse HEAD)` 로만 확인할 것.
2. **정규식이 두 번 좁았다.** `8px 32px rgba(0` 은 `8px 32px 0 rgba(0` 을 못 잡고,
   `[locale]` 은 glob 문자클래스로 먹혀 검사 파일이 0개였다.
   → 패턴이 아니라 «의미»로 검출하고, 결과 건수를 먼저 의심할 것.
3. **소스 grep 은 62곳을 신고했지만 화면은 1곳이었다.** 모달·툴팁·버튼이
   전부 오검출. 정본은 화면이다. [[verify-at-the-screen-not-the-layer]]
