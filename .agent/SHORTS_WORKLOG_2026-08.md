### 1-A. 반복된 버그 — 다섯 번 되살아난 앱 화면 잘림
```
top: `${-focus.y * scale * 100}%`      ← 틀림
```
CSS `top`의 `%`는 **컨테이너 높이** 기준이지 이미지 높이가 아니다. 컨테이너 520px /
이미지 2400px 이면 0.3을 줘도 이미지의 30%가 아니라 156px만 움직인다.
→ **원인은 코드가 아니라 «복사»였다.** 컴포지션을 새로 만들 때마다 옛 코드가 따라왔다.
→ 해결: `components/AppShot.tsx` **한 곳**으로 추출. 픽셀 계산. 앞으로 이것만 쓴다.

### 1-B. 게이트가 레퍼런스를 떨어뜨린 사건
「장면 간 밝기 편차(spread) 상한」으로 만들었더니 **레퍼런스 영상 자체가 FAIL**(spread 220).
→ 전역 편차가 아니라 **인접 컷 급변 횟수**로 교체. 레퍼런스 PASS(1회) / 내 V1 FAIL(6회).
→ 교훈: **기준을 만들면 반드시 «좋은 것»에 먼저 걸어본다.**

### 1-C. 자막이 말을 잘라먹던 버그
`wrap()`이 2줄 초과분을 `slice`로 버려 `day range` → `day`.
→ **자르지 않는다.** 줄 수가 넘치면 `sizeFor()`로 폰트를 줄여 문장을 살린다.

## 4. 대표 지적 사항 (2026-08-06) — 미해결 5건

### ① 배경화면 — 뉴스면 뉴스 이미지여야 한다
현재: AI 생성 broll **8~16장 회전**. 역할 매핑은 됐지만 **소재가 부족**하고
「뉴스 이야기」에 실사 뉴스 이미지가 하나도 없다.

**계획 (3층 구조)**
| 층 | 소재 | 라이선스 | 비고 |
|---|---|---|---|
| A. 실사 배경 | Pexels / Unsplash API | 무료·상업이용 가능 | **키 발급 필요(대표)**, API 호출 → 로컬 캐시 |
| B. 기업·제품 | 우리 로고 프록시 + 공개 IR 이미지 | 상표는 «보도적 사용» 범위 | 로고 위 문구 주의 |
| C. 데이터 실사 | 우리 앱 실화면 · 차트 렌더 | 자체 자산 | 가장 안전하고 가장 «우리다움» |
> ⚠️ **언론사 기사 사진은 쓰지 않는다.** OG 이미지 긁어쓰기는 저작권 위험.
> 출처 표기로 해결되지 않는다. → 대신 **헤드라인 텍스트 + 매체명 + 시각**을
> `source` 블록으로 «인용»하고 배경은 A/B/C에서 고른다.

### ② 음성·자막·이미지가 «모두» 인사이트를 줘야 한다
현재: `say` → 자막/음성은 일치. 하지만 **시각 블록은 따로 손으로 채운다.**
**계획**: `beat` 안에서 파생되도록 한 단계 더 묶는다.
```
say  →  자막 · 음성 · 노출시간
role →  배경
fact →  시각 블록(숫자·행·로고)  ← say와 «같은 사실»에서 파생, 중복 아님
```
원칙: **자막이 말한 것을 화면이 반복하지 않는다. 화면은 «증거»를 댄다.**

### ③ ElevenLabs 음성 + Higgsfield 앱 홍보영상
- ElevenLabs: `beat.say` 배열 → TTS → 오디오 트랙 + **실제 낭독 길이로 컷 재조정**
  (지금은 글자수 추정치. 실측 길이가 오면 그게 정답이 된다)
- Higgsfield: 앱 홍보영상 1편. 소재는 **실앱 캡처**(§⑤ 선결)
- 🔑 **키는 대표가 `.env.local` / Vercel 환경변수에 직접 넣는다. 채팅에 붙여넣지 않는다.**

### ④ 대본 고도화 — 4단 파이프라인
```
뉴스(사실)  →  설명(왜 중요한가)  →  전문뉴스·리서치 인용(권위)  →  우리 자원 해석(우리만)
```
현재 T1은 ①②④만 있다. **③ 인용 슬롯이 없다.**
**계획**: `source` 블록을 정식 비트로 승격 — 매체명·시각·헤드라인 + (있으면) 애널리스트 목표가·투자의견.
컴플라이언스: **인용은 «남의 의견»으로 명시**. 우리 의견으로 섞지 않는다.

### ⑤ 앱 스크린샷 부정확 + 빨간 박스의 의미 불명 🔴 **최우선**
- 실측: 04번 컷에서 카드 상단이 어중간하게 잘리고, **빨간 박스가 `GAMMA FLIP $850.00`
  값 글자를 덮어** 오히려 안 읽힌다.
- **빨간 박스는 «여기를 보라»는 뜻인데, 영상 어디에도 그 설명이 없다.**
  → 설명 없는 강조는 노이즈다.
- **계획**
  1. 박스는 **값을 덮지 않는다** — 타일 «바깥»에 여백을 두고 감싼다
  2. 박스에는 **반드시 라벨이 붙는다** (`← GAMMA FLIP $850`), 없으면 박스도 없앤다
  3. 앱 캡처는 **비트가 말하는 수치가 화면에 실제로 보이는 프레이밍**으로만 자른다
  4. `SHOT_PRESET`에 «검증된 프레이밍»만 등록하고 즉석 좌표 금지
