## 0. 왜 이 문서가 필요한가 (핵심 진단)

- **1000트윗 참사의 진짜 병 = 콜드스타트(관객 0).** 자동 발행을 아무리 잘해도, **밀어줄 초기 반응이 없으면 알고리즘이 도달을 안 줌.** (자동화 문서 §2.1 TweepCred<65 = For-You 후보 3개 제한과 같은 수학.)
- ∴ **오가닉 소셜 자동화(자동화 문서)만으로는 설치가 안 난다.** 기존 관객 앞에 **사람이 직접 서는 시딩**이 반드시 병행돼야 함. [근거: 딥리서치 §1 — 완전자동 다채널 발행이 ZERO 트래픽 낸 실사례]
- **애드몹 승인 지연 = 낭비할 시간이 아니라, 이 4개 층(직접침투·획득·ASO·측정)을 완성해 둘 시간.** 승인 나는 순간 이미 쌓인 관객·트래픽이 즉시 수익화되도록.
- **원칙: 적극적일 땐 적극적, 보수적일 땐 보수적 — 무조건이 아님.** §5 캘리브레이션 매트릭스로 명문화.

## 4. ASO — 스토어 전환 층 (자동화 문서에 없음, 설치가 실제로 나는 곳)

소셜·직접 침투가 데려온 트래픽은 **스토어 리스팅에서 설치로 전환되거나 이탈.** 여기가 깔때기의 목.
- **키워드**: 제목·부제·키워드필드에 "options flow, dark pool, gamma, max pain, 감마, 다크풀, 옵션, 米国株, オプション" 등 니치 검색어. (ASC/Play 각 로케일)
- **스크린샷 1~3장 = 전환의 80%**: 첫 장에 "차트가 안 보여주는 층"(감마/맥스페인/다크풀) 한 컷 + 한 줄 카피. en/ko/ja 각각.
- **전환 측정**: ASC "제품 페이지 전환율" + Play "스토어 등록정보 전환수"를 주간 추적 → 스크린샷 A/B.
- [판단] 무료 채널 착수 전 **리스팅 1회 정비**가 ROI 최고 — 데려온 사람이 새는 걸 막는 게 먼저.

## 5. ★ 적극 vs 보수 캘리브레이션 (대표 원칙 명문화)

**무조건 적극도, 무조건 보수도 아님.** 상황별로:

| 국면 | 모드 | 행동 |
|---|---|---|
| Product Hunt / Show HN 발사일 | 🔴 **적극** | 전 채널 총동원, 하루 집중 화력 |
| 창업 서사·콜라보 DM·디스콰이엇 | 🔴 **적극** | 매주 능동적으로 밀기 |
| 실이벤트 발생(감마플립·매크로·괴리) | 🔴 **적극** | 즉시 발행(자동화문서 §3 트리거) |
| 평시 오리지널 발행 볼륨 | 🟡 **보수** | 캡 3~5/일·지터·간격≥90분 (자동화문서 §2) |
| 레딧·Stocktwits·커뮤니티 | 🟡 **보수** | 가치우선·서브당 1/일·링크 절제 |
| X 콜드 답글 / 엔게이지 자동화 | 🟢 **금지** | 플랫폼 정책(자동화문서 §1) |
| 유료 광고 | 🟡 **씨앗 후** | 무료 검증 뒤 소액부터 |

**한 줄: 적극=사람이 앞에 서는 단발/이벤트/관계 / 보수=반복 발행 볼륨·커뮤니티 규칙 / 금지=플랫폼이 막은 것.**

## 6. 측정 루프 (무료·유료 공통 전제)

- **`?from=` 유입 패치**(웹 `src/app/app/route.ts` 3줄, [사장님결정]—웹파일 승인) = 채널별 유입 귀속의 전제. **측정 없으면 뭘 해도 장님.** 최우선.
- ASC/Play 설치 지표 + `?from=` + 자동화문서 §2 성과탭 → **주간 test-and-double-down.** 되는 채널 2배, 안 되는 채널 컷.
- 콜드스타트 히어로 지표 = **조회수 아님** → 답글수/일·프로필클릭·팔로워증감·**설치**. ("조회수" 히어로화 = 패닉→볼륨증량→1000트윗 재발.)
