## W0 상세 (2026-07-13)

**진단 (실측)**: 일요일 ET 아침 방문자가 `wim:units:v2:2026-07-12` 키로 생성 트리거 →
주말이라 gainers/losers 무버 빈 결과 → 열화 유닛 3개(가치無) → 홈 히어로 카드 빈 렌더.
+ WIM은 워밍 크론이 없는 pull 구조(UC와 동일 결함이었음).

**수정 (파일:함수)**:
1. `api/wim/today/route.ts` — `lastTradingDayET()` 신설: ET Sat→-1일, Sun→-2일.
   캐시 키·aggs 범위 끝·시드 전부 이 값 사용 → **주말엔 금요일 정식 캐시를 서빙**
   (열화 생성 경로 자체 차단). 공휴일은 미매핑 — value 무버가 전세션 데이터를 들고 있어
   커버됨, 공휴일 빈화면이 실제 관측되면 그때 확장 (스펙 §5 주석 참조).
2. `api/cron/uc-warm/route.ts` — `warmWim()` 추가: 일반 GET(콜드면 인라인 생성) →
   `_stale`(>4h)일 때만 `refresh=1` 재생성. **매 사이클 refresh 강제 금지** —
   유닛 AI는 8k토큰 호출이라 15분마다 재생성하면 동일 콘텐츠에 돈만 탐. 병렬 웨이브에 편입.
3. 클라이언트 가드: 근본 차단으로 불요 판단 (열화 유닛이 더는 생성 안 됨). W1 재설계에서
   히어로가 어차피 재작성됨.

**검증 절차 (이 파일 갱신 시점 기준)**: tsc → push → 프로드 `api/wim/today` 응답의
dateET가 주말에도 금요일인지 + units 5개·moveMagnitude 정상 → 시뮬 `/ko/wim` 히어로 렌더 확인.
