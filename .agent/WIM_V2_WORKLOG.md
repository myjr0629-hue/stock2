## W2 상세 (2026-07-13) — 신규 API 0, 전부 `src/app/[locale]/wim/page.tsx` 단일 파일

**변경 (파일:컴포넌트)**:
1. **P3 `LevelHuntPlay` 신규** (풀스크린 오버레이, 퀴즈 오버레이와 동일 비주얼 언어):
   히어로 유닛 티커의 lab 스냅샷 사용. 라운드 = maxPain→callWall→putFloor 중 non-null만
   (셋 다 null 또는 스파크 부재 → "오늘은 이 데이터가 없어요" 빈 상태, XP 0).
   대형 차트(264px, 측정폭 1:1 viewBox — 왜곡 없음) 위 수평 추측선을 포인터 드래그
   (touch-action:none + setPointerCapture — iOS 웹뷰에서 스크롤 안 끌림), 우측 플로팅 $칩.
   가격 도메인 = closes ∪ 전체 레벨 +8% 패딩 **고정** (라운드별 리스케일로 힌트 누설 방지).
   확정 → 실제 레벨 대시라인+라벨 공개, 근접도 판정(≤1% +XP_CORRECT "대박" / ≤3% +XP_TRIED /
   그 외 0 + 격려 카피) + 개념 한 줄 의미(3언어). 이미 찾은 레벨은 다음 라운드 차트에 잔존
   (차트가 자라는 감각). 최종 요약 = 라운드별 차이% + 합계 XP.
2. **P4 `NumberSensePlay` 신규**: 오늘 유닛 티커 최대 3개의 lab을 병렬 fetch(캐시 우선),
   non-null 필드로 질문 풀 구성 — darkPoolPct vs 50 · pcr vs 1.0 · shortVolPct vs 40 ·
   vol.regimeScore vs 50 · 종가 vs SMA50 (동률 문항 제외). 셔플 후 5문항(3개 미만이면 빈 상태).
   높다/낮다 큰 버튼 2개(chevUp/chevDown 아이콘 — 방향 색칠 없음, 둘 다 바이올렛) →
   즉시 실값 CountUp 공개 + 한 줄 의미 + 러닝 스코어. 정답당 +XP_TRIED, 5/5 보너스 +XP_CORRECT.
3. **오버레이 언락 1단계**: 레벨 헌트 최초 완주 → `localStorage 'wim.unlock.levels'='1'` →

## W1 상세 (2026-07-13) — 홈 탭만, 퀴즈/사전/검색/기록 탭·API 무변경

**변경 (전부 `src/app/[locale]/wim/page.tsx` 단일 파일)**:

2. **오늘의 플레이 덱** (기존 "사건 파일" 레일 대체): 카드 168→212px 확대(snap 유지),

3. **스트릭 밴드 압축**: 3줄(링+주간 도트+레벨/XP바) → 1줄(링 44px + "이번 주 N일" +

**검증 절차 (시뮬 실화면, ko/en/ja 각각 `/{loc}/wim`)**:

  0→값으로 굴러 올라감, 차트 아래 PRE·REG·POST 스트립에서 본장(REG)만 점등.

  "곧 열림/Coming soon/近日公開" 칩 + 탭해도 무반응인지.

## W0 상세 (2026-07-13)

**진단 (실측)**: 일요일 ET 아침 방문자가 `wim:units:v2:2026-07-12` 키로 생성 트리거 →
주말이라 gainers/losers 무버 빈 결과 → 열화 유닛 3개(가치無) → 홈 히어로 카드 빈 렌더.
+ WIM은 워밍 크론이 없는 pull 구조(UC와 동일 결함이었음).

**수정 (파일:함수)**:
1. `api/wim/today/route.ts` — `lastTradingDayET()` 신설: ET Sat→-1일, Sun→-2일.
   캐시 키·aggs 범위 끝·시드 전부 이 값 사용 → **주말엔 금요일 정식 캐시를 서빙**
   (열화 생성 경로 자체 차단). 공휴일은 미매핑 — value 무버가 전세션 데이터를 들고 있어
   커버됨, 공휴일 빈화면이 실제 관측되면 그때 확장 (스펙 §5 주석 참조).
2. `api/cron/uc-warm/route.ts` — `warmWim()` 추가: 일반 GET(콜드면 인라인 생성) →
   `_stale`(>4h)일 때만 `refresh=1` 재생성. **매 사이클 refresh 강제 금지** —
   유닛 AI는 8k토큰 호출이라 15분마다 재생성하면 동일 콘텐츠에 돈만 탐. 병렬 웨이브에 편입.
3. 클라이언트 가드: 근본 차단으로 불요 판단 (열화 유닛이 더는 생성 안 됨). W1 재설계에서
   히어로가 어차피 재작성됨.

**검증 절차 (이 파일 갱신 시점 기준)**: tsc → push → 프로드 `api/wim/today` 응답의
dateET가 주말에도 금요일인지 + units 5개·moveMagnitude 정상 → 시뮬 `/ko/wim` 히어로 렌더 확인.
