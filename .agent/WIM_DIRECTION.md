# Why'd It Move? — 최종 실행 방향 (v-Final)

크리티크 6개 결함을 전부 반영: (a)(c)(e)는 스코프 축소로 수용, (b)는 매출표 폐기로 수용, (d)는 방어 설계로 수용. **빌드 전 kill-gate를 최상위에 박았다.**

---

## 0. 노스스타 (한 문단)

**"이미 1~2종목 사서 손익 긴장이 생긴 신규 투자자가, 오늘 실제로 ±2% 움직인 종목 하나를 8초 안에 '왜?'로 맞히고, 관찰자 톤 AI가 원인을 2문장으로 짚어주는 30초 습관형 교육 퀴즈."** 존재 이유는 스탠드얼론 매출이 아니라 **SIGNUM/Undercurrent로 가는 가장 싼 퍼널 상단 + CAC 절감 라인아이템**이다. 단일 KPI = **D7 리텐션**. 두뇌(데이터·AI)만 재사용하고 얼굴(프레젠테이션)은 새로 만든다 — 이게 App Store 4.3 통과 조건. **단, 어떤 코드도 짓기 전에 코어 루프 D7을 노코드로 검증한다. 8% 미만이면 이 앱은 만들지 않는다.**

---

## 0.5. KILL-GATE (빌드보다 먼저, 비타협)

크리티크의 가장 무서운 지적: 이 계획 전체가 **"신규 투자자가 안 익숙한 종목의 원인을 매일 궁금해할 것"이라는 단 하나의 미검증 가정** 위에 서 있다. 틀리면 71개 지표도 죽은 자산이다. 그래서 착수 순서를 뒤집는다.

**Gate 1 — 코어 루프 D7 검증 (노코드, 2~3주):**
- 웹 랜딩 + 이메일/푸시로 "7일 연속 하루 한 문제" 수동 운영. 매일 사람이 실제 무버 1개 골라 4지선다 + 2문장 설명을 발송.
- 측정: D1/D3/D7 오픈율, 문제 완료율, 재방문. **D7 ≥ 8% 나와야 통과.** 안 나오면 중단하거나 타깃/훅 재설계.
- 비용 ~0, 코드 0. 여기서 죽는 게 3개월 풀빌드 후 죽는 것보다 100배 싸다.

**Gate 2 — 타깃 확정:** "주식 없는 초보" → **"막 1~2종목 산 신규 투자자"**로 좁힘. 손익 긴장이 있어야 "왜 내렸지?"가 진짜 질문이 된다. KR 1450만·JP 신NISA·US Gen Z 근거는 전부 "이미 사기 시작한" 사람이므로 정합적.

Gate 1 통과 후에만 §6 MVP 빌드 시작.

## 1. 코어 루프 & 제품 프레임워크

**원칙: 하나의 30초 인과 습관을 소유한다. 코스 앱이 되면 죽는다.** 벤치마크는 Edu(D30 2~3%)가 아니라 게이밍/핀테크 습관 루프(D1 30% / D7 15%).

**루프 (Hook → Guess → Reveal → Return):**
1. **Trigger** — US 종가 직후, 유저의 실제 습관 시간대에 미스터리 티저 푸시("오늘 거의 아무도 못 맞힌 무브가 하나 나왔어 — 뭘까?"). 답 감춤 = 열린 고리. 죄책감 카피 금지.
2. **Action (<10초)** — 콜드오픈 → 오늘의 무버 카드 → 4지선다 8초 → 탭.
3. **Reveal = 보상** — 현금·포인트 절대 금지(Zogo 부검: 외재 보상은 콘텐츠 내재동기 부재의 증상). 정답=컨페티, 오답=처벌 없는 친절한 설명, 부분정답="절반 맞혔어!". **단, "리빌이 보상"은 아직 가정이므로 Gate 1에서 실측한다.**
4. **Return** — 스트릭 +1(학습 일수), 다음 날 티저.

**비타협 3규칙:**
- **하트/라이프/처벌 금지** — 불안 유발 장치는 무료·광고·초보 리텐션에 독.
- **스트릭은 은혜롭게** — 오토프리즈 1개 출시일부터, 주말/휴장일 무과실 자동 프리즈. "정답 일수" 아니라 **"학습 일수"** 카운트(컴플라이언스 필수).
- **첫 세션 = 온보딩.** 로그인·설문 벽 없음. 계정은 첫 보상 이후로 연기.

## 2. UI/UX + 퍼스트런 + 브랜드 무드

**무드: 제3의 정체성.** 듀오링고처럼 촉각적(3D 눌리는 버튼·둥근 모서리·마스코트·컨페티)이되 (a) 듀오 그린 클론 아님, (b) SIGNUM 다크골드 아님, (c) **초록/빨강은 이미 시장 방향+정답/오답 의미를 가지므로 브랜드 히어로 컬러가 될 수 없음.**

**디자인 토큰:**
- 히어로 = 친근한 **바이올렛/인디고(~#6C5CE7)** — 브랜드·주 CTA
- 의미 고정(크롬 금지): 초록(~#16C784 정답), 코럴(~#FF5C7A 오답)
- 스트릭 = 앰버(~#FF9F1C), 캔버스 = 따뜻한 오프화이트(~#FAF9FF)
- 폰트 = **M PLUS Rounded 1c + Pretendard**(CJK 라운드 고딕). KR/JP 긴 선택지 → **2×2 금지, 풀폭 세로 스택**
- 마스코트 = **"마켓 디텍티브"**(돋보기 = 인과 호기심). 부엉이 아님.

**★ 컴플라이언스 UI 방어 (크리티크 d 수용):**
- **무버 카드에서 방향 화살표·상승/하락 색을 죽인다.** "TSLA +5%↑"가 아니라 **"오늘 TSLA에 무슨 일이 있었나"**로 프레이밍. 가격 예측 게임으로 오독되면 3.1.1(금융 도박화) 리젝 리스크.
- **초보 UI에서 confidence/riskFlag 수치 완전 제거.** "confidence 82%"는 초보에게 "82% 확률로 이렇게 됨"(=투자신호)으로 읽힌다. 서술만 노출.
- 질문은 항상 **방향(±)이 아니라 원인(why)만.**

**퍼스트런 (MVP는 3~4단계로 압축 — §5 스파이더/컬렉션은 P2):**
- `[0]` 스플래시: 마스코트 + 워드마크 + "Start"(계정 없음)
- `[1]` **아하 모먼트** — 즉시 오늘 실제 무버 웜업: "TSLA가 오늘 크게 움직였어. 왜?" + 4선택지, **첫 판 타이머 끔** → 탭 → 리빌 → 원인 볼드된 2문장 → 작은 컨페티. 이 30초가 온보딩.
- `[2]` 3탭 미니 설문(1설문 3역할): "얼마나 알아?"(레벨 게이트) / "뭐에 끌려?"(관심 가중치) / "하루 30초 언제?"(푸시 시간대)
- `[3]` iOS 시스템 프롬프트 **전에** 커스텀 푸시 프라이머 → 연기 가능 가입("스트릭 저장할래?"·"나중에"). 진행상태 온디바이스(4.3 충족)

**코어 카드:** 상단바(스트릭 불꽃, 레벨, 설정) / 히어로 무버 카드(로고+회사명+**추상 스파크라인**, 트레이딩 차트 아님, 방향색 죽임) / **8초 카운트다운 링(탭하면 정지)** / 풀폭 3D 선택지 4개.

**리빌:** 정답=초록 채움+체크+컨페티 / 오답=코럴 채움+부드러운 흔들림+정답 하이라이트+무처벌 카피 / 부분정답="절반 맞혔어!". 그 뒤 "The Why" 카드(2문장, 원인 카테고리 볼드+탭).

**Pull Ladder (탭하면 열리는 바텀시트, MVP는 1~2단만):** (1) The Why 자동 → (2) "영수증"(실제 헤드라인/8-K 태그) → *(3) 라이브 차트, (4) 글로서리 카드 = P2.*

## 3. 콘텐츠/커리큘럼 모델 — 초보 안전, EASY부터

**★ 크리티크 (c) 전면 수용: 옵션 구조(감마/GEX/다크풀/맥스페인)는 초보 MVP에서 통째로 뺀다.** 소스가 전부 SIGNUM 세미프로용이라 "번역"이 아니라 "통역"이 필요하고, 통역은 결정론적 템플릿으로 안 된다. 감마는 P2 언락 보상이 아니라 **초기엔 존재조차 안 한다.**

### 3-1. 난이도 사다리 — 서사형 원인만으로 시작

| 레벨 | 원인 카테고리 | 초보 질문 성립? | MVP 포함 |

### 3-3. 매일 정답키 파이프라인 (탭타임 AI = 0)

야간 베이커:
1. **선택** — 엔진이 이미 `bigMove = abs(priceChange) >= 2.0`(route L176)로 플래그한 티커 = Command/Intel과 같은 스냅샷 캐시. **MVP는 L1(서사형)으로 해결 가능한 무버만 필터.**
2. **정답 생성** — 하루 1회 오프라인 deep-analysis 호출(`triggerReason='PRICE_MOVE'`) → 강제 첫 섹션 'Price Move Attribution'(route L334-341)이 우선순위대로 원인 해결.
3. **태깅** — 드라이버를 8카테고리로 매핑. **cat 5·8(옵션/플로우)로 태깅되면 MVP 큐에서 제외**(P2 대기).
4. **선택지 조립** — 정답 + 8-카테고리 뱅크에서 그럴듯한 혼동 오답 3개(L1 케이스는 오답도 cat 1/2/3에서만).
5. **영수증** — 같은 문서에서 뉴스 헤드라인 + disclosures.ts 이벤트.

**탭타임 AI 비용 = 0. 유일한 라이브 콜은 야간 베이커.**

### 3-4. 가이드 재활용 — "퀴즈 소스" 아니라 "졸업 예고편" (사용자 원 요구 재배치)

사용자가 원한 GEX/감마 가이드(71 badge / 162 guide 라인) 재활용은 **유지하되 위치를 바꾼다:**
- **STATE-MATCH / SIGNAL-CLOZE 상록 유닛은 코어 큐에서 뺀다.** "VOL REGIME stable/coiling/loaded/erupting 중 뭐?"는 초보에겐 순수 찍기 = 좌절이고, 계획이 경계한 "코스 앱"의 정확한 증상이다.
- **가이드 콘텐츠는 Pull Ladder 심화읽기 + 졸업 직전 SIGNUM 예고편**으로만 쓴다. 프로 콘텐츠는 초보 정답지로는 독, 졸업 유저에겐 자산.
- 조용한 날(휴장/주말)엔 **나쁜 상록 유닛보다 빈 날이 낫다** → "어제의 놓친 무버 재방영" 또는 큐 비우고 주말 프리즈.

1. **8-카테고리 원인 뱅크**(3언어 라벨 + 카테고리별 고정 혼동-오답 맵). disclosures.ts PRIMARY_LABELS(10cat×3언어)를 모델로.
2. **드라이버구문→(causeCategoryId, boldTerm) 사전**('analyst'→cat3, '8-K/filing'→cat4, 'earnings'→cat1…). MVP는 L1 매핑만 필요.

**★ 컴플라이언스는 "20개 regex"로 안 끝난다 (실측):**
- `education.ts` iv_percentile 영문 본문 = 문자 그대로 **"High = sell options, Low = buy options"**(직접 매매 조언), pcr = **"High = bearish, Low = bullish, Extremes precede reversals"**(심리 단정+예측). regex 단어치환 불가, **문장 통째 재작성** 필요.
- 결정적: **같은 파일 ko/ja 본문엔 그 조언 문장이 이미 빠져 있다** → 소스가 로케일별로 불균질. **"en 제로코스트 재활용" 전제는 거짓.** 재사용하는 모든 필드를 3언어×사람 눈으로 검수.
- **베이커에 게이트 내장:** 모든 유닛이 `applyCompliance()`(compliance.ts) 통과 + DISCLAIMER{ko,en,ja} 부착. 개념 카드는 **metricGlossary.ts 본문(이미 관찰자 안전 정본) 우선**.
- **TriggerDefinitions.ts는 한국어 전용(54줄)** → en/ja 번역이 실작업. 어차피 P2이므로 MVP 부담 아님.

톤 레지스터 2개: metricGlossary/deep-analysis = 관찰자 안전(드롭인) / 가이드 desc·tip·education.ts = 자문형(재사용 전 반드시 스크럽).

## 4. AdMob 모델 — 정직한 매출 수학

**★ 크리티크 (b) 전면 수용: 매출표 5줄을 폐기한다.** 이 계획 자신이 6절에서 "광고는 스케일 전까지 무의미, 진짜 가치는 두 금융앱 퍼널"이라 자백한다. 그렇다면 매출표는 의사결정자를 오도한다.

**정직한 숫자:**
- Education 카테고리 eCPM = 게이밍의 40~60%. AdMob은 앱 카테고리로 수요 결정 → Edu 등록하면 Edu 입찰 풀.
- 매출 나는 유저(US)와 리텐션 나는 유저(KR/JP)가 **다른 지역**. KR/JP eCPM = US의 1/3~1/5. 성장은 KR/JP 주도 → 현실 혼합 ARPDAU ≈ **$0.003~0.004**(표의 절반).
- 30초 1회 세션 = 구조적 ~1 임프레션인데, Day 0~3 광고 억제 + 리워드 opt-in 5~15% → **활성 유저 초기 임프레션 1 미만.**
- **결론: 50k DAU라도 월 $3~6k.** 스탠드얼론 매출은 성공지표가 아니다.

**재프레이밍: WIM은 매출 사업이 아니라 CAC 절감 라인아이템.**
- 성공지표에서 ARPDAU 제거. 남기는 지표 = **"WIM→SIGNUM/UC 전환수 ÷ 그 전환의 대체 UA 비용"** 하나.
- 이 재프레이밍으로 §4 광고 논쟁(리워드/인터스티셜/앱오픈) 대부분이 MVP에서 불필요.

**배치 규칙 (리텐션 우선, MVP는 사실상 OFF):**
- **MVP: 광고 완전 OFF.** AdMob SDK 배선조차 미룰 수 있다. 리텐션 미검증 상태에서 광고는 순손실.
- **P2 도입 시:** 인터스티셜 정확히 1개(리빌/레슨 완료 이탈 전환점, 하루 1회 하드캡, Day 0~2 억제 = D1 +5~8%). **정답 사실은 절대 광고 뒤에 안 둠**(다크패턴+컴플라이언스). 리워드 비디오는 유저 개시(스트릭 프리즈/보너스 퀴즈/힌트)로만 — 깊이·수량만, 정답은 아님.
- **P3:** AdMob 미디에이션(Meta/AppLovin/Unity) +15~35% eCPM, 앱오픈은 D7+ 복귀 유저만.
- **eCPM 보호:** 17+ 성인 선언, **'Made for Kids' 절대 금지**(비개인화 광고 강제 → eCPM 붕괴). iOS ATT 신중히(SIGNUM 7/8 ATT 리젝 전례).

## 5. 리텐션 & 그로스 + SIGNUM 퍼널

**D7 = 단일 회사 KPI.** 2026 양대 스토어가 D7+안정성을 다운로드보다 상위 랭킹 → 리텐션이 곧 ASO 엔진. 7일 스트릭 = 2.4배 잔존.

**복제 불가 해자 2개:** (a) **비증권사 중립** — 거래를 안 팔아서 '관찰자' 톤이 진짜 신뢰 포지션(Robinhood Learn은 브로커+영어우선). (b) **FinTok 갭** — Gen Z #1 학습소스인데 상위 투자영상 ~70% 오해소지 → 비하이프 3언어 대안 갭. 브로커도(이해상충) 크리에이터도(하이프) 못 채움.

**푸시 = 미스터리 티저(죄책감 아님):** 유저 드러난 습관 시간대 발사, 답 감춤. 스트릭이 진짜 끊길 때만 세이브 알림. 빈도 캡.

**★ 졸업 퍼널을 1급 기능으로 (WIM의 실제 재무 가치):**
- 성취 순간 교차프로모("실적 무브 20개 정답 → SIGNUM에서 라이브 인텔"). Day 1부터 앱간 전환을 코어 지표로 측정 — 여기가 포트폴리오 LTV, §4를 대체하는 진짜 손익.
- 옵션/감마 콘텐츠(§3-4)는 정확히 여기서 = 졸업 예고편으로 소비.

**바이럴 원자 1개(P2):** Remotion "스트릭 + 나 $TICKER 왜 움직였는지 맞혔어" 카드(Wordle 스타일 티커 숨김). **사람이 먼저 시딩 후 자동화** — 컴플라이언스로 죽은 13채널 자동포스터 재건 금지.

**ASO:** Education 리스팅(키워드 경쟁 낮음) + Apple In-App Events '오늘의 무브' 반복 이벤트(2026 피처링 레버) + 온디바이스 상태·계정불필요(Apple 에디토리얼 선호).

## 6. 단계별 빌드 플랜

**★ 크리티크 (e) 전면 수용: MVP를 강제 축소.** 기존 "MVP"는 이름만 MVP고 실제론 v1.0 풀프로덕트였다. 스파이더·컬렉션·상록뱅크·광고·공유·퍼널 전부 뒤로.

**전제: Gate 1(D7≥8%) 통과 + SIGNUM/UC 심사 정착 후에만 제출**(4.3 배치 트리거 회피).

**MVP (이것 하나):**
- 콜드오픈 → 오늘의 실제 L1 무버 1장(서사형 원인만) → 4지선다 8초 → 리빌 + 2문장 설명 → 스트릭 +1. **끝.**
- 야간 베이커(축소판): 캐시된 |Δ|≥2% 티커 → L1 필터 → deep-analysis 1콜 → 4지선다 조립 → applyCompliance+DISCLAIMER → `wim:units:{date}` 기록. 앱은 읽기만.
- 새 정적 테이블 2개(§3-6, L1 매핑만)
- 퍼스트런 3~4단계(§2), 스트릭 1개, Pull Ladder 1~2단(The Why + 영수증)
- **광고 OFF.** SDK 미배선.
- 인프라 재사용: FCM 푸시, i18n ko/en/ja, Bedrock, Redis/Dynamo, in-app-review
- 컴플라이언스 UI: 방향색 죽임, confidence 미노출

**Phase 2 (D7 검증 후 증폭):**
- L2 원인(8-K/섹터/매크로) 추가, 캘리브레이션 스파이더, 개념 컬렉션, Pull Ladder 3~4단
- 상록 뱅크는 **STATE-MATCH/CLOZE가 아닌** "어제 놓친 무버 재방영" 중심으로만
- 일간 공유카드 + 주간 Remotion 리캡, SIGNUM/UC 졸업 퍼널 ON + 전환 측정
- 인터스티셜 1개(전환점) 도입, AdMob 미디에이션 SDK 배선

**Phase 3 (복리 & 자금화):**
- L3 옵션/플로우 콘텐츠 언락 게이트로 도입(감마 = 졸업 예고편), TriggerDefinitions en/ja 번역
- 승리 바이럴 루프 스케일, D7 검증 코호트에만 라이트 UA(WIM 광고매출 아니라 두 금융앱 LTV로 정당화)
- 미디에이션 full 최적화, 앱오픈(D7+) 추가, D30 평가

## 7. 사람의 결정이 필요한 것

**코드/파이프라인은 결정론적으로 명세됨. 사람 판단 필요 영역 = "얼굴" + 검증 2건:**

1. **★ Gate 1 실행 승인** — 빌드 전 노코드 D7 A/B를 실제로 돌릴지. 이게 1순위.
2. **★ 데이터-코스트 체크** — 야간 베이커가 SIGNUM/UC와 **같은 Bedrock·스냅샷 캐시·deep-analysis**를 쓰면 리뷰어가 네트워크 콜에서 "같은 백엔드"를 본다(4.3 리스크). **별도 API 도메인/브랜딩, 최악의 경우 별도 개발자 계정**이 필요한지 확인 필요.
3. **히어로 컬러 최종 확정** — 바이올렛/인디고(~#6C5CE7) 권장(초록/빨강 의미 고정). 미학 결정.
4. **마스코트 디자인** — "마켓 디텍티브" 컨셉은 정해짐, 캐릭터 아트/이름/성격은 창작 필요.
5. **앱 이름/워드마크/아이콘 + 상표 유니크니스** — 4.3용 독립 번들ID. "Why'd It Move?"가 작동 제목이나 스토어 이름 상표 확인 필요(SIGNUM 로컬라이제이션 충돌 전례).
6. **폰트 라이선스** — M PLUS Rounded 1c + Pretendard 최종 승인.
7. **톤 캘리브레이션** — 듀오링고 밝기 vs 절제의 지점(35%+가 과잉 게임화 이탈). 컨페티 1·불꽃 1·링 1·햅틱 3~6 원칙은 정해짐.

## 가장 큰 단일 리스크 & 디리스크

**리스크: "신규 투자자가 안 익숙한 종목의 원인을 매일 궁금해할 것"이라는 미검증 가정.** 이게 틀리면 71개 지표, 스키마, 베이커, 폴백 큐 — 전부 죽은 자산이다. 코드량이 아니라 **아무도 안 돌아오는 것**이 진짜 리스크다.

**디리스크: 순서를 뒤집는다.** 셸·베이커·테이블을 짓기 전에 **노코드 웹랜딩+푸시로 "7일 연속 하루 한 문제" A/B를 먼저 돌려 D7≥8%를 실측한다**(§0.5 Gate 1). 동시에 타깃을 "주식 없는 초보"→"막 1~2종목 산 신규 투자자"로 좁혀 손익 긴장을 확보한다. 8% 미달이면 빌드 전에 중단 — 이 kill-gate가 3개월치 오버빌드를 막는 유일한 장치다.
