## 0. 대본 프레임 — 모든 템플릿의 공통 뼈대

레퍼런스 3종(TIGER ETF · 경제사냥꾼 ×2 · 팔란티어편) 분석에서 **같은 4단**이 나왔다.
비율은 팔란티어편 실측:

| 단계 | 분량 | 하는 일 |
|---|---|---|
| **HOOK** | 10% | 대형 수치 1~2개를 «5초 안에» 던진다 + 답 안 하는 질문 |
| **PROBLEM** | 40% | 사실을 쌓다가 «근데 지금 바로 그렇게 볼 수 있나?» 로 뒤집는다 |
| **PROOF** | 30% | **본질 지표**로 논리를 세운다 ← 여기가 우리가 이기는 지점 |
| **CTA** | 20% | 리스크를 먼저 말하고, 질문으로 닫는다 |

### ★ 두 개의 규칙 (레퍼런스에서 실측으로 뽑은 것)
1. **연쇄 커리오시티 루프** — 컷마다 «답하지 않는 질문»을 남기고, 답은 **바로 다음 컷**에.
   하나의 큰 루프가 아니다. 3~7초마다 새 미끼다.
2. **본질 지표 선점** — 팔란티어편은 주가·매출이 아니라 **NDR 157%** 를 들고 나왔다.
   "남들이 안 짚는 지표를 내가 먼저 설명한다" = 신뢰의 원천.
   **우리 대응물**: 감마 플립 · 맥스페인 괴리 · 다크풀 비중 · 딜러 프리미엄 · IV 스큐.
   이건 저쪽이 못 만든다. 공시는 누구나 읽지만 옵션 북은 우리만 읽는다.

### 🚫 컴플라이언스 (BUFFER_OPS §0-7)
레퍼런스는 «분할 매수 권장»으로 닫는다. **우리는 못 한다.**
- 매수·매도·비중 조언 0 / 예측 프레이밍 0 ("~로 간다", "~를 노린다")
- 대신 **관찰형 질문**으로 닫는다: "차트를 믿었을까, 북을 믿었을까?"
- 뉴스와 가격은 «같은 시간대»로만 잇는다. 인과 단정 금지.

## 1. 템플릿 4종

### T1 · 「모순」 — 특정 종목 (구현 완료 = BriefingV7)
**언제**: 아무 때나. 소재가 나오면.
**소재 조건**: 가격 방향과 옵션 플로우 방향이 «어긋난» 종목
**뼈대**
```
HOOK    종목 +6.23% 마감 — "그런데 돈은 반대로 갔다"
PROBLEM 순방향 -$251.8M / P/C 1.43 → "근데 딱 하나가 패턴을 깼다"
        $12.6M 콜 한 방 → "먹히고 있을까?"  → 손익분기 아직 5.5% 위
PROOF   [앱 화면] 맥스페인·감마플립·총프리미엄 + 다크풀·고래·판정
CTA     "차트를 믿었을까, 북을 믿었을까?"
```
**데이터 소스**: `/api/live/quotes` · `/api/live/ticker` · Flow 화면 캡처

### T2 · 「장 시작 전」 (미구현)
**언제**: 08:00 ET 발행 (모닝브리프와 같은 시각)
**뼈대**
```
HOOK    밤사이 가장 크게 움직인 선물/지수 수치 1개 + "오늘 볼 건 이거다"
PROBLEM 밤사이 뉴스 2건(출처·시각) → 어느 종목에 닿는지
PROOF   그 종목의 «개장 전 옵션 포지션» — 감마 플립·맥스페인이 어디 있나
CTA     "오늘 이 선을 지켜보나?" (관찰형)
```
**데이터**: `guardian/briefing` · `news-digest` · `market-feed`(선물) · ticker
**우리 우위**: 남들은 "밤사이 뉴스"만. 우리는 **개장 전에 옵션이 어디 묶여 있는지**.

### T3 · 「장중 속보」 (미구현 — 어제 만든 감지 엔진이 소재를 공급)
**언제**: 급변동 감지 시 (2.5σ / 30분). 하루 1~2편
**뼈대**
```
HOOK    "방금 X가 30분 만에 N% 움직였다" + 시각 못박기
PROBLEM 같은 시간대에 나온 것(뉴스/지표/공시) 또는 «아무것도 없음»
PROOF   그 순간의 거래량 배수 · σ 배수 · 다크풀 · 스윕
CTA     "뉴스 없이 움직였다. 그럼 누가 움직였을까?"
```
**데이터**: `cron/breaking-detect` 산출물 그대로. **이미 만들어져 있다.**
**우리 우위**: 속보를 «남들보다 빨리»가 아니라 «남들이 못 보는 층»으로 설명.

### T4 · 「장 마감」 (미구현)
**언제**: 17:00 ET
**뼈대**
```
HOOK    오늘 지수 마감 수치 + "그런데 안에서는 갈렸다"
PROBLEM 오른 섹터 / 내린 섹터 대비, 낙폭 3종목
PROOF   내일 만기·감마 벽이 어디 있나 (사후 서술로만)
CTA     "오늘 갈린 건 무엇 때문이었을까?"
```
**데이터**: `cross-sector-brief` · `market/movers` · intel 10섹터

## 2. 배경 이미지 정책 (대표 지적 반영)

> "뉴스 기반이면 실제 이미지를 쓰면 더 좋을 듯. 사람이 아는 것이 더 무섭다."

맞다. 지금은 AI 생성 broll 16장을 돌려쓴다. 개선 순서:

| 등급 | 소재 | 상태 |
|---|---|---|
| 🥇 | **뉴스에 딸린 실제 사진** (기업 로고·CEO·제품·건물) | ❌ 미구현. 저작권 확인 필요 |
| 🥈 | **우리 앱 실화면** (Command·Flow·Intel) | ✅ 사용 중 |
| 🥉 | 종목 로고 (`/api/logo` 프록시 있음) | ⚠️ 영상에 미사용 — **즉시 가능** |
| ⚪ | AI 생성 broll | ✅ 현재 주력 |

**다음 액션**: ③ 종목 로고를 컷에 넣는 것부터. 이미 API가 있고 저작권 이슈가 가장 작다.
①은 뉴스 제공처별 이미지 라이선스를 확인해야 하므로 별건 조사.
