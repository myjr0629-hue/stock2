## 2. 디자인 — «하이 퀄리티, 조잡하지 않게»

- **정체성**: 앱의 짙은 남색·카드·청록 강조를 그대로 쓰고, **금색은 ★ 과 맥스페인 ◆ 두 곳에만** — 금색 = «내 것·핵심 레벨».
- **행 해부(앱 특화 컬럼)**: 로고·티커·이름 | **포지셔닝 지도**(풋플로어 ─ ◆맥스페인 ─ ●현재가 ─ 콜월) | 가격·등락(색 + ▲▼) | **오늘의 사실 칩** | 🔔
- **규격**: 터치 48×48(애플 44pt·안드로이드 48dp 동시 충족) · 숫자 고정폭 · 빈 별 #94A3B8 → 채운 별 #FBBF24(테두리 #F59E0B) · 누름 0.92배 120ms · 추가 = «성공» 진동, 한도 = «경고» 진동 · 되돌리기 토스트(4초) · 움직임 줄이기 설정 존중.
- **품질 원칙**: 숫자를 지어내지 않는다(레벨 정의 위반·오래된 값 = 지도 숨기고 «레벨 갱신 대기») · 로딩 중 흔들림 0(최종 치수 뼈대) · 재방문 즉시 표시(마지막 정상값) · 시트가 열린 동안 네이티브 배너 내림.
- **시안·구현**: 시안 6장(무료 4/5·PRO 8·🔔→PRO 시트·알림 설정·빈 상태/한도·별 규격) → 프리뷰 실데이터 구현 확인 완료.

### 3-1. 구매 자극 요소 (가짜 희소성·과장 없이, 사실로)
1. **한도 미터 «4/5 ●●●●○»** — 가득 차기 전부터 보인다.
2. **6번째 ☆ = 한도 시트** — 지금 담긴 5종목 + PRO 혜택 + «PRO 시작하기»(스토어 현지가) + «코드 입력» + «기존 종목 정리하기». 결제하면 **담으려던 종목이 자동으로 담김**.
3. **🔔 = 알림 권유 시트** — 방금 누른 종목의 «검증된 실제 레벨»로 만든 알림 예시. 결제하면 **그 종목 알림 설정이 바로 열림**.
4. **놓친 알림 요약(최강 요소, 신규)** — «지난 7일 내 종목에서 PRO 알림 조건이 3번 충족됐습니다 — NVDA 콜월 250 돌파(9/24 14:05 ET) …». 실제 판정기로 과거 데이터를 다시 돌려 **사실만** 보여 준다. 무료는 건수만, 내용은 PRO.
5. **잠긴 두 번째 칩** — «고래 신규 포지션 · PRO» 처럼 종류만 보이고 내용은 잠금.
6. **가격 비교 문장(공식 요금표 근거만)** — «월 $89+ 웹 도구에만 있던 레벨 알림을, 내 폰으로 $9.99에».
7. **리딤코드 = 홍보용 체험권**(대표 방침) — 채널별로 «PRO 1개월 무료» 코드를 뿌려 알림을 먼저 겪게 → 전환. 누르면 적용 + 직접 입력 병행.
8. **첫 달 무료 체험(스토어 소개 혜택)** — 대표 결정 사항.

## 4. 차별화 포인트 (경쟁 18앱 조사 결론)

1. **행마다 포지셔닝 지도** — 가격·등락만 보여 주는 토스·로빈후드·웹불·키움에 없다. 문서상 행 컬럼으로 주는 곳 0.
2. **레벨 교차를 «모바일 푸시»로** — 콜월·풋월·감마플립 알림은 SpotGamma($89~299 웹)·QuantWheel(이메일·Discord)뿐. 모바일·월 $10대·한/일 = 0.
3. **맥스페인 알림** — 어디에도 없음.
4. **FINRA 장외·공매도 물량 급변 알림** — 소비자 앱 없음(기존 «다크풀 알림»은 블록 체결 기반·$50~99).
5. **한국어·일본어** — 서학개미·新NISA 미국주식 투자자에게 모국어 포지셔닝 도구가 없다.
6. **가격** — 같은 기능 타사 $50~$299 vs PRO $9.99.
