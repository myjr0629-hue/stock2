# «신규 포지션 구축» 카드 — 마감 직후 «그 세션 거래량 기준 추정» (2026-10-09)

대표 10/9: «목요일 장이 마감됐는데 카드가 수요일 새로 깔린 옵션을 보여 준다. 자료는 항상 신선하고 정확해야 한다.»

## 왜 한 세션 늦었나
옵션 EOD 묶음 = 공급사 레코드 D(저녁 16:4x~17:3x ET 에 올라옴, 수집기 «저녁(API) 경로»). 레코드 D 의 두 칸은 세션이 다르다.
- 거래량 `v` = D 세션 것 → D 마감 직후부터 안다
- 미결제약정 `oi` = D 아침 OCC 공시 = D−1 마감 포지션 → 증가분 `d` 가 «열린 세션» = `prevDate`

그래서 확정치(OI 증가분)는 늘 한 세션 늦다. 목요일 저녁 묶음(D=10/8, prevDate=10/7)의 확정치는 수요일 것이고,
목요일 장 확정치는 금요일 저녁 레코드가 올라와야 생긴다(수집기·Redis 는 바꾸지 않았다).

## 추정 정의 (정본: `src/lib/newPositionBasis.ts` 머리 주석 — 코드와 같은 식)
- 계약마다 열린 계약 수 = `max(0, v − oi)` (`oi` = 레코드 D 의 OI = 세션 D 시작 시점) — 업계 표준 Vol > OI
- 금액 = 열린 계약 수 × 100 × 행사가 — 확정치와 같은 식·같은 단위(USD 명목)·같은 종목 범위(묶음 `top` 행: 종목당 12행, 점수 = 2|ΔOI| + 거래량)
- **뺀다**: 만기가 «그 세션 다음 거래일» 이내인 계약(0·1일 만기). 하루 안에 사고판 거래가 대부분이라 남는 포지션과 거리가 멀다.
- «최대 단일 계약»은 만기가 마지막 마감 세션 이후인 것만(만기 지난 계약 제외 — 확정치 경로와 같은 규칙)
- 평소 대비(백분위)는 확정 정의로 쌓인 이력이라 추정에는 달지 않는다(`percentile: null`)
- 표본이 얇으면(추정 종목 50 미만) 추정을 만들지 않고 확정치로 되돌아간다. 0·상수를 지어내지 않는다.

## 카드가 말하는 세션 (순수 함수 `pickNewPositionBasis`)
L = 마지막으로 끝난 정규장(`lastClosedSessionDate`), P = 확정치 세션(`prevDate`), D = 레코드 날짜.
1. P ≥ L → **확정**(확정치가 L 까지 왔다)
2. 아니고 D 가 L 이하의 거래일 → **추정(세션 D)** — 마감 직후~묶음 갱신 전(약 1시간)에도 D 의 추정을 그대로 둔다(날짜를 단 채 한 칸 물러나지 않는다)
3. 그 외(레코드 없음·D > L = 진행 중 세션·날짜 이상) → **확정(세션 P)**

장중·장 시작 전·주말·휴장일은 L 이 «직전 마감 세션»이므로 같은 규칙이다. 진행 중인 세션은 절대 추정하지 않는다.
묶음이 매 거래일 저녁 D = L 로 갱신되므로 정상 운영에서 카드는 늘 «마지막 마감 세션의 추정»이다 — 확정치는 한 세션 늦게 도착해 카드에 오르기 전에 다음 세션 추정이 같은 묶음에 들어온다. 확정이 나오는 건 위 3번(추정 불가)일 때다.

## 노출
- `/api/live/premium-metrics` 의 `institutionalFlow`: `basis: 'estimate' | 'confirmed'`, `date` = 카드가 말하는 세션, `asOf`(ms)
- 대시 카드: 키커 «{요일} 장 신규 (추정)» / «New on {day} (est.)» / «{曜日}の新規（推定）», 문장 끝에 «OCC 확정 전 거래량 기준 추정»(en «volume est., pre-OCC», ja «OCC確定前の出来高推定»). 카드 줄 수·높이 유지(320·360·390·430px 실측)
- 추정은 `getInstitutionalFlowSummary({ allowEstimate: true })` 를 부르는 이 카드뿐. 마케팅 영상·SEO·옵션 흐름 페이지는 옵션이 없어 옛 동작(확정치) 그대로
- 정상본 키 `premium:instflow:lastgood:v2` + `asOf` 15분 신선도 — 배경 갱신이 서버리스에서 멈춰도 새 묶음 뒤 한 시간 안에 새 날짜로 넘어간다

## 남은 한계
- 추정은 추정이다. Vol > OI 는 하루 안에 열고 닫은 거래를 구분하지 못한다(단기 만기 제외로 줄였을 뿐). 확정치와 어긋날 수 있다.
- 검증 예정: 10/8 묶음 사본(로컬 보관)의 목요일 추정 $20.1B 를 금요일 저녁 레코드의 목요일 확정(`d`)과 대조 → 같은 범위 비율로 보정할지 결정.
- `top` 12행 한정이라 추정도 확정도 시장 전체의 하한이다.
