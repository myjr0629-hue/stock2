## 0. 지금까지의 «틀린 근거» 3개를 먼저 폐기한다

이 채널의 판단은 스튜디오 화면을 눈으로 읽은 수치에 기대 있었다. API 전수로 재니 셋이 무너졌다.

| 폐기 | 문서에 적혀 있던 것 | 전수 실측 |
|---|---|---|
| **게시 빈도** | 「1편/일 4.05 vs 3편/일 0.83」 | 1편/일 그룹은 **n=1**. 같은날편수 ↔ 지속률 **+0.24** (음수 아님). 4편/일이 3편/일보다 좋아 단조도 아님 |
| **트래픽 질** | 「피드 1.96초/회 vs 검색 10.66초/회 — 검색이 압도적」 | SHORTS **72.0%** vs SEARCH **71.9%**. 차이 없음 |
| **루프 파괴** | (제미나이) 「엔드카드가 루프를 죽인다」 | Oil편 곡선 1초 **2.56** → 끝 **1.15**. 끝에서도 1.0 초과 = 되감아 본다 |

**살아남은 신호는 하나다.**

```
첫컷 시각 ↔ 지속률   순위상관 -0.90    ← 유일
길이 ↔ 지속률        -0.08
게시시각 ↔ 지속률    -0.01
같은날편수 ↔ 지속률  +0.24
```

⇒ **제작 규칙은 「첫컷 ≤2.8초」 하나만 강제한다.** 나머지는 강제하지 않고 «측정 대상»으로 둔다.
근거 없는 규칙을 늘리면 그게 다음 세션의 오판이 된다.

## 1. 쇼츠 뒤 앱 광고 — «붙이지 않는다». 이유는 산술이다

시청자는 흥미를 잃는 «절대 시점»에 나간다. 뒤에 뭘 붙여도 시청 «초»는 그대로인데 분모만 커진다.
09_AMD 20.7초 · 지속률 60% 가정(12.4초 시청):

| 뒤에 붙임 | 총 길이 | 평균 조회율 |
|---|---|---|
| 0 (현재) | 20.7초 | **60.0%** |
| 3초 | 23.7초 | 52.4% |
| 6.5초 (태그) | 27.2초 | 45.6% |
| 24초 (완품) | 44.7초 | 27.8% |

**그리고 이미 들어 있다.** 브리핑 구조는 `본문 → 앱 CTA 2.77초 → 루프백 2.5초` 다.
CTA 뒤에 태그를 붙이면 CTA 가 두 번 나오고, 루프백 앞에 넣으면 루프가 밀린다.

### 결정
- **본편에는 붙이지 않는다.** 기존 2.77초 CTA 를 유지한다
- 대신 그 2.77초의 «질»을 올린다 — 광고 엔드카드(로고·흰 FREE·실제 스토어 배지)를 이식.
  **길이 비용 0** 이므로 지표를 해치지 않는다
- 만든 `AD_SIGNUM_tag_6s.mp4` 는 **본편용이 아니라** 인스타·틱톡 등 «루프 구조가 없는 플랫폼»용으로 돌린다

## 2. 앱 광고를 «독립 영상»으로 올리는 법

광고도 조회를 목적으로 한다. 그러려면 **광고가 아니라 콘텐츠로 읽혀야** 한다.

### 게시 규격
| 항목 | 값 |
|---|---|
| 파일 | `AD_SIGNUM_solo_24s.mp4` (단독) / `AD_SIGNUM_duo_27s.mp4` (자매 앱 포함) |
| AI 사용 신고 | **「예」** — 배경 플레이트가 Flow 생성물 |
| 유료 프로모션 | 체크 안 함 (자사 앱) |
| 자막 | **건너뛴다** — 번인 자막이 있어 트랙을 넣으면 이중이 된다 |
| 태그 | 앱·지표 키워드로. **유명 티커 금지** (의도 불일치 → 즉시 이탈 → 알고리즘 오학습) |

### 태그 (확정)
```
options flow app, max pain, gamma flip, dark pool data, options data app,
free stock app, stock market app, AI stock analysis, unusual options activity,
institutional options data, stock alerts app, SIGNUM HQ
```
`max pain` `gamma flip` `dark pool` 은 **그 지표를 찾는 사람**이 검색하는 말이고 영상이 정확히 그걸 보여준다 — 의도가 맞는다.

### 주기적 변형 — «같은 광고를 다시 올리지 않는다»
유튜브는 동일 영상 재업로드를 중복으로 취급한다. **매번 다른 각도 하나씩** 뽑는다.

| 회차 | 각도 | 주력 화면 | 나레이션 핵심 |
|---|---|---|---|
| A | 알림 | dash + 알림 배너 | 「장 열기 전에 폰으로 온다」 |
| B | 지표 | cmd 6타일 | 「기관이 돈 내고 보는 층」 |
| C | 고래·다크풀 | WHALE & DP | 「안 보이는 물량」 |
| D | AI | AI DEEP ANALYSIS | 「클로드가 한 줄로 읽는다」 |
| E | 무료 | 전체 + FREE | 「전부 무료다」 |

`scripts/tts-ad.mjs` 의 `LINES` 만 바꾸고 `AppAd` 의 `ORDER` 를 재배열하면 나온다.
**컷 길이가 나레이션 실측에 묶여 있어** 대본만 바꾸면 타이밍이 자동으로 맞는다.

주기: **2주에 1편.** 콘텐츠 사이에 끼워 넣되 연속 배치 금지.

## 3. 하루 3편 운영 설계

빈도가 성적을 해친다는 근거가 없으므로 **3편/일로 간다.** 다만 «같은 성격 3편»은 서로 잡아먹는다.

### 하루 편성
| 시각(KST) | 트랙 | 성격 |
|---|---|---|
| **08:00** | MORNING | 장 시작 전 — 선물·매크로·리스크 |
| **14:00** | TICKER | 종목 하나를 파고드는 편 (검색 겨냥) |
| **22:00** | CLOSE | 마감 해석 — 그날의 «왜» |

- **성격이 겹치면 하나를 버린다.** 같은 티커·같은 각도 두 편 금지
- 2주에 1회, 14:00 자리에 **앱 광고**를 넣는다

### 소재 공급
`node scripts/topic-bank.mjs` + `.agent/TOPIC_BANK.json` 으로 후보를 쌓아둔다.
하루 3편이면 주 21편이라 **소재가 병목**이 된다 — 재고 없이 시작하면 품질이 무너진다.
**착수 조건: 재고 15편 이상.**

## 4. 측정 루프 — 이게 «고도화»의 본체

지금까지 판단이 흔들린 이유는 표본이 9편·수동이었기 때문이다. 이제 자동이다.

```bash
node scripts/yt-ledger.mjs      # 전수 원장 갱신 + 상관 재계산
node scripts/yt-stats.mjs       # 28일 지속률·트래픽 소스
node scripts/yt-retention.mjs   # 이탈 곡선 (승자 vs 패자)
```

### 규칙
1. **매일 1회 원장을 갱신한다.** 사람이 스튜디오를 볼 일이 없다
2. **표본 30편 미만에서는 새 규칙을 만들지 않는다.** 지금 22편이다
3. **상관이 |0.5| 를 넘지 않으면 규칙으로 승격하지 않는다.**
   상단밝기 +0.13 을 원인으로 오판했던 사고의 재발 방지
4. A/B 는 **훅만 다른 쌍**으로 하루 간격 게시 (08A/08B 가 첫 쌍)

### 다음 검증 대상
| 가설 | 방법 | 판정 기준 |
|---|---|---|
| 첫컷 2.47초가 지속률을 올린다 | 09_AMD 지속률 (8/21 반영) | 60% 이상이면 지지 |
| 배경을 티커에 묶으면 오른다 | BG 교체본 vs 기존 | 지속률 중앙값 비교 |
| 훅 문장 차이 | 08A vs 08B | 같은 본문·다른 훅 |
