# WIM(Why'd It Move?) 완성 작업 — 실화면 QA + 계획 (2026-07-18, Mac)

> 대표 지시: "3번째앱 지금 완성해놓자, 많이 부족해 보임". 아래는 **프로덕션 실화면(모바일 375px) QA 실측 결과**. 스크린샷 근거로 확인된 것만 기록.

## ★ 제품 정의 (대표 비전, 2026-07-18 — 모든 작업의 기준)
1. **정체성**: 매매앱 ✕ / **학습앱** ○ — 단, 교과서처럼 딱딱하지 않게. **실제 데이터**가 교재이고 인터랙션이 수업.
2. **핵심 메커니즘**: "**한 지표 × 여러 실제 데이터 × 반복**" — 지표(맥스페인·다크풀·금리 등) 하나를 오늘의 여러 종목/시장 실데이터로 반복 체득. 지표 퀴즈 + 라이브 예시 드릴.
3. **범위**: **거시경제부터** 옵션 구조까지 전부 — "자기도 모르게" 흡수(스텔스 러닝: 게임 루프 안에 커리큘럼).
4. **대상**: 초보→고급 전부 아우름(난이도 사다리 L1~L3 + 벨트, 초보 진입장벽 0).
5. **표면**: 앱 스타일 웹 + **가이드 페이지**(웹 문서형 커리큘럼 — SEO 트래픽 겸용).
6. **감각**: 그래픽/인터랙티브 — 차트·마이크로비주얼·드래그 플레이 중심, 텍스트 최소.

### 비전 → 구현 매핑 (기존 자산 위에)
- 이미 있음 ✅: 실데이터 퀴즈 루프(P1), 인터랙티브 플레이 6종(레벨헌트 드래그·리플레이 스크럽·숫자감각), 벨트/XP/스트릭, 용어집 25(기술/옵션), 3언어.
- **신설 A — 개념 드릴("한 지표 × N 실데이터")**: 오늘의 개념 1개 → lab API로 종목 3~4개 실측값 → 같은 질문 반복(예: "이 종목, 가격이 맥스페인 위? 아래?") → 즉시 정답+실데이터 해설. 반복=체득.
- **신설 B — 거시 트랙 가동**: WIM 로컬 거시 용어(금리·FOMC·CPI·고용·10Y·달러·VIX 등 10+) 3언어 + 펄스 스트립 실데이터(10Y·FOMC 확률)와 연결 → 빈 트랙 2개 채움.
- **신설 C — 가이드 페이지**(/[locale]/wim/guide/[track]): 트랙별 문서형 커리큘럼(초보→고급), 각 용어에 오늘 실데이터 임베드. SEO 인덱서블(서버 렌더) = 트래픽 엔진 겸용.
- 순서: 결함 수정(W-FIX) → A(드릴) → B(거시) → C(가이드) → 시뮬 3언어 검증.
