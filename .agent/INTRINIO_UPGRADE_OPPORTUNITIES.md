# Intrinio 로 «좋아진» 부분 — 실측 근거와 활용안

> 2026-08-29. 대표 지시: «메시브에 없던 것, 더 질 좋게 들어오는 것이 있으면 찾아 강화하라.»
> 마케팅 문서가 아니라 **우리 키로 실제 호출해 확인한 것만** 적는다.
> 안 되는 것은 안 된다고 적는다.

---

## A. 이미 반영한 것

### A-1. 정규장 종가와 시간외 가격의 «명시적» 분리 ★
Massive 는 `day.c` 하나뿐이라 시간외 체결이 섞이면 정규장 종가를 잃었다.
Intrinio 는 세 값을 따로 준다 (NVDA 2026-08-28 실측):
```
normal_market_hours_last_price 217.58 @ 15:59:59 ET   ← 정규장 종가
last_price                     217.98 @ 19:44 ET      ← 시간외 포함
eod_close_price                227.98  (eod_close_date 2026-08-27)
```
→ POST 등락률이 0% 로 죽던 문제의 근본 해결. 이미 어댑터에 반영.

### A-2. 봉마다 bid/ask OHLC + 체결건수 ★
Massive 분봉은 `o,h,l,c,v,vw,n` 뿐. Intrinio 는 (NVDA 15:59 봉 실측):
```json
{"open":217.84,"close":217.58,"high":217.85,"low":217.36,"volume":183889,
 "average":217.6082,          ← 진짜 평균가 (우리는 (h+l+c)/3 로 근사하고 있었다)
 "trade_count":1265,
 "bid_open":217.83,"bid_high":217.84,"bid_low":217.43,"bid_close":217.52,
 "ask_open":217.84,"ask_high":217.85,"ask_low":217.45,"ask_close":217.56,
 "bid_change_percent":-0.1423,"ask_change_percent":-0.1285}
```
→ `average` 를 VWAP 자리에 쓰면 근사치를 실측치로 대체할 수 있다.

### A-3. 전 종목 NBBO 스냅샷을 «1콜»로 ★★
`securities/snapshots` → S3 CSV 1개에 **약 13,000종목**의 bid/ask/size + 누적거래량.
→ 이걸로 **시간외 봉 기록기**(`scripts/intrinio-ext-bars.js`)를 만들었다.
   Intrinio 가 시간외 «과거» 분봉을 안 주는 약점을, 우리가 직접 기록해서 메웠다.
   종목당 호출이 아니라 폴링 1회로 전 종목이 커버된다.

## B. 아직 안 쓰는데 쓸 수 있는 것

### B-1. 시장 전체 «유동성 지도» (신규 지표 후보) ★★
스냅샷 CSV 에 bid/ask/size 가 전 종목 들어온다. 2026-08-28 시간외 실측 분포:

| 스프레드 | 종목 수 |
|---|---|
| ≤0.1% | 112 |
| ≤0.5% | 505 |
| ≤1% | 595 |
| ≤5% | 3,034 |
| ≤20% | 3,741 |
| >20% | 5,002 |

Massive 스냅샷에는 호가 사이즈가 없어 만들 수 없던 지표다. 만들 수 있는 것:
- **유동성 스트레스 지수** — 시장 전체 중앙값 스프레드의 시계열
- **종목별 스프레드 백분위** — «지금 이 종목은 평소보다 유동성이 나쁘다»
- **호가 불균형(bid_size vs ask_size)** — 체결 데이터 없이도 수급 압력 근사

### B-2. 봉 단위 스프레드 (마이크로 유동성)
A-2 의 `bid_close`/`ask_close` 로 **분봉마다 스프레드**를 만들 수 있다.
급변동 구간에서 스프레드가 벌어지는 것을 그대로 보여줄 수 있다 —
«가격은 올랐는데 유동성은 말랐다» 같은 서술이 데이터로 가능해진다.

### B-3. `qualified_last_price` — 거래조건 필터된 가격
정규 체결 조건만 통과시킨 가격. 이상 체결(경매·오류·조건부)에 흔들리지 않는다.
현재 우리 어댑터는 폴백 사슬에만 쓰는데, **«가격 검증»의 기준선**으로 쓸 수 있다.

### B-4. `market_volume` vs `exchange_volume`
```
NVDA  exchange_volume 18,998,948   market_volume 195,498,733
```
보고 거래소 물량과 통합 물량이 분리돼 온다.
※ 이것을 «오프익스체인지 비중»으로 해석하고 싶겠지만, `exchange_volume` 이
   **어느 거래소인지**가 확정되지 않아 다크풀 대용으로 쓰면 틀린 숫자가 된다.
   유동성 집중도 참고 지표로만 쓸 것.

### B-5. `figi` / `composite_figi` / `exchange_ticker`
글로벌 표준 식별자. 티커 변경·상장이전 추적, 중복 상장 판별에 쓸 수 있다.

## C. 확인 결과 «안 되는» 것 (희망 고문 방지)

### C-1. 다크풀 — 현재 피드에서는 불가, DELAYED_SIP 은 판정 대기 ⏳
- REST 응답에 `is_darkpool` 필드가 **있다.** 그래서 될 것처럼 보인다.
- 그러나 같은 응답이 명시한다:
  > "market_center, listing_venue, sales_conditions, and quote_conditions
  >  are only available with our delayed sip feed."
- **EQUITIES_EDGE WS 실측 (2026-08-28 POST)**:
  ```
  MarketCenter=" "  Condition=""  IsDarkpool=false(전건)  Size=0  TotalVolume=0
  ```
  필드는 존재하지만 **값이 안 온다.** 그대로는 다크풀을 만들 수 없다.
- **프로바이더별 권한 실측**: `DELAYED_SIP` **HTTP 200 (권한 있음)**
  (`NASDAQ_BASIC`·`CBOE_ONE`·`IEX`·`EQUITIES_EDGE` 도 200)
- ⏳ **미확정**: 권한이 있다는 것과 필드가 채워진다는 것은 다른 문제다.
  장이 닫혀 체결 표본이 없어 확정하지 못했다.
  → `scripts/intrinio-darkpool-probe.js` 를 EC2 cron 에 등록
     (평일 ET 09:45 = UTC 13:45, `/var/log/intrinio-darkpool-probe.log`)
     **개장 직후 자동으로 판정문이 찍힌다.** 그 결과로 결정할 것.

### C-2. 시간외 «과거» 분봉 — 없음 (자체 기록으로 우회함)
`securities/{t}/prices/intervals` 는 정규장만 준다.
실측: NVDA 8/28 → 390봉(09:30–15:59), PRE 0 / POST 0.
`start_time`·`end_time`·`timezone` 을 붙여도 결과 동일.
→ A-3 의 기록기로 우회. 다만 **기록 시작 이전 날짜는 영영 없다.**

### C-3. 403/404 로 닫혀 있는 것 (스타트업 플랜)
| 항목 | 상태 |
|---|---|
| 옵션 만기/실시간 체인/이상거래 | 403 (EOD 체인만 열림) |
| 공매도 잔고 (short_interest) | 403 |
| 13F 기관보유 | 404 |
| 배당 이력 | 404 |
| 애널리스트 추정·실적일정 | 404 |
| ESG · 기업행위 · 지수 · 경제지표 | 404 |

열려 있는 것: 회사개요 · 펀더멘털 · 재무지표(data_point) · **내부자 거래**

## D. 우선순위 제안

| 순위 | 항목 | 비용 | 효과 |
|---|---|---|---|
| 1 | ⏳ **다크풀 판정 결과 확인**(C-1) | 0 (자동 실행됨) | 껐던 간판 기능 복구 가능성 |
| 2 | `average` → VWAP 대체 (A-2) | 매우 낮음 | 근사치를 실측치로 |
| 3 | 유동성 스트레스 지수 (B-1) | 중간 | **경쟁사에 없는 신규 지표** |
| 4 | 봉 단위 스프레드 (B-2) | 중간 | 급변동 해설의 근거 |
| 5 | `qualified_last_price` 검증선 (B-3) | 낮음 | 가격 이상치 방어 |

**1번은 이미 자동으로 돌게 해뒀다** — 다음 개장 때 답이 나온다.
