## 3. 확정된 규칙 — 근거가 있는 것만

### ✔ 고쳤다 (근거 강함)

| # | 규칙 | 근거 | v2 → v3 |
|---|---|---|---|
| 1 | **자막은 화면 세로 72~80%** | DTW 2편 75~80% (프레임 육안 확인). 그 아래는 쇼츠 UI(제목·채널·진행바)가 덮는다 | 86~91% → **73~78%** |
| 2 | **한 자막은 6~8단어** | 레퍼런스 **9편 전부** 5.8~7.8 단어/큐. 예외 없음 | 11.3 → **6.5** (최장 19 → 9) |
| 3 | **자막 노출은 1.8초 이상** | 레퍼런스 1.79~2.98초 | 2.85초(단, 11단어) → **1.82초(6.5단어)** |
| 4 | **밝기는 최소 100 이상** | 상위 3계급 전부 197~235. 100 미만은 플릿에서 우리와 DTW뿐 | 96.6 → **121** |
| 5 | **컷은 0이면 안 된다** | ICT 가 0컷으로 17.6만을 하지만 그건 «실시간 화면녹화»의 신뢰감이 값이다. 우리처럼 만든 화면은 안 움직이면 죽는다 | 0 → **10.4/분** |
| 6 | **키워드에 색 박스** | DTW 의 `BULL` 박스 (프레임 확인). 한 청크에서 «봐야 할 단어»를 지정한다 | 없음 → 적용 |
| 7 | **상단 타이틀 필 고정** | DTW — 영상 내내 남아 «무슨 영상인지» 이탈자에게도 보인다 | 페이오프에서 사라짐 → **CTA 직전까지 유지** |

### ✔ 구조적 차용 — 계급 ①에서

Primate(1,500만)는 개념을 **문장으로 설명하지 않는다.** 원숭이가 팻말을 들고 «연기»한다.
같은 것을 우리 재료로 하면 → **실제 스트라이크별 미결제약정 사다리**다.

```
$450 에 11,991 계약   ← 실제 데이터, 우리가 매일 받는 것
$480 에  8,080 계약
$490 에  6,624 계약
```

**설명이 아니라 그림 자체가 데이터다.** 이건 Primate 도, ICT 도 못 한다.
출처 `/api/live/options/atm?t=AMD` · 만기 2026-08-21 · ATM ±8 스트라이크.

### ✘ 고치지 않았다 (근거 약하거나 반증)

| 항목 | 왜 안 고쳤나 |
|---|---|
| **채도 34.5% (플릿 상한 30.4)** | 상한을 13% 넘지만, 1,500만 영상의 채도가 **6.4%** 로 최저다. 채도는 성과 요인이 아니다 — 벗어난 것만 기록하고 쫓지 않는다 |
| **엣지(디테일량) 4.31 (플릿 3.11~10.52)** | 1,500만 영상이 **3.11 로 플릿 최저**다. 화면을 빽빽하게 채우는 것이 답이 아니다 |
| **LUFS -14.8 (레퍼런스 -18~-28)** | 우리가 제일 크다. 그러나 유튜브 표준이 -14 다. 레퍼런스가 낮은 것이지 우리가 틀린 게 아니다 |
| **WPM 222** | 레퍼런스 124~227 의 상단이지만 밴드 안이다. ICT·DTW(17.6만/2.2만)가 207~227 로 같은 자리 |
| **밝기 121 (상위권 197+)** | 흰 배경은 브랜드(다크블루 금융)를 버려야 도달한다. 100 이상 확보로 절충. **다음 실측 대상** |

## 4. ⛔ 측정에서 걸러낸 함정

| 함정 | 실측 |
|---|---|
| ffmpeg `loudnorm`·`silencedetect` 는 **stderr** 로 찍는다 | `execFileSync` 는 성공하면 stdout 만 준다 → LUFS 가 전부 null 이었다 |
| 유튜브 자동자막은 **롤업** — 같은 단어가 다음 큐에 다시 실린다 | 단순 중복 제거로는 WPM 이 356~664 로 튄다. 꼬리↔머리 겹침을 잘라야 124~227 이 나온다 |
| `textRowPct` 는 **자기정규화** 지표다 | 그 영상 분포로 임계를 잡아서 글자를 늘려도 값이 안 변한다. 절대 엣지량(`edgeAbs`)을 같이 봐야 한다 |
| 「자막띠」 자동 검출은 **자막이 아닐 수 있다** | ict-fvg 의 94~95% 는 차트 시간축, bagel 의 56~60% 는 마이크였다. **프레임을 뽑아 확인해야 확정** |
| 디졸브는 **컷이 아니다** | 9프레임 페이드는 프레임간 차가 1/9로 흩어져 컷 검출 0.0/분. 2프레임 안에 갈아끼워야 «컷» |
| 컷 프레임에서 **화면이 빈다** | `seg(f, a, a+2)` 는 f=a 에서 opacity 0 이다. `seg(f, a-2, a)` 로 해야 컷 순간에 이미 보인다 |
| 밝기를 **배경으로** 올리면 규칙 위반 | 플레이트 밝기 2.35배로 올렸더니 연기가 화면에서 제일 밝아졌다. 밝기는 균일 그라디언트로, 질감은 34% 로 |
