## 0. 목적

알파스코어(XS 엔진) 상위 데실의 T+3 시장조정 알파가 **실제 체결 환경에서도 실현되는지** 검증한다.
마케팅·UI 노출과 무관한 독립 트랙. 성공해야만 다음 단계(규모 확대·UI) 논의 자격이 생긴다.

| **B. 배관 테스트 (1주 왕복)** | 토스 실계좌로 최소단위 주문·정정·취소 수 회 — 파이프라인 검증만, 전략 아님. *(수정 2026-07-17: 토스 Open API에 모의투자/샌드박스 부재 실측 확인 → 원안 "모의투자 API"를 최소단위 실검증으로 대체)* | A 가동 + 키 연결 | ~$수십 |

## 2. 전략 규칙 (고정 — 재량 0)

- **시그널**: 매일 장마감 후 XS 엔진 산출 (22:10 UTC). 판정 엔진은 3파전(v1.0 적응/frozen/anti) 중 **라벨 15일 시점 롤링 IC 최고 변형** 하나를 시작 전 지정(그 후 변경 금지).
- **유니버스 필터**: xsScore 상위 데실(D0) ∩ mcap ≥ $2B ∩ price ≥ $5 ∩ 옵션구조 데이터 존재.
- **진입**: 필터 통과 상위 **10종목**, **동일가중**, 익일 **시가** 매수 (시장가).
- **청산**: 진입일 이후 **3번째 거래일의 종가** 전량 매도 (스코어일 D → 진입 D+1 시가 → 청산 D+4 종가. T+3 라벨 창과 정합. 손절·익절·재량 청산 없음).
- **거래일 판정**: 유니버스 중앙값 |1일 등락| > 0.05%인 날만 거래일로 인정 (signum-alpha-history의 유령 비거래일 행 방어 — §42.7 발견).
- **트랑슈**: 매일 1/3씩 진입하는 3-트랑슈 롤링 (하루 리스크 = 자본의 1/3).
- **재투자**: 청산 대금은 다음 트랑슈로 롤 (복리), 신규 입금 없음.

## 3. 규모·킬스위치 (C단계, 사용자 확정 필요)

- 총 자본: **$[사용자 결정: 제안 $1,000~3,000]** (고정, 증액은 새 사전등록으로만)
- 종목당: 총자본/30 (3트랑슈×10종목)
- **킬스위치 (자동 정지, 재개는 수동만)**:
  1. 주간 실현손실 ≥ 계좌의 **-3%** → 전량 청산·정지
  2. 시장조정 언더퍼폼 2주 연속 (실현수익 − SPY동기간 < 0) → 정지·원인 조사
  3. `mkt:killswitch`와 별도의 `trade:killswitch` (콘솔/수동) → 즉시 신규 진입 중단
  4. 체결 슬리피지가 예측 알파의 50% 초과 (10체결 롤링) → 정지 (전략이 체결비용을 못 이김)
- 기간: **8~12주** 고정. 조기 종료는 킬스위치로만.

## 4. 성공 기준 (사전 고정)

1. 시장조정 실현수익 > 0 (기간 전체, 수수료·슬리피지 차감 후)
2. 실현 알파와 그림자 예측(데실 adjF3)의 방향 정합 — 예측이 양(+)인 주에 실현도 양
3. 상기 미달 시 **실패로 기록**하고 규모 확대·UI 노출 논의 중단 (§42.3: 인샘플 포장 금지)
