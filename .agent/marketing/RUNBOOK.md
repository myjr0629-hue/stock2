## 0. 이 스케줄이 «실제로» 어떻게 도는가

- **크론 = 이 클로드 코드 세션 안의 반복 알람**이다. Vercel 도 서버도 아니다. `CronList` 로 확인하고 `CronCreate`/`CronDelete` 로 관리한다.
- 현재 **매시 :07 에 1개**가 돈다. 대표님이 컴퓨터를 계속 켜 두시므로 세션이 살아 있고, 이 구조가 정상 동작 조건이다.
- **깨우는 경로는 «크론 하나»뿐이다.** ScheduleWakeup(자기 예약)은 **쓰지 않는다** — 두 개를 같이 쓰면 한 시간에 두 번 돌아 캡을 낭비하고 기록이 꼬인다. 2026-09-17 에 이 중복을 제거했다.
- **반복 크론은 7일 뒤 자동 만료된다.** 그래서 **매 사이클 1단계에서 `CronList` 로 남은 수명을 확인**하고, 만료가 가까우면 그 자리에서 새로 만든다. 이건 선택이 아니라 절차다.
- Vercel 크론 44개 중 마케팅은 **0개**다. 프로덕션 자동화는 없고 **만들지 않는다**(대표 지시).

## 1. 사이클 절차 — 이 순서를 지킨다

```bash
cd ~/.gemini/antigravity/scratch/stock2
node scripts/mkt-plan.js slot      # ① 담당 구역 배정 (이게 이번 시간에 할 일이다)
node scripts/audit-expiration-selection.js --live   # ② 발행 게이트
```

1. **크론 수명 확인** — `CronList`. 7일 만료가 가까우면 재생성.
2. **담당 구역 배정** — `mkt-plan.js slot`. 출력이 곧 지시다. **골라서 하지 않는다.**
   - **실행 4개**: 가장 오래 방치된 열린 채널부터. 넷 다 처리한다.
   - **뚫기 2개**: 계정이 막힌 곳. **우회로를 실제로 시도한 뒤에만** 보류로 적는다(§22).
   - **확장 1개**: 신규 표면 발굴 → 실행 또는 티켓 → `channels.json` 등록.
3. **발행 게이트** — `audit-expiration-selection.js --live`. 실패가 하나라도 있으면 **발행 금지**하고 앱부터 고친다.
4. **발행** — 채널 성격에 맞게. 모든 게시물에 **앱 화면 또는 앱 카드 + 스마트링크 `?from=<채널>`**. 단 레딧·Quora·HN 은 **무링크 순수 가치**(앱명 0~1회).
5. **발행 즉시 기록·검증** — `node scripts/mkt-plan.js pub <채널> <URL>` + **공개 페이지에서 본문·이미지·링크 확인**. 검증 못 하면 «발행했다»고 쓰지 않는다.
6. **광고** — 콘솔이 살아 있으면 **기간을 «오늘»로 고정**하고 지출·설치·CPA + 키워드 단위를 읽는다. 이긴 키워드 확장, 진 키워드 정지. **예산·입찰 증액 금지.**
7. **기록** — `OUTREACH-LOG.md` 에 **과정·결과·개선사항**을 성공과 실패 모두 적는다. 판정이 뒤집히면 그 자리에서 정정한다.
8. **커밋·푸시** — `git add <경로>` (**-A 금지**) → 커밋 → 푸시.
9. **보고** — 한글. 대표 개입이 필요한 것은 티켓으로 쌓고 **한 번에** 보고한다.

## 4. 반복하면 안 되는 실수 (전부 내가 실제로 저질렀다)

1. **한 방법만 해 보고 «채널이 막혔다»로 적기** → 블루스카이 2주 유실. 이미지 첨부 경로는 넷이다: `setInputFiles` / `input[type=file] >> nth=0` / `drop` / `paste`. 플랫폼마다 답이 다르다.
2. **`const URL = "..."` 로 전역 URL 클래스 가리기** → `fetch` 가 전부 깨지고 try/catch 가 삼켜 «클릭 0건»이라는 거짓 판독이 나왔다.
3. **날짜 기준 혼동** → 귀속 키는 **ET 날짜**다. UTC·로컬로 조회하면 전부 0으로 보인다.
4. **`scrollIntoView` 직후 좌표 사용** → 스크롤이 끝나기 전이라 다른 행이 선택된다. 대기 후 **재측정**한다.
5. **자동완성 첫 항목을 확인 없이 Enter** → SaaSHub 에 없는 이름을 치니 무관한 제품이 선택됐다. **입력어와 정규화 일치할 때만** 선택.
6. **넓은 셀렉터로 드롭다운 클릭** → 푸터 링크를 눌러 입력한 폼이 통째로 날아갔다. **찾기와 클릭을 분리**한다.
7. **정책 문서 URL 추측** → 4개 전부 404. Zendesk 계열은 `/api/v2/help_center/articles/search.json?query=AI` 로 찾는다.
8. **광고 보고서 기간을 확인 안 하고 숫자 비교** → 30일치와 오늘치를 섞어 읽었다.
9. **자동화 상태를 과장·축소해 보고** → 크론은 «돌고 있었는데» 「자동화가 없다」로 들리게 말했다. **있는 그대로 적는다.**
10. **ego 스크립트에서 `require`** → ESM 이라 죽는다. `await import('node:fs')`.
