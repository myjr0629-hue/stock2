> **목적은 하나 — 프로필을 본 사람이 «앱을 깔게» 만드는 것.**
> 사이트 방문이 아니다. 프로필의 모든 칸은 설치로 가는 계단이어야 한다.

**자동 다발 게시로는 한 명도 못 늘렸다.** 프로필이 설치로 이어지지 않으면
게시물 수는 아무 의미가 없다. 그래서 «게시»보다 «프로필»이 먼저다.

## 5칸 규격 — 모든 채널에 동일 적용

### 1. 이름 — 검색되는 이름
```
SIGNUM HQ
```
- 부제를 허용하는 채널(틱톡·유튜브)은 `SIGNUM HQ · 미국주식 데이터` 처럼
  **현지어 검색어**를 붙인다. 검색 후보군에 들어가는 유일한 칸이다.

### 2. 소개 — 「무엇을 보여주는지」 → 「왜 앱인지」 → 「공짜」
세 문장을 이 순서로. 형용사 금지, 지표 이름으로 말한다.

```
en: What institutions are doing — options flow, dark pool %, GEX, max pain.
    Daily briefings before the open. Free on iOS & Android.
ko: 기관이 실제로 움직인 흔적 — 옵션 플로우·다크풀·감마(GEX)·맥스페인.
    장 열기 전 브리핑, 장 마감 리포트. iOS·안드로이드 무료.
ja: 機関投資家の動きを解読 — オプションフロー、ダークプール、ガンマ(GEX)、
    マックスペイン。毎営業日、無料。iOS・Android。
```
- **150자 제한 채널이 많다**(Threads·Instagram). 짧은 판을 따로 둔다.
- 마지막 줄은 언제나 «무료 + 플랫폼». 설치 장벽을 먼저 없앤다.

### 3. 링크 — 반드시 스마트링크 + `?from=` 태그
```
https://signumhq.com/app?from=<채널>_bio      SIGNUM HQ
https://signumhq.com/app-uc?from=<채널>_bio   Undercurrent
https://signumhq.com/app-wim?from=<채널>_bio  Why'd It Move?
```
- `/app` 는 UA 분기 스마트링크 — 안드로이드는 Play(+install referrer),
  iOS 는 App Store 로 간다. **스토어 링크를 직접 쓰지 않는다.**
- 태그는 `[a-z0-9_]` 만. **하이픈을 쓰면 설치 측정이 통째로 사라진다.**
  ([[smartlink-from-tag-hyphen-eats-attribution]])

### 4. 이미지 — 아바타는 앱 아이콘과 «같은 것»
- 아바타: `public/icons/icon-512x512.png` (앱 아이콘과 동일해야
  스토어에서 다시 만났을 때 알아본다)
- 배너: `.agent/assets/x-banner-1500x500.png`

### 5. 고정/첫인상 — 이 계정이 무엇인지 한 장으로
고정 게시물이 가능한 채널(X·Threads·Reddit)은 **앱 링크가 든 고정글**을 둔다.

## 하지 않는 것

- **버퍼 자동발행** — 2026-09-01 영구 정지. 팔로워 0 에 다발 게시는 도달 0 을
  만들 뿐이고 채널이 스팸으로 읽힌다.
- **사이트 링크** — 목적은 앱 설치다. 프로필 링크는 언제나 `/app*`.
- **승인 없는 게시** — 프로필 정비는 내가 하고, 공개 게시는 대표가 「올려」 할 때만.
