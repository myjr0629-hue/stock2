## 3. 코드 설계 (승인 받을 확정안)
- **오퍼 1개**: 이름 «SIGNUM PRO — 1 Month Free (Launch)» · 기간 ONE_MONTH · 대상 NEW + EXPIRED(기존 유료 사용자 제외) · 도입가 오퍼와 교체(REPLACE_INTRO_OFFERS)
- **맞춤 코드(애플, «누르면 적용»용)** — 채널 이름이 코드 글자에 보이게: `WEBPRO` · `THREADSPRO` · `BSKYPRO` · `XPRO` · `NOTEJP` · `NAVERPRO` · `IHPRO` · `PHPRO`(프로덕트헌트 런치용). 코드마다 **사용 한도 = 게시물에 적는 수량**, 만료 = 게시물에 적는 날짜
- **일회용 코드(애플·구글, «직접 입력»용)** — 번호 붙인 목록으로 소량 배포(레딧·MacRumors·뽐뿌 등), 구글은 자판기로 1장씩
- 방식별 효과를 재려고 **채널마다 링크용·입력용을 나눈다** — 스토어의 «코드별 사용 수»만으로 어느 방식이 더 쓰이는지 나온다

## 6. «남들보다 얻는 기분» 장치 — 전부 사실이어야 한다
- 코드 이름에 채널: «Threads 보는 분들 전용 THREADSPRO»
- 수량·마감을 실제 한도대로: «선착순 50명 · 10/31까지»(스토어 한도 = 표기 숫자)
- 남은 수량은 스토어 사용 수를 읽을 수 있을 때만 표시
- 일회용 번호 목록은 «쓰신 번호를 댓글로» — 다음 사람을 위한 공동체 느낌(뽐뿌 관행)
- 금지: 가짜 마감·가짜 재고(FTC 다크패턴·일본 景表法 有利誤認·공정위 다크패턴 가이드)
