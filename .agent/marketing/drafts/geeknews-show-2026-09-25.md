## 내용

미국 증시를 보는 앱 세 개를 만들어 운영하고 있습니다. 기술적으로 가장 많이 배운 건 데이터 쪽이라 그 얘기를 적습니다.

**1. 벤더가 끊기면 «에러 없이 틀린 숫자»가 남는다**
다크풀 거래량을 벤더 API 로 받다가 권한이 끊겼습니다. 문제는 화면이 «비지» 않았다는 것입니다. 파생 지표들이 기본값으로 채워져 그럴듯한 숫자를 계속 보여줬습니다. 200 OK 였고 로그도 조용했습니다. 이후로는 원천을 먼저 찾습니다 — 다크풀은 FINRA, 8-K 는 SEC, 국채는 재무부에 무인증 공개 API 가 있습니다. 벤더는 대개 그걸 재포장합니다.

**2. 「거래일」로 나이를 재야 한다**
캐시 TTL 을 갱신 주기로 착각해서 분석 결과가 24~35시간 묶인 적이 있습니다. 더 재밌는 건 휴장일이었습니다. 「장이 닫혔으니 마지막 세션 = 어제」라고 가정했더니 표시가 한 세션씩 밀렸고, 어떤 종목은 −4.9% 가 −0.2% 로 보였습니다. 시장 데이터의 나이는 «시간»이 아니라 «거래일»로 재야 합니다.

**3. 3개 언어를 하면 고정폭이 전부 깨진다**
한국어·영어·일본어를 같이 냈습니다. 같은 문구가 언어마다 1.6배까지 길어져서, 「가장 긴 로케일 기준」으로 폭을 잡고 세 로케일을 기계로 전수 검사하지 않으면 반드시 하나가 잘립니다. 그리고 `<html lang>` 을 하드코딩했다가 한국어 페이지가 통째로 중복 색인된 적도 있습니다.

**4. 앱은 Capacitor 셸 + Next.js 입니다**
`server.url` 이 «경로 접두사»로 동작하는 걸 몰라서, `allowNavigation` 없이 같은 도메인의 다른 경로로 이동하면 시스템 브라우저가 떴습니다. 「앱은 그대로인데 갑자기 크롬 창이 뜬다」는 버그의 원인이었습니다.

무료이고 가입도 없습니다. 한국어·영어·일본어로 다 볼 수 있습니다. 틀린 부분이나 더 나은 원천이 있으면 알려주세요.
