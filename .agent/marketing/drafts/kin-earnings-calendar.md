# 지식iN 답변 초안 — 「미국주식 실적 발표 모아놓은 사이트 있나요?」 (docId 493664277)

**상태**: 2026-09-19 04:5x KST, 브라우저 진입 직전에 대표가 taskspace 를 잡아 중단. 제어가 돌아오면 이 글을 그대로 올린다.
**규칙**: 본문 링크 금지(광고 신고 대상) · 앱 이름 1회 · 예측·투자권유 금지 · 계정 `iEldora`
**진입**: 주소를 짐작하지 말고 지식iN 검색(`미국주식 실적 발표 사이트`, 최신순)에서 «눌러서» 들어간다.

무료로 볼 수 있는 곳이 몇 군데 있고, 고르는 기준이 하나 있습니다.

**1. 발표 «시점»을 장전/장후로 구분해 주는지**
미국 기업 실적은 대부분 정규장 밖에서 나옵니다. 장 시작 전(BMO)과 장 마감 후(AMC)로 나뉘는데,
이걸 구분해 주지 않는 달력은 한국에서 보기에 사실상 쓸모가 없습니다. 새벽에 볼지 아침에 볼지가 달라지니까요.

**2. 한국시간으로 바꿔 주는지**
서머타임 때문에 미국 장 시간이 1시간씩 움직입니다. 현지시간만 적혀 있으면 매번 직접 환산해야 하고,
전환 주간에 한 번씩 틀립니다.

**3. 컨센서스(예상치)를 같이 보여 주는지**
실적 자체보다 «예상 대비»가 주가를 움직입니다. 숫자만 있고 예상치가 없으면 발표를 보고도 해석이 안 됩니다.

무료로 쓸 만한 곳:
- 각 증권사 HTS/MTS 의 해외주식 실적 일정 — 이미 계좌가 있으면 가장 빠릅니다. 다만 BMO/AMC 구분이
  빠진 곳이 있어 한 번 확인해 보시는 게 좋습니다.
- 야후 파이낸스 Earnings Calendar — 영문이고 현지시간이지만 커버리지가 넓습니다.
- 나스닥 공식 사이트의 실적 캘린더 — 종목별 예상치가 같이 붙습니다.

저는 SIGNUM HQ 라는 무료 앱을 만들고 있는데, 거기서도 이번 주 실적을 장전/장후로 나눠 한국시간으로 보여 줍니다.
회원가입 없이 열립니다. 만든 사람이라 밝히고 적습니다 — 위의 세 기준으로 직접 비교해 보시는 게 더 중요합니다.

**덧붙임**: 실적 달력을 볼 때 «발표 후 주가»를 같이 보실 텐데, 그 숫자가 정규장 종가인지 시간외 가격인지
구분해서 보셔야 합니다. 실적은 장 밖에서 나오니 발표 직후 움직임은 대부분 시간외입니다.
앱이나 사이트가 그걸 표시해 주지 않으면 같은 숫자를 다르게 읽게 됩니다.
