# 애플 «실제» 키워드 인기도 — 한국 (2026-09-02)

> 출처: Apple Ads Advanced 콘솔 → 캠페인 생성 → 광고그룹 → 키워드 추가 → 「제품 추천」 패널
> 척도: 애플 공식 `apui-wc-popularity-dots` 의 `aria-valuenow` (0~5)
> **광고비 0원. 계정만 있으면 읽힌다.**
>
> 왜 중요한가: 그동안 우리는 「상위 5개 앱 평점 중앙값」이라는 **대리지표**로
> 추정했다. 이건 애플이 직접 주는 **진짜 검색 수요**다.

## 뽑는 법 (재현)

Apple Ads → 캠페인 생성 → 앱/지면/국가 선택 → 계속 → 광고그룹 → 「광고 그룹에 키워드 추가」
왼쪽 「제품 추천」 검색창에 씨앗 단어를 넣으면 관련어 + 인기도가 나온다.
DOM 에서 한 번에 긁는 스니펫:

```js
const box = document.querySelector('.keyword-module__column--recommendations');
[...box.querySelectorAll('apui-wc-popularity-dots')].map(d => {
  let p = d; for (let i=0;i<5;i++){ p=p.parentElement;
    const t=p.innerText.split('\n')[0].trim(); if (t&&t.length<40) return [t, +d.getAttribute('aria-valuenow')]; }
});
```
⚠️ 결과가 **한 박자 늦게** 갱신된다 — 이전 결과와 달라질 때까지 폴링할 것(안 하면 앞 씨앗의 답을 읽는다).

## ★ 계측기 함정 — 오른쪽 «표»는 못 믿는다

키워드 추가 화면은 두 곳에서 인기도를 보여준다.
- **왼쪽 「제품 추천」 패널 = 진짜 값** (차등이 나온다)
- **오른쪽 「키워드」 표 = 대부분 1 로 기본 표시** (실측 아님)

일본에서 같은 40개 단어를 두 곳으로 재봤더니:

| 단어 | 오른쪽 표 | 왼쪽 패널 |
|---|---:|---:|
| ニュース | 1 | **4** |
| カレンダー | 1 | **4** |
| 投資 | 1 | **3** |
| クイズ | 1 | **3** |

→ **반드시 왼쪽 패널로 잴 것.** 오른쪽 표만 보고 «다 죽었다»고 판단하면 오진이다.
(한국·미국 수치는 전부 왼쪽 패널로 잰 값이라 유효하다.)
