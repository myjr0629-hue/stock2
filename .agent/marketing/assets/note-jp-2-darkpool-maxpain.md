# note.com JP #2 초안 (t113, 9/17 JST 발행) — 「株価アプリ」 검색 의도어 제목

## 제목
米国株アプリで「ダークプール比率」と「マックスペイン」を毎日見るようになって変わったこと

## 본문 (execCommand 단락 삽입용 — 1단락 1줄)
米国株を見るとき、値動きとニュースだけを追っていると「なぜ今日この株が動いたのか」が分からないまま終わることが多い。私は SIGNUM HQ という無料アプリで、1銘柄につき「価格・オプション・ダークプール」を1画面で見る習慣にしてから、値動きの読み方が変わった。

【ダークプール比率とは】取引所の外（ダークプール）で成立した出来高の割合。SIGNUM HQ では銘柄ごとの比率と「市場平均との差」を出す。例えば NVDA が 39.9%、市場平均が 49.1% なら、この銘柄は取引所での売買が相対的に多い、という読み方になる。比率そのものより「平均との差」と「前日比」を見る。

【マックスペインとは】満期日にオプション保有者の損益合計が最小になる権利行使価格。ここに株価が引き寄せられると言われるが、私は「磁石」とは考えない。月次満期のように建玉が長期間積み上がったケースでは、株価とマックスペインが 10% 以上離れていることも普通で、それは「過去にどこでポジションが作られたか」の足跡にすぎない。

【ガンマフリップとは】ディーラーのネットガンマの符号が変わる価格。上にいるか下にいるかで、ヘッジ売買が値動きを「抑える」方向か「増幅する」方向かが変わる。指数（SPY）はプラスガンマ、個別株はマイナスガンマ、という日が多く、同じニュースでも動き方が違う理由がここにある。

【アプリでの見方（無料）】銘柄を検索 → Command 画面。上から 価格 → ダークプール比率（市場平均との差） → マックスペイン／ガンマフリップ／プレミアム合計 → RSI・VWAP・レンジ → ボラティリティ。英語・日本語・韓国語対応、iOS と Android、登録不要。

【注意】これらは前日終値時点の建玉に基づく数字で、日中のフローで変わる。予測ではなく「今どこにポジションが集中しているか」の説明として使う。投資助言ではない。

アプリ: https://www.signumhq.com/app?from=note （※ 発행 시 Shift+End → リンク → 適用）
