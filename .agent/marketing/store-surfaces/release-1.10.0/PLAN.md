# SIGNUM iOS 1.10.0 · Android 1.3.0 스토어 자료 묶음 (2026-09-30 03시 KST)

바이너리 제출은 대표 승인 대기. 이 묶음은 **파일 + 적용 스크립트**까지다 — ASC 에 버전을 만들거나 기존 버전을 바꾸지 않았다.

## 0. 적용 순서 (1.10.0 버전이 PREPARE_FOR_SUBMISSION 이 된 뒤)
1. 위젯 재캡처가 들어오면 → `bash scripts/store-release-widget-finish.sh <이 폴더>` (위젯 칸 채움 · 이벤트·Play 위젯 이미지)

3. 적용 → 같은 명령 + `--apply` (실시간 공용 연결이 운영에 반영됐으면 `--variant B`)

4. 심사 제출은 기존 릴리스 절차(대표 승인)로. 스크립트는 제출하지 않는다.
5. 1.10.0 승인 뒤 → 위젯 이벤트: `python3 scripts/asc_inapp_event.py 6783130444 <이 폴더>/event-widget/event-widget-spec.json --dry-run` → 우선순위 확정 후 실행

  - 대안(대표 결정): 시험을 1.10.0 출시 때 멈추고 ko 도 교체 — 파일은 `screenshots/ko/` 에 준비됨(번들 `locales` 에 `"ko": "ko"` 한 줄).
