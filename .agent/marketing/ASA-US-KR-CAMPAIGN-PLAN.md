전제: **1.9 메타데이터가 스토어에 반영된 뒤에만 켠다.** 반영 전엔 `stock market` 이
      우리 지면에 한 글자도 없어서 관련성이 낮고, $6.33 경매에서 돈만 태운다.

## 공통 설정 (3개 캠페인 동일)
- 지면: **검색 결과만** (투데이/검색탭/제품페이지 안 씀 — 전환율이 낮다)
- 입찰: **입찰 관리(수동)**. `Maximize Conversions` 는 **Search Match 를 강제**하므로 금지
- **Search Match OFF** (광고그룹마다 기본 ON 이라 직접 꺼야 한다)
- 검색 유형: **완전일치 `[키워드]`** 만
- 타겟: 적합한 모든 사용자
- ⚠️ 시간대별 집행(dayparting)은 Apple Ads 에 **없다**. 시작일/종료일만 있다

### 콘솔 조작 메모 (다음에 헤매지 말 것)
* 주소는 `app-ads.apple.com` (`app.searchads.apple.com` 은 404)
* 캠페인 생성: `/cm/app/<appId>/campaign` · 광고그룹 추가: `/cm/app/<appId>/campaign/<campId>/adgroup`
* **국가 선택 필드는 타이핑만으로 필터가 안 걸린다.** 마지막 글자를 지웠다 다시 쳐야 목록이 좁혀진다

* **Search Match 는 광고그룹마다 기본 ON** 이라 매번 직접 꺼야 한다
* 폼이 렌더되기 전에 입력하면 «조용히 빈 칸»이 된다 — 입력 후 반드시 스크린샷으로 확인
