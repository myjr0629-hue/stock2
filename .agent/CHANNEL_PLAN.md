## 1. 소재를 고르는 법 — 「문 × 이상값」

⛔ **감으로 고르지 않는다.** 두 조건을 «둘 다» 만족해야 소재다.

### 문(door) — 사람들이 이미 검색하고 있는가

값 = **소형채널(구독 10만 미만) 조회 중앙**. 원시 조회 중앙과 «절대 섞지 않는다».
(2026-08-21 「금 84,262 vs 실제 256」 사건이 자를 섞어서 났다.)

**여지(room)** = 상위 결과 중 소형채널이 차지한 비율.
⛔ **수요만 크고 여지가 없으면 들어가지 않는다.** 0구독 채널은 대형 채널을 못 이긴다.

### 이상값(anomaly) — 우리만 낼 수 있는 숫자가 있는가

우리 데이터로 계산한 값 + 비교 기준 + n≥20 + (p<0.05 또는 백분위 ≤10/≥90).
`scripts/insight-check.mjs` 가 이걸 막는다.

⛔ **남이 발표한 숫자를 옮긴 것은 인사이트가 아니다.**

## 1-B. ★ 소재는 «네 칸»이다 — 기준선은 뒤에 붙이는 게 아니다

⛔ 대표 지적 2026-08-21: "기준선은 소재 선정 단계에서 정했어야지. 그런 구조 자체를 만들라는 것이야"

지금까지 소재를 「문 × 이상값」으로만 골랐다. 그래서 통계적 이상값은 나왔지만
«오늘 밤 확인할 숫자»가 없었고, 결론이 「통화 베팅이다」처럼 추상으로 끝났다.

**사람들이 더 궁금해하는 건 수치가 아니라 이야기다** —
「세상에 무슨 일이 벌어졌고 · 그게 이렇게 해석되고 · 그게 이렇게 수치로 나타난다」

| 칸 | 뜻 | 어디서 |
|---|---|---|
| **① 사건** | 세상에서 무슨 일이 벌어졌나 | `scripts/news-radar.mjs` (가디언 뉴스·캘린더·연준) |
| **② 영향 경로** | 그게 **왜** 시장에 닿나 — 한 줄 | 가디언 분석 + 우리 해석. **이 줄이 스토리다** |
| **③ 우리 수치** | 그 영향이 **우리 데이터**에 어떻게 찍혔나 | `close-brief.mjs` + 사전등록 `edge-*.mjs` |
| **④ 기준선** | **오늘 밤 확인할 숫자 하나** | news-radar 후보에서 «하나» |

⛔ **하나라도 비면 만들지 않는다.**
   ③이 없으면 뉴스 재방송이고, ④가 없으면 추상으로 끝난다.
   `topic-check` 가 plan 의 `story` 블록으로 이 넷을 «실제로 막는다».

⛔ **기준선은 «하나»다.** 3소스가 합의한 유일한 항목이다 —
   경제사냥꾼 「10년물 4.7%」 / 외부 분석 「맥스페인 128달러」 / 우리 결함 「통화 베팅이다」.
   일본 1호는 3개를 줬다 (감마 220 · 주가 216.85 · 맥스페인 210). 2호부터 하나로 좁힌다.

## 4. 만드는 과정 — 이 순서를 바꾸지 않는다

```
① 소재    문 × 이상값        scripts/topic-radar.mjs · jp-deep.mjs · us-deep.mjs
② 측정    사전등록 후 계산     scripts/edge-*.mjs → .agent/_edge_*.json
③ 대본    반박 훅 → 근거 → 반전 → 오늘의 위치
④ 음성    tts-beats           🇺🇸 Adam / 🇯🇵 Rio (SIGNUM_VOICE)
⑤ 렌더    remotion
⑥ 마감    finish-video        -14 LUFS + 밝기 90~150 + 프레임0 썸네일
⑦ 게이트  shorts-gate         6겹 전부 통과해야 업로드
⑧ 업로드  yt-upload           비공개+예약. 개시는 대표
⑨ 댓글    yt-comment          공개 «후» (비공개는 403)
```

### 대본 골격

| 비트 | 역할 | |
|---|---|---|
| 훅 | 반박·질문으로 연다 | ⛔ 선언형 금지 (우리 32편 100% 선언이었다) |
| 1 | 통념을 세운다 | 「다들 이렇게 말한다」 |
| 2 | 우리가 쟀다 | 표본 수를 화면에 |
| 3 | 결과 | 비교 카드 |
| 4 | **반전** | ★ 「너도 몰랐지」— `role:'verdict'` (컷에서 절대 안 버려진다) |
| 5 | 오늘의 위치 | 실시간 값 · 종목 카드 |

⛔ **자막에 숫자를 넣지 않는다.** 숫자는 화면 카드가 나른다 (레퍼런스 중앙 1.0%).
⛔ **인과를 단정하지 않는다.** 「기관이 함정을 팠다」 금지. 위치와 분포만 보여준다.

### 제목 — 과감하게

- 수요 어휘를 **맨 앞**에
- 「唯一の」「~を除いて」「なぜ~だけ」처럼 **궁금증을 거는 한 단어**
- **종목이 나오면 `hook.syms` 필수** — 게이트가 막는다. 폰 썸네일 210px 에서 사명은 뭉개지고 로고는 읽힌다
- 1문장. 이모지 금지. 물음표는 허용(금지 근거가 없었다)

## 6. 외부 에이전트 소재 — 받으면 이렇게 한다

대표가 다른 에이전트의 제목·소재를 주면 **버리지 않는다.** 틀을 살리고 사실만 고친다.

1. **날짜·인물·수치를 실측으로 검증한다** (FMP·우리 API·웹)
2. 틀린 것은 «무엇이 틀렸는지» 숫자로 보고한다
3. **틀이 좋으면 사실만 갈아끼워 쓴다** — 좋은 프레임은 차용한다
4. 우리 데이터로 실증 못 하는 주장은 «빼고» 만든다

**실제 사례 (2026-08-21)**

| 받은 소재 | 검증 결과 |
|---|---|
| 「잭슨홀에서 파월이…」 | ✗ 파월은 의장이 아니다. **케빈 워시** 2026-05-22 취임. 잭슨홀 8/27~29, 첫 기조연설 8/28 |
| 「NVDA 실적 8/26」 | ✔ 맞다. 내가 9/30 이라고 반려했던 게 틀렸다 (과거 간격 91~98일로 교차검증) |
| 「다크풀 은밀한 매집」 | △ 데이터는 있으나 `darkPoolPct` 는 «비중»이지 «방향»이 아니다. 매집이라 쓰면 거짓 |
