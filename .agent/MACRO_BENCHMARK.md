## 2. ⛔ 우리가 몰랐던 것 — 제목에 「검색되는 말」이 없다

발행 22편의 제목을 측정 수요 어휘 91개와 기계 대조했다.

| | |
|---|---|
| 수요 어휘가 제목에 들어간 편 | **1 / 22 (4.5%)** |
| 그 1편의 수요 | "amd stock" = **286** (사실상 0) |
| 22편 조회 중앙 | **42** |

**21편은 「아무도 검색하지 않는 문장」이었다.**
이것이 조회 중앙 42의 구조적 원인이다. 영상 품질 이전의 문제다.
→ `scripts/topic-check.mjs` 가 이 항목을 막는다. 소급 검사 결과 **22편 전부 불통과**.

## 4. ⛔ 대본 문법 — 여기서 격차가 가장 크다

조회 32만~84만 해설 7편의 자동자막을 롤업 중복 제거 후 계량했다.

| 항목 | 레퍼런스 중앙 | **우리 32편 중앙** | 판정 |
|---|---|---|---|
| 훅 유형 | 선언4 · **반박2 · 질문1** | **선언 32 / 32** | ✗ 우리는 100% 선언 |
| 숫자 밀도 | **1.0%** | 2.6% | ✗ 2.6배 — 자료 낭독처럼 들린다 |
| 우리·너 비율 | **3.9%** | 1.9% | ✗ 절반 — 남 얘기처럼 들린다 |
| 단어/큐 | 6.9 | 7.1 | ✔ |
| WPM | 195 | 222 | △ 빠르다 |

### 레퍼런스 훅 원문 — 이것이 「흐름의 기본」이다

| 조회 | 유형 | 첫 마디 |
|---|---|---|
| 835,584 | 선언(반전) | *Inflation this, inflation that. Babe, you are worried about the wrong thing* |
| 709,501 | **반박** | *Hold on. Let me get this straight. You're an expert in the economy, right?* |
| 692,849 | 선언(자기부정) | *You never like to predict a recession — people like me have predicted nine of the last three* |
| 350,597 | **질문** | *Are we going to enter a recession this year?* |
| 333,262 | **반박** | *Okay. Yeah. The AI bubble. Everyone wants to know. Is it real?* |
| 322,276 | 선언(대비) | *Gold is valuable, but right now it's **crazy** valuable* |

**공통 구조**: 훅에 숫자가 없다. 훅은 «긴장»을 만들고, 숫자는 그 뒤에 근거로 온다.
우리는 훅부터 숫자를 던졌다 — 그래서 「자료」로 들리고 넘긴다.

→ `scripts/script-check.mjs` 가 이 네 항목을 막는다.

## 5. ⛔ 동음이의 오염 — 「ai bubble」의 함정

"is the ai bubble popping" 검색 상위 19편 중 **4편(21%)이 게임 밈**
(*"We Did It Triple T, We Popped The AI Bubble"* — 금융과 무관, 27만·26만·5만·2만회).

수요가 커도 **검색 유입이 우리 주제로 오지 않는 소재**가 있다.
→ 게이트 항목 `동음이의 오염 <= 40%`.
