## 2. 알파 지도 — 어디가 신호, 어디가 노이즈 (근거기반)
**원칙: 신호강도 ∝ 물리적 전달경로의 직접성**(원유 배럴·재고 미사일·대만 웨이퍼). 물리 연결 없으면 노이즈/맥락.

✅ **되는 4클러스터**
- **에너지/원유** — 호르무즈·수에즈 초크포인트. 가장 강·즉각(호르무즈 보도 WTI +6.7%·XLE +3.1%, **천연가스는 −1.5%** = 원유 특정적 = 진짜 공급신호). 타깃: XLE·XOM·OXY·유조선(FRO·STNG·TNK).
- **방산** — 분쟁→재고 소진(패트리엇·JASSM). LMT·RTX·NOC·AXON 사상최고. 클린·반복적.
- **반도체** — 대만 리스크→TSM·NVDA·AVGO·AMD. 단 **에피소드성 꼬리위험**(상시 아님), 평균회귀 → **역발상 미시구조 읽기**가 가치.
- **해운/운임** — 홍해·수에즈→ZIM·FRO·STNG + 수입의존 소매/자동차. 물리적·측정가능.

❌ **노이즈**: "지정학 심리점수→지수 방향"(역사적 S&P −5~7% 후 6~8주 회복 = 평균회귀), 물리연결 없는 일반 "긴장". 네이키드 뉴스피드(미시구조 오버레이 없으면 그냥 열등한 뉴스앱).

**프로 선례**: Bloomberg GEO·GDELT·Predata·Kpler·RANE 전부 지정학을 **방향예측이 아니라 리스크 팩터 + 확인 필터**로만 사용. = 우리 컴플라이언스 프레이밍과 정확히 일치.

## 3. 유기적 융합 아키텍처 (핵심 IP)

```
[촉매] 지정학 이벤트 (GDELT / WM get-news-intelligence·get-chokepoint-status)
   → [물리 사슬] 초크포인트/원자재 (IMF PortWatch / WM get-energy-intelligence·compute-energy-shock)
      → [노출 바스켓] 섹터·티커 자동매핑 (사전정의 4클러스터 바스켓 / WM get-sector-dependency)
         → [증거] SIGNUM 미시구조: 다크풀% · 옵션 플로우/스윕 · GEX · 맥스페인 (우리 것)
            → [산출물] "스마트머니 선포지션?" 괴리 카드 + AI 브리핑 (UC 괴리엔진 + Bedrock 재사용)
```

**시그니처 산출물 = "이 이벤트 대비, 큰손은 이미 움직였나 / 아직인가"** (관찰형·과거시제).

### 4개 워크드 예시 (전부 관찰형)
- **A. 호르무즈 긴장** → 원유 리스크프리미엄 → XLE·XOM·OXY·유조선 → **헤드라인 이전 2세션 다크풀 프린트 + OTM 콜 스윕이 선행했나?** → "다크풀 먼저→콜스윕" 수렴이 고신뢰 패턴. **가장 강한 예시.**
- **B. 이스라엘·이란 타격** → 방산 재고 → LMT·RTX·NOC → **에스컬레이션 헤드라인 전 콜/OI·GEX가 방어적으로 쌓였나?** 선행 없으면 "헤드라인 주도·늦음"으로 프레이밍.
- **C. 대만 헤드라인** → 반도체 셀오프 → NVDA·AMD·TSM → **역발상 읽기**: 헤드라인 약세를 기관이 다크풀로 *매집*(풋 매도·적봉 다크풀 매수)하나, 진짜 디리스크(풋 스윕·딜러 숏감마)인가. "헤드라인은 팔라는데 플로우는 매집" = 우리 엣지 실증.
- **D. 홍해/수에즈 교란** → 운임·에너지·수입소매 → ZIM·FRO·STNG → 운임 스파이크를 해운주 콜플로우·다크풀이 선행했나. 호르무즈와 동일 템플릿.

## 4. SIGNUM 구현 계획 (기존 자원 재사용)

**재사용(신규 백엔드 최소화)**:
- **UC 괴리 스코어보드 엔진** — 이미 "시그널 기록→D+1/D+3 판정→전적" 문법 보유. 이벤트-대비-포지션 괴리에 그대로 적용.
- **computeOnePipe / IntelQuote** — 티커별 다크풀·PCR·GEX·맥스페인 실측(이미 있음).
- **Bedrock AI 브리핑** — 이벤트 요약+미시구조 해석을 관찰형으로 생성(이미 3언어 파이프라인).
- **Redis + Vercel 크론** — 트리거 폴링·캐시(WM은 poll-based·stale 봉투; 우리 serveSWR와 동형).
- **푸시 인프라** — "내 워치리스트 티커가 지정학 이벤트에 노출됐고 플로우가 선행" 알림(레이더/시그넘 공유).

**신규(작음)**:
1. **지정학 트리거 인제스트** — 경로②면 WM `get-chokepoint-status`·`get-energy-intelligence`·`search-gdelt-documents`; 경로③이면 GDELT + PortWatch + EIA 직접. 4클러스터만.
2. **이벤트→바스켓 매핑 테이블** — 초크포인트/원자재/분쟁 → 섹터·티커 바스켓(사전정의, 4클러스터). WM `get-sector-dependency`·`compute-energy-shock`가 참고표.
3. **융합 카드 UI** — Command/Intel에 "지정학 노출 + 스마트머니 선포지션" 패널(관찰 캡션 자동생성, 레이더 배당탭 톤).
4. **컴플라이언스 스캔** — 예측 프레이밍 필터 재사용([[predictive-framing-forbidden-in-posts]]).

**소비 권장(경로②)**: 셀프호스트·MCP 금지. **호스티드 REST를 서버사이드 fetch + `POST /api/batch/v1/execute`(≤20) + Redis 캐시**(초크포인트~10분·CII/브리프 길게·시세 짧게). Starter 1k/day는 캐시+배치로만 감당.

## 6. 노력·비용·타이밍
- **경로② 검증 MVP**: ~2–4일(4클러스터 트리거+융합카드 1종), **$99.99/mo**(검증기간만). ToS 재배포/표시 확인 필수.
- **경로③ 프로덕션**: ~1–2주(GDELT+PortWatch+EIA 인제스트 + 4바스켓 + 괴리엔진 배선 + 3언어 브리핑), **$0 상시**. 완전 우리 것·의존 없음.
- **타이밍 주의**: SIGNUM은 세금→애드몹 대기 중, WIM/레이더 제출 큐. 이건 **SIGNUM 플래그십 강화**라 런치큐와 경합 → "지금 착수 vs 런치 후" 대표 판단 필요. 단 **검증 MVP는 저비용이라 병행 가능**.
