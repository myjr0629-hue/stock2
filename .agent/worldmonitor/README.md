## 30초 결론
- **코드 라이선스 = AGPL-3.0-only**(MIT 아님) → worldmonitor 코드/집계는 **접목 안 함**. "설계 참고서 + 검증용 유료 데이터탭"으로만.
- **진짜 가치 = 개념 + 검증된 무료 소스 맵.** 우리는 **퍼미시브/공개 소스(GDELT·IMF PortWatch·EIA·CFTC COT·SEC EDGAR·FRED·USGS·OFAC)**만 직접 소싱 → 우리 옵션 미시구조와 융합.
- **최고 추가 알파는 "더 많은 지정학"이 아니라 공짜 포지셔닝 데이터**: COT×GEX("갇힌 두 군중"), SEC Form4 확신스택, FRED 레짐게이트 — 셋 다 공짜·저노력·컴플라 안전, 지정학 없이도 즉시 SIGNUM 강화.
- **알파 4클러스터**: 에너지/원유(호르무즈·수에즈)·방산(분쟁)·반도체(대만)·해운(홍해). 그 밖 "지정학→지수방향"은 노이즈.
- **⛔ 피할 것**: ACLED(유료+대체물/AI학습 금지), OpenSky·adsb.fi(상업금지), Kalshi(상업표시 서면동의).
- **컴플라이언스**: 관찰형·출처명기·과거/현재시제. "가격에 뭘 의미/사라" 금지.
