# World Monitor × SIGNUM — 앱 UX 표현 (정본) — 2026-07-23

> "적용 시 무엇을 유의미하게 보여주고, SIGNUM 앱에 어떻게 구현/표현해 사용자가 알 수 있게 하나" 보고. (SIGNUM 실제 화면: Dashboard·Guardian·Command·Flow·Intel)

## 관통 원리 — 하나의 UI 언어 "positioning readout"
모든 신호를 한 문장으로 수렴:
> **"이 촉매/지표에 스마트머니가 이미 포지션 잡았나? — 예 / 아니오 / 혼재 + 증거(다크풀%·콜스윕·COT·인사이더)"**

→ 지정학·COT·인사이더가 전부 같은 카드 문법으로 표현돼 **"별도 뉴스탭 볼트온"이 아니라 앱 전체에 유기적으로 흐름.** 별도 "지정학 탭"으로 뉴스앱과 경쟁하지 않고, 기존 종목/시장 화면에 **"왜 움직이나·누가 알았나" 레이어**로 스며듦.

## A. 지정학/정책 촉매 → "이미 포지션?" 괴리 (플래그십)
**무엇을 보여주나 (실예):**
```
🔴 호르무즈 통항 다주 최저 · IMF PortWatch · 14:20 UTC
   초크포인트 → 원유 → 노출: XLE · XOM · OXY · FRO
   스마트머니 선포지션? → 예(강) — 헤드라인 2세션 전 XLE 콜스윕 +Δ, 다크풀 62%
   (관찰 정보 · 투자조언 아님)
```
반대면: **"→ 아니오"** = "선행 없음, 헤드라인 주도·늦은 움직임."

**어디에·어떻게:**
- **Guardian(모니터 화면) = 우리만의 월드 모니터.** 세계 지도/리스트에 활성 촉매(초크포인트·분쟁·정책) 핀, 열면 위 카드(이벤트→물리사슬→노출 바스켓→우리 플로우 괴리). 일반 뉴스 대시보드와 달리 **모든 이벤트가 우리 옵션 데이터에 배선.**
- **Dashboard 히어로** = "오늘의 촉매 + 괴리" 한 장.
- **Command(종목별)** = 상단 "촉매 노출" 타일(이 종목이 어떤 이벤트에 노출·플로우 선행 여부).
- **푸시** = "내 워치리스트 XOM이 호르무즈 이벤트 노출 · 플로우 선행 감지."

## B. 트럼프/정책 레이어 (동일 모니터 안)
```
🟠 자동차 관세 인상 신호 · USTR · [날짜]
   노출: F · GM · TSLA · APTV
   Polymarket "관세 발효" 41% (−15pt/24h = 페이드) · Kalshi 33% · 괴리 8pt
   선포지션? → 혼재 · TACO 페이드 트래커: 위협 확률 5-10일 소멸 추세
```
특징 = **프리딕션마켓 확률 칩(다중출처 괴리)** + **TACO 페이드 미니 차트**(쇼크 아니라 소멸) + "누가 먼저 포지션". 속도 경쟁 아님.

## C. COT × GEX — "갇힌 두 군중"
```
SPY 포지셔닝 충돌
투기세력 ES 순숏 2년 극단(8%ile) │ 딜러 감마 [레벨] 아래 깊은 숏
→ 둘 다 갇힘 · 상방 시 동시 커버 취약 (스퀴즈 조건)
```
**어디에:** Command **QUANT 탭**(SPY·QQQ·IWM)에 2바 타일 + 수렴/괴리 판정 칩. Intel에 시장전체 요약. 갱신 = COT 주간(금)+GEX 실시간.

## D. SEC Form 4 확신 스택
```
NVDA 확신 스택 ▣▣▣ 정렬
✓ 인사이더 3인 9일간 $Xm 매수(기회적·비루틴)
✓ 이상 콜스윕 · ✓ 다크풀 매집 62%
→ 세 신호 같은 방향 (탭 → 실제 Form4 성명·금액·일자)
```
**어디에:** Command OVERVIEW "Conviction" 3칸 스택 + Intel "확신 스택 리더보드". 푸시 = "확신 스택 형성: [종목]." 갱신 ≤2일(EDGAR).

## E. FRED 매크로 레짐 게이트 (전체를 물들임)
```
금융환경: 긴축 ▲ (NFCI +0.3 · HY스프레드 확대 · 2s10s −)
강세 플로우 신호 가중치 하향 중
```
**어디에:** 별도 기능 아님 — Dashboard/Intel 상단 레짐 배너 + 기존 플로우 카드에 작은 "레짐" 배지. 신호 나열을 **레짐 인지 시스템**으로 승격.

## 요약: 신호 → 위치 → 표현
| 신호 | 앱 위치 | 표현 |
|---|---|---|
| 지정학/정책 촉매 괴리 | **Guardian 모니터** + Dashboard + 푸시 | 이벤트→물리사슬→노출바스켓→"선포지션?" 게이지 |
| 트럼프/관세 | Guardian 피드 | +프리딕션마켓 확률칩(다중괴리) +TACO 페이드 |
| COT×GEX | Command QUANT / Intel | 2바 "갇힌 두 군중" +판정칩 |
| Form4 확신스택 | Command OVERVIEW / Intel 리더보드 | 3칸 스택 ✓✓✓ +실필링 |
| FRED 레짐 | Dashboard/Intel 배너 | 컴팩트 미터, 기존 신호에 배지 |

## 컴플라이언스 표현 규칙(모든 카드 공통)
`[출처]가 [사실]이 [Δ]함을 관찰 (시각)` + "무엇을 재나" 툴팁. **"가격에 뭘 의미/사라"는 절대 금지.** 프리딕션마켓·장기지정학은 저신뢰 라벨. [[predictive-framing-forbidden-in-posts]] 규칙 적용.
