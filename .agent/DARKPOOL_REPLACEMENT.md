같은 응답이 스스로 밝힌다:
> "market_center, listing_venue, sales_conditions, and quote_conditions
>  are only available with our delayed sip feed."

EQUITIES_EDGE WS 실측(2026-08-28 POST):
```
MarketCenter=" "   Condition=""   IsDarkpool=false(전건)   Size=0   TotalVolume=0
```
필드는 존재하는데 **값이 안 온다.** `DELAYED_SIP` 은 권한이 200 이지만
장 마감으로 체결 표본이 없어 미확정 — 월요일 개장에 자동 판정된다
(`scripts/intrinio-darkpool-probe.js`, `/var/log/intrinio-darkpool-probe.log`).

## 3. 채택: 유동성 점수 (LIQ)

### 왜 이것이 다크풀에 상응하는가
다크풀이 답하려던 질문은 «기관이 여기서 티 안 나게 큰 물량을 소화할 수 있나»였다.
스프레드는 그 질문에 **직접** 답한다 — 좁으면 대량 체결이 가격을 밀지 않고,
넓으면 시장이 얇아 큰 물량이 못 들어온다. 트레이딩 데스크가 실제로 보는 지표다.

### 계산
스프레드는 자릿수 단위로 벌어지므로 **로그 스케일** 정규화:
```
0.001% → 100점 · 0.01% → 67 · 0.1% → 33 · 1.0% → 0
```
정본 구현: `intrinioClient.liquidityScoreFromSpread()`
EC2 적재기(`scripts/intrinio-liquidity.js`)도 **같은 식**을 쓴다 — 갈리면 안 된다.

### 세션 정책 ★
유동성은 **정규장 지표**다. 배포 직후 실측에서 드러났다:
```
정규장  NVDA 0.009% · AAPL 0.012% · GOOGL 0.011%
휴장중  NVDA 0.064% · AAPL 0.150% · GOOGL 2.009% → 0점
```
휴장 중 호가로 재면 **전 종목이 나쁘게 나온다.** breadth 와 같은 규칙:
- **정규장** → 실시간 호가
- **그 외** → EC2 가 적재한 직전 정규장 **분봉 중앙값**
- 둘 다 없으면 **null** (0 도 50 도 아니다)

한 시점 호가보다 정규장 390봉의 중앙값이 «유동성 품질»의 정본에 가깝다.

### EC2 적재기
```
30 20 * * 1-5   scripts/intrinio-liquidity.js   → intrinio:liquidity:lastreg
```
- 달러거래량 상위 600종목 · 종목당 1콜 (하루 600콜, 한도 2,000/분 대비 무시)
- 표본 60봉 미만이면 값을 만들지 않는다
- 정합성 게이트: 성공률 20% 미만이거나 중앙값이 0/100 이면 **적재 중단**
- 되읽기 검증 후 종료

**실측**: 600종목 중 593종목 성공 · 30초 · 20KB
```
NVDA 68(0.0092%) · SPY 80(0.0039%) · QQQ 79 · MSFT 59 · TSLA 55 · AEHR 20
점수 분포 최저 0 · 중앙 39 · 최고 80
```

## 5. 함께 강화한 것 — 내부자 거래

다크풀은 **익명**이지만 내부자는 **누가·언제·얼마에** 샀는지 다 나온다.
스마트머니 서사로는 오히려 강하다.

Intrinio 로 이관하면서 개선한 점:
- 전역 피드가 **실시간(0일전)**
- `derivative_transaction` — Massive 에 없던 필드. 옵션 행사와 실제 매매를 구분
- **「거래 30건인데 매수 0 매도 0」 모순 해소**:
  Form 4 에는 «보유 신고» 행(코드 없음+수량 0)이 섞여 온다.
  실측 NVDA 30건 중 17건이 그것이었다 → 제외하고, 무엇이 몇 건인지
  `breakdown` 으로 그대로 노출한다.

**실측**(40건 기준)
```
NVDA  매도 18건 $452.5M · 무상부여 13 · 증여 4 · 세금원천 5
AAPL  매도 17건 $113.1M · 옵션행사 16 · 파생 11
PLTR  매도 27건 $96.9M · 전환 6
```
