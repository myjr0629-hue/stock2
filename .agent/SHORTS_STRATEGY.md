## 0. 한 줄 결론
**Remotion이 본체(데이터·차트·티커·실앱화면 합성, 픽셀정확, ~$0.02/클립). AI 비디오(Veo/Flow·Higgsfield)는 시네마틱 b-roll·훅샷 액센트일 뿐(숫자를 못 그림, ~$3–12/편).** 승부 포맷 = **"데이터 리빌"**(1프레임에 큰 숫자) + **실제 앱 화면(디바이스 프레임)을 증거 비트로**. 채널은 **TikTok(콜드 도달) → YouTube Shorts(링크·검색) → Reels(웜)**. 지금 당장 유료 도구 구독 불필요 — Remotion으로 템플릿·훅 라이브러리·실앱 녹화부터.

## 1. 도구 비교표 (완성 30–45초 1편 기준)

| 도구 | 잘하는 것 | 못하는 것 | 완성편당 비용 | 자동화 | 판정 |
|---|---|---|---|---|---|
| **Remotion** (보유) | 데이터·차트·티커·오버레이·실앱화면 합성, 브랜드 일관, 픽셀정확 | 시네마틱 실사 b-roll | **~$0.02** | 완전(코드) | **본체 — 데이터 레이어 전담** |
| **Google Flow / Veo 3.1** | 시네마틱 추상 b-roll, 9:16 네이티브, 오디오, 4K | **숫자/텍스트 할루시네이션**, 이음새 글리치(리롤 2–4회) | ~$3–6 (Ultra 5x $99/mo) | Gemini API/Vertex만(Flow UI엔 MCP 없음) | b-roll 전용. 새 GCP $300 크레딧으로 프로토타입 |
| **Higgsfield (+MCP)** | 카메라 무빙 프리셋, 마케팅/광고 템플릿(9:16 기성), Veo/Sora/Kling 통합 1빌 | 데이터 못 그림, 실앱 편집엔 이점 적음, 상업라이선스 문서 불명확 | ~$3–12 (Ultra ~$99/mo) | **공식 MCP `mcp.higgsfield.ai/mcp` (Claude Code 연결, API키 불필요) + REST/Python SDK** | b-roll 전용, 단 **자동화 편의는 최고** |

**Veo vs Higgsfield:** Higgsfield는 내부적으로 Veo3를 감싸며 카메라 프리셋·마케팅 템플릿·단일 MCP를 얹은 편의 프리미엄. **순수 Veo 원본**만 원하면 Flow/Veo API가 초당 더 쌈. **에이전트로 자동 생성**하고 여러 모델을 한 계정으로 쓰려면 Higgsfield MCP. **둘 다 Remotion 대비 100–600배 비쌈** → 액센트로만.

> 대표님이 말한 "Flow 10초×여러 개 병합": 실제로는 **8초** 생성 + **SceneBuilder Extend**로 이어붙임(내부에서 단일 MP4 출력, ffmpeg 불필요) + **Ingredients**로 일관성. 단 이음새 리롤 2–4회 필요. 이건 **b-roll 텍스처용**이지 데이터편 대체 아님.

## 2. 권장 파이프라인 (하이브리드)

```
[1] 실제 앱 화면 녹화 (SIGNUM/UC/WIM/레이더 실행 → 디바이스 프레임 안에 넣고 탭 하이라이트)
        +
[2] Remotion 데이터 그래픽 (훅 숫자·다크풀%·GEX·맥스페인 오버레이, 브랜드·컴플라이언스 자막 고정)
        +
[3] (선택) AI b-roll 훅샷 — Flow/Veo 또는 Higgsfield로 시네마틱 컷어웨이 몇 초
        ↓
Remotion에서 최종 합성 (자막·티커·CTA·"Not investment advice" 고정) → 9:16 클린 출력
        ↓
TikTok 네이티브 업로드 → 워터마크 없이 YouTube Shorts·Reels 교차 업로드
```
- **비용 구조:** 대부분 Remotion(~$0)로 처리, AI b-roll은 훅이 필요한 일부에만. 유료 도구는 **발사 시점에 하나만** 붙임(Higgsfield MCP 자동화형 또는 Flow/Veo API 배치형) — 무료 크레딧으로 먼저 프로토타입.
- **실앱화면:** 편당 **30–50%** 화면시간. 훅(데이터 그래픽)으로 스크롤 세우고 → **중간 "증거" 비트에서 실앱 화면 리빌**(숫자가 사는 곳을 보여주는 게 신뢰·전환 포인트) → CTA. **디바이스 프레임 안에** 넣기(풀블리드 생캡처는 아마추어로 보임; 히어로 1컷만 예외).

## 3. 어떤 쇼츠 — 포맷·훅

**포맷:** ① 데이터 리빌(1프레임 큰 숫자 = 최강) ② "오늘 스마트머니가 한 것" 데일리 리캡(프랜차이즈화) ③ 실앱 워크스루 ④ "차트가 안 보여주는 것"(우리 차별화) ⑤ "기관이 보는 3가지"(리스티클) ⑥ 통념 반박.

**컴플라이언스 안전 훅 10 (관찰형 — will/should/target/profit 금지):**
1. "다크풀이 오늘 [TICKER] 거래량의 51%를 삼켰다. 어디였는지 보자."
2. "[TICKER] 주가가 움직이기 **전에** 옵션 플로우가 켜졌다. 무엇을 보여줬나."(과거 관찰)
3. "가격 차트가 지금 [TICKER]에 대해 **안 보여주는** 것."
4. "오늘 [TICKER]에 $40M 콜 스윕이 들어왔다. 리테일은 못 봤다."
5. "기관 데스크가 보는데 리테일이 무시하는 3가지."
6. "오늘 마감 기준 [TICKER] 맥스페인이 앉은 자리."(관찰 레벨, 예측 아님)
7. "오늘 S&P 감마 익스포저가 마이너스로 뒤집혔다 — 이게 뭘 재는지."
8. "우리 웨일 인덱스가 [TICKER] 이상활동을 잡았다. 원본 데이터다."
9. "대부분 가격만 본다. 나머지 60%의 테이프는 여기 있다."
10. "오늘 [TICKER] 테이프, 30초로 — 의견 없이 데이터만."

> 온라인에 도는 금융 훅 리스트("돈 2배"·"조기은퇴")는 전부 **우리 규제상 사용 불가**(조언·수익 암시) → 위 10개는 관찰/사실형으로 재작성됨. **영상 내(자막 아닌 화면)** 고정 문구: *"Informational only. Not investment advice."*

## 5. 플랫폼·케이던스·반복 루프

- **우선순위: TikTok #1**(무명 콜드 도달 최강; 단 2026-01 "팔로워 우선" 업데이트로 첫 500–1,000 팔로워가 도달 게이트 → 초기 소규모 시딩 필요) → **YouTube Shorts #2**(검색·인텐트형 + **설명/고정댓글에 클릭 링크 허용** = 설치 인텐트 최고) → **Reels #3**(무명 진입장벽 높음, 웜되면 도달률 높음).
- **인스톨 퍼널:** 인피드 외부링크는 억제됨 → **영상 CTA → 프로필/바이오 → iOS/Android 라우팅 스마트링크 1개**. YouTube Shorts만 설명·고정댓글 링크 유효.
- **케이던스:** TikTok 1–3/일(수 시간 간격), Shorts 1/일, Reels 3–5/주. **모든 TikTok을 워터마크 없이 Shorts·Reels 교차 업로드**(3배 노출, ~0원).
- **테스트-더블다운:** 템플릿 고정 → **훅만 주5–7개 변형** → **48시간**에 **완주율·저장/공유**(좋아요 아님)로 판정 → 중앙값 2배 넘는 클립은 **3–5개 재컷**(티커·지표·오프닝 숫자 스왑) → 중앙값 이하 킬. 제작이 자동(Remotion)이라 **볼륨×무자비한 반복**이 우리 엣지.

**섀도밴/봇 회피:** 하루 10+ 발행 금지(1–3), **100% 금융 토픽 고정**(주제 드리프트 금지), 동일 캡션/해시태그/썸네일 복붙 금지(템플릿 안에서도 변주), 해시태그 ≤5, 인게이지먼트 팟·매스팔로우 금지, 타 플랫폼 워터마크 재업로드 금지. 억제 감지 시 48–72h 정지+문제 클립 삭제.

**금융 광고 지뢰(유료 시):** 금융서비스 광고는 사전승인·자격 필요, **보장수익 금지**, CFD·바이너리·페니·대부분 크립토 제한. 오가닉도 금융은 더 엄격 심사 → 영상 내 면책 + 관찰형 스크립트 규칙을 템플릿에 영구 내장.

## 6. 최고 레버리지 5 (발사 시 이 순서)
1. **TikTok로 도달, YouTube Shorts+바이오 스마트링크로 설치 퍼널** — 전 클립 클린 교차업로드.
2. **"데이터 리빌" 프랜차이즈 소유** — 1프레임 큰 숫자로 스크롤 정지, 실앱 화면(디바이스 프레임)을 증거 비트로 전환. 앱 화면 ~30–50%.
3. **템플릿 고정, 훅만 반복** — 주5–7 변형, 48h 완주율·저장 판정, 승자 3–5 재컷. Remotion 자동화가 복리되는 지점.
4. **컴플라이언스를 템플릿에 영구 내장** — 영상 내 "not advice" + 관찰형 규칙(대량 자동생산이 예측/조언으로 드리프트하는 것 차단). 금융 최대 억제·규제 리스크.
5. **계정 스팸신호 보호** — 1–3/일 간격, 100% 금융, ≤5 해시태그, 변주, 팟/매스팔로우 금지.

## 7. 지금 vs 발사 후
