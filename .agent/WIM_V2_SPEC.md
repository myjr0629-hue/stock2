## 3. 진행 시스템 — "차트가 자라난다" (자기도 모르게 깊어지는 구조)

**벨트 사다리** (CMT 역전 + just-in-time): 캔들·거래량 → 레벨·추세(VWAP·SMA) → 옵션 구조
(맥스페인·감마: "군중의 포지션 읽기") → 시장 미시구조(다크풀·숏볼·블록) → 변동성(IV·스퀴즈) → 거시(금리·Fed·상관).

**핵심 창작 메커니즘 — 오버레이 언락**: 승급할 때마다 **내 차트에 보이는 층이 늘어난다.**
초심자의 차트는 가격뿐 → VWAP 선이 생기고 → 감마 레벨이 뜨고 → 다크풀 게이지가 붙는다.
"공부했다"가 아니라 **"이제 나는 이게 보인다"** — 진행이 곧 시력(sight)이 되는 구조.
(동기 정합: 시장을 더 잘 보고 싶다는 욕구 그 자체 — Gardenscapes 실패의 교훈 반영)

**개념 도감(알마낙)**: 개념 마스터 시 **그날 실제 차트가 박힌 카드**로 수집 — "이 개념을 배운 날,
시장은 이랬다." 개인 역사가 됨. 공유 카드로도 사용(무해한 자랑 = 유통).

**스트릭**: 학습일 기준 유지 + **freeze 2개 기본 지급**(용서 장치 [VERIFIED]) + 10일 마일스톤 축하.
**리그**: v2.1로 보류 (소프트 진입 설계 필요). **보상은 후하게** — 캡·그라인드 금지 [VERIFIED].

## 4. 비주얼 언어 — "데이터 그래피티" (검증 공백 → 자체 원칙)

- **차트가 히어로**: 모든 플레이 화면은 풀블리드 실차트 위에서 벌어짐. 텍스트 박스 나열 금지.
- **큰 숫자 + 카운트업 애니메이션**: 지표는 수치가 아니라 "장면"으로 (등장 시 굴러 올라감).
- **세션 히트 스트립**: 프리→본장→애프터를 가로 띠로, 오늘 사건 위치를 마킹.
- 팔레트: 바이올렛 기반 유지하되 **다크 차트 캔버스**를 중심에 (WIM 라이트 글래스 + 다크 차트의 대비).
- 이모지 금지(기존 원칙) · Ic 스트로크 아이콘 확장 · 방향 색칠(초록/빨강 하이프) 금지 — 크기·강도만.
- 판정: 실기기/시뮬 실화면 스샷으로만 (목업 금지 — 메모리 원칙).
