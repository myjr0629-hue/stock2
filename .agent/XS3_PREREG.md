# XS‑3.0 사전등록 명세 (PREREG) — 개인 자동매매용 «S&P 500 트레이딩 유니버스» 스코어

> 상태: **등록 2026-09-16 (Claude 작성, 대표 지시 «엔진은 유니버스 전체에서 완벽·매매는 S&P 500 종목만·개인 사용»)**. §42.3 검증 헌법 준수: 아래 §2~§5 상수는 코드에 하드코딩되며 등록 후 변경 금지(변경 = 새 버전 등록 + 기존 트랙 종료). 섀도 전용 — 주문·UI·마케팅 노출 없음. 실행 주체는 대표 소유 시스템(Claude 는 코드·측정까지).
> 근거: `.agent/ALPHA_SCORE_PERFORMANCE_AND_ROADMAP_2026-09-16.md`(8/31까지 실측·시뮬레이션), 외부 문헌 메모(단기반전·비용·검증 표준).

## 0. 목적
XS‑2.0 의 저장된 팩터 z 벡터에서 **살아 있는 신호만** 추출해 T+5 지평의 크로스섹션 점수를 만들고, 그 점수를 **S&P 500 구성종목** 에만 매매 후보로 변환한다. 목표는 «항시 승리» 가 아니라 **비용 차감 후 양의 기대값을 스스로 증명하고, 죽으면 스스로 멈추는 스코어** 다.

## 1. 입력 (모두 읽기 전용)
| 입력 | 원천 | 비고 |
|---|---|---|
| 팩터 z 벡터·종가·시총 | DynamoDB `signum-xs-history` 당일 행(`ver XS-2.*`, `z`) | XS‑2.0 이 22:10 UTC 에 기록 → 3.0 은 22:25 UTC 실행 |
| S&P 500 구성·GICS 섹터 | Wikipedia «List of S&P 500 companies» 표 | 파싱 실패 시 `_SP500_` 캐시(마지막 성공본) 사용; 티커 `.`↔`-` 정규화 |
| 종가 매트릭스·SPY | EC2 Redis `intrinio:eod:history`(20영업일) | 라벨(T+5)·SPY 조정·페이퍼 NAV |
| 실적 예정일 | DynamoDB `signum-pattern-db` `EARNINGS:{t}.nextDate` | 트레이딩 후보 제외에만 사용(점수엔 미사용) |
| VIX | FMP stable `quote?symbol=^VIX` (폴백 Redis `yahoo:vix`) | 노출 배율(§3)에만 사용 |

## 2. 점수 (동결)
- 코어 팩터 4개(동일가중): `revRet3`(3일 반전) · `revChg`(1일 반전) · `smaExt`(SMA 과확장) · `squeeze`. 팩터 ≥3개 있는 종목만 채점.
- 제외(방향 신호로 쓰지 않음): ivLow · dGex5 · gexInv · pcr · dtc · darkPool · shortVol · blockTrades · analystRev(8/31 실측 IC ≤ 0 또는 부호 반대).
- 합성 `comp = mean(z_core)`; EMA `ema_t = 0.4·comp_t + 0.6·ema_{t-1}`(첫날은 comp).
- 점수 `xs3 = 유니버스 백분위(ema) × 100`(0~100, 소수1). S&P 부분집합 백분위 `spPct` 별도 기록.
- 변형(레이스, 같은 라벨로 동시 측정): **A(main)** = 위 그대로 · **B** = comp − 0.5·(GICS 섹터 평균 comp) (S&P 종목만) · **C** = A 와 동일 점수 + 트레이딩만 «하락일 다음 날» 진입(레짐 게이트). · **D** = EMA 없이 comp 백분위(8주 인샘플 민감도에서 상위20 순수익이 A 보다 높아 등록 «당일» 추가; 라이브 자료 0일 시점이므로 선택 편향 없음 — 단 등재 이유는 인샘플이다). 60일 판정에서 A 가 지면 새 버전 등록으로만 교체.

## 3. 트레이딩 후보(섀도 페이퍼; 실주문 없음)
- 유니버스: S&P 500 ∩ 종가 ≥ $5 ∩ 코어 팩터 ≥3 ∩ **실적일이 D+1~D+5 안에 없음**.
- 후보: xs3 상위 **20종목**(동일가중). 보조 표시: 상위 10%·상위 50.
- 보유: 진입 D+1 종가 근사(1일 실행 지연 보수적 가정) → 청산 D+6 종가(5세션 보유). 손절·재량 없음. 5트랑슈 롤링(하루 1/5).
- 비용: 왕복 15bp(S&P 대형주·지정가 중간가 가정). 실시간 체결 트윈이 붙으면 실측치로 교체(새 버전).
- 노출 배율(레짐, 순위 불변): VIX ≥ 20 → 1.25 · VIX < 14 → 0.75 · 그 외 1.0. 자본 $10,000 명목.
- 킬(페이퍼 NAV): 주간 −3% → 신규 진입 정지(수동 재개) · 롤링 20일 IC < 0 5일 연속 → 후보 목록 비움 + 알람.

## 4. 라벨·측정 (동결)
- 라벨: `f5 = close[D+5]/close[D] − 1`; `adj5 = f5 − 유니버스 평균 f5`; `spyAdj5 = f5 − SPY f5`. |f5| > 150% 는 데이터 오류로 제외.
- 일일: Spearman IC(xs3 vs adj5) 전체·S&P 부분집합, 변형 A/B/C 각각, XS‑2.0 xsScore 의 같은 라벨 IC(맞대결).
- 누적: 평균 IC · Newey‑West(lag 4) t · ICIR · 양수일 비율 · 블록 부트스트랩(5일 블록·2,000회) 95% CI · 데실 표(adj5·적중률·n) · 상위20 순수익(비용·SPY 조정) 주기별 승률 · 페이퍼 NAV·MDD.
- 모든 수치는 `_REPORT_/{date}` 와 Redis `cache:xs3:report` 에 기록. 인샘플(백필) 구간은 `backfill:true` 로 분리 표기하며 게이트 판정에 쓰지 않는다.

## 5. 게이트 (60 라벨일, 라이브 OOS 만)
① S&P 부분집합 롤링 IC(T+5) ≥ +0.05, NW t ≥ 2.0 · ② 상위20 순수익(비용·SPY 조정) 평균 > 0, 양수 주기 ≥ 55% · ③ 데실 단조(데실 평균 adj5 의 Spearman ≥ 0.8) · ④ XS‑2.0 대비 Δ IC > 0 인 날 ≥ 55% · ⑤ 페이퍼 MDD ≤ 5%. **5/5 통과 시에만** 실시간 체결 트윈(지정가 중간가·참여율 ≤5% ADV) 8~12주 → 그 뒤 소액 실계좌(별도 사전등록).

## 6. 안전선
섀도 전용(주문 코드 없음) · 예산·계정·비밀번호 무관 · 화면·마케팅 노출 금지 · 등록 후 §2~§5 변경 금지 · 실패는 실패로 기록(포장 금지).

## 7. 운영
Lambda `signum-xs3`(nodejs20, 900s), EventBridge `signum-xs3-daily` `cron(25 22 ? * MON-FRI *)`, DynamoDB `signum-xs3-history`(PAY_PER_REQUEST), Redis `cache:xs3:{report,scores,trade}`. 알람: 실행 오류·S&P 유니버스 < 400·리포트 부재(24h). 코드: `scripts/lambda-xs3/index.js`, 배포 `scripts/deploy-xs3.js`, 로컬 검증 `scripts/xs-analysis/xs3-backtest.js`.
