# 배당/ETF 정보 기능 — 실현가능성 정밀 조사 (정본) 2026-07-20
> 딥리서치 106에이전트·검증 통과분만. 대표 질문: "우리 자원으로 ①배당 랭킹 ②'얼마 넣으면 얼마' 계산기 ③배당락 캘린더+시뮬 만들 수 있나?"

## A. 데이터 실현가능성 (가장 중요 — Polygon/Finnhub 공식문서 대조)
> 우리 스택 = Polygon(Massive 프록시, api.polygon.io) + Finnhub.

| 제품 아이디어 | 판정 | 근거 |
|---|---|---|
| **배당 캘린더 (배당락일·지급일)** | ✅ **지금 바로** | Polygon Dividends v3가 cash_amount·declaration/ex_dividend/record/pay 날짜·frequency(월/분기/연 등)·유형 전부 반환. **전 Stocks 플랜 포함(업그레이드 불필요)**. |
| **배당락 이벤트/시뮬** | ✅ **지금 바로** | 위 날짜+금액으로 "배당락일 시가가 배당금만큼 낮게 시작하는 경향" 교육 시뮬 구현 가능(예측 아님, 메커닉 설명). |
| **지급주기·유형 랭킹** | ✅ **지금 바로** | frequency + 4개 배당유형(정기 CD/특별 SC/장기 LT/단기 ST) 구분 가능. |
| **배당수익률(yield) 랭킹** | ✅ **지금 바로 (단, 파생)** | ⚠️ **yield 필드는 어느 벤더도 안 줌** → "연환산 배당 ÷ 현재가"로 직접 계산(현재가는 우리가 이미 보유). |
| **"얼마 넣으면 얼마" 계산기** | ✅ **지금 바로** | 위 파생 yield × 투자금 = 연/월 예상 배당. |
| **배당성장 연수(귀족주 배지)** | 🟡 **부분(파생)** | 필드 없음 → Polygon 과거 배당 이력으로 "연속 증가 연수" 직접 계산. Finnhub도 30년 이력 있으나 **All-In-One $3,500/mo 게이트**(안 씀). |
| **미래/추정 배당 (forward)** | 🔴 **불가(현재 자원)** | Polygon 없음. Finnhub 추정치는 마케팅엔 있으나 SDK 미노출+$200/mo+ → **넣지 말 것**(현재 배당으로만). |

**결론**: 3개 핵심 아이디어(랭킹·계산기·배당락 캘린더/시뮬) = **전부 지금 자원으로 구현 가능**. 신규 데이터 소스·유료 업그레이드 0. 유일한 파생 계산 = yield(단순)·성장연수(과거 이력 스캔).
⚠️ 착수 전 라이브 API로 **SCHD/JEPI/QYLD 등 월배당 커버드콜 ETF의 분배 데이터 깊이 1회 실측** 필요(ETF는 티커라 커버되나 깊이 미검증).

## B. 시장 수요 (실측)
- **KR 서학개미 = 강함·명확**: SCHD 보유 **~$3.1B**(전 미국상장 13위·미국ETF 4위, 2026-05), 순매수 상위, 토스가 SCHD를 "제2의 월급통장"으로 교육. 배당 정보 수요 대중화됨.
- **인컴번트 = 주로 구독**($6.99~$24/mo, Track Your Dividends·Snowball·getquin 등). 리텐션 루프 = 인컴 projection + 배당락/지급 알림 + DRIP 시뮬 + 배당성장 차트.
- **JP(新NISA) = 미검증** — 조사에서 독립 확인 실패(오픈 이슈). 브랜드는 3언어로 하되 JP 수요는 착수 전 별도 확인 권장.

## C. 컴플라이언스 (스토어 안전성)
- ✅ **정보/교육 = 안전**: 한국 배당 재투자/인컴 계산기가 **이미 미국 앱스토어에 무료·승인 상태**로 존재 = 계산기·인컴 projection 스토어 안전성 실증.
- 애플 중과금 규정(3.2.1/5.1.1)은 **매매·자산운용 실행**에 붙지 정보 랭킹/캘린더/계산기엔 안 붙음. SIGNUM HQ LLC(법인)라 엔티티 요건 이미 충족.
- Google Play = 정보앱은 **금융기능 선언 체크박스**만(라이선스 게이트 아님).
- 배당락 "드롭 시뮬"은 예측 아닌 메커닉 교육이라 안전 — UC/WIM의 "관찰 언어" 원칙 그대로 적용.

## D. 배치 결정 (내 판단 — 리서치는 미결로 남김)
> 리서치가 이 항목은 검증 못 함 → 아래는 근거 기반 내 권고.
- **불가: SIGNUM/UC에 끼우기** — 톤·오디언스 불일치(프로 터미널/뉴스 브리프에 배당 계산기는 이질적).
- **최적 후보 2개**:
  1. **레이더 새 탭 "배당"** — 레이더가 이미 "관심종목×실데이터×3초 체크" 습관 유틸리티라, 배당 캘린더/알림(배당락 D-day 푸시)은 **같은 습관 루프에 자연 융합**. 워치리스트 공유 → 전환비용↑. **가장 응집력 높음.**
  2. **5번째 독립 앱 "배당 캘린더/랭킹"** — KR/JP 배당 검색 트래픽(SEO)·스토어 키워드("배당","SCHD","高配当")를 독립 브랜드로 흡수. 단 빌드·심사·마케팅 1세트 추가.
- **권고**: **① 레이더 탭으로 먼저**(빌드 최소·습관 융합·즉시 검증) → 반응 좋으면 ②독립 앱으로 스핀. 배당락 D-day 푸시 = 레이더의 알림 엔진과 동일 인프라 = 시너지.

## 미검증/공백 (정직)
- JP 배당앱 수요 수치 미확인. ETF 분배 데이터 깊이 라이브 실측 필요. 옵션 데이터로 배당락 차별화(디비덴드 캡처 플로우 등) 가능성은 매력적이나 미검증 — 별도 탐색.
