# SIGNUM 랭킹 엔진 — 사용 안내

다른 에이전트(윈도우 등)가 이 문서만 읽고 쓸 수 있도록 쓴다.

## 왜 코드가 아니라 주소인가

엔진은 DynamoDB·EC2 Redis 를 직접 읽는다. 코드를 복사해 주면 **AWS 키까지
넘어가야 한다.** 그러면 안 된다. 그리고 두 벌로 갈라지면 어느 날 조용히
달라지고, 그때 어느 쪽이 맞는지 알 수 없다. **구현은 한 곳에만 두고 주소만 부른다.**

## 엔드포인트

```
GET https://www.signumhq.com/api/ranking              # 목록 + 각 랭킹의 의미
GET https://www.signumhq.com/api/ranking?run=all      # 전부 실행
GET https://www.signumhq.com/api/ranking?run=stealth  # 하나만
```

| 파라미터 | 기본 | 설명 |
|---|---|---|
| `run` | — | 없으면 목록만. `all` 또는 랭킹 id |
| `top` | 5 | 상위 몇 개 (1~10) |
| `days` | 30 | 기준선 기간 (10~90) |
| `refresh` | — | `1` 이면 캐시 무시 (평소엔 넣지 말 것 · 캐시 10분) |

인증 없음. 응답의 각 랭킹에 `what`(무엇을 재나)·`why`(왜 가치 있나)·`guards`
(막아둔 함정)가 그대로 들어 있다. **그걸 읽고 쓰면 된다.**

## 랭킹 8종 — 장중 5 / 마감 후 3

### 장중 (intraday) — 정규장에도 갱신된다

| id | 이름 | 무엇을 재나 |
|---|---|---|
| `deviation` | 평소 대비 이탈 | 옵션 7축을 그 종목 자신의 30일 중앙값과 비교 |
| `multi-axis` | 다축 동시 이탈 | 두 축 이상에서 «동시에» 벗어난 종목만 |
| `maxpain-gap` | 맥스페인 이격도 | 현재가가 맥스페인에서 몇 % 떨어졌나 (먼 순) |
| `gamma-flip` | 감마플립 근접 | 현재가가 플립 레벨에서 몇 % 이내인가 (가까운 순) |
| `money-vs-oi` | 돈과 포지션의 불일치 | 프리미엄 비와 미결제약정 비가 반대를 가리키는 정도 |

### 마감 후 (postclose) — FINRA 자료가 들어와야 작동

| id | 이름 | 무엇을 재나 |
|---|---|---|
| `darkpool-volume` | 장외 물량 이탈 | 장외 체결량 배수 ÷ 그날 시장 중앙 배수 |
| `darkpool-short` | 장외 공매도 비중 이탈 | 공매도 비중이 평소보다 몇 %p |
| `stealth` | 은밀 축적·분산 | 물량↑ + 공매도비중↓ 조합을 그날 시장 중앙값과 비교 |

**FINRA 는 마감(16:00 ET) 후 약 90분, 17:31 ET 에 그날 파일이 뜬다.**
그 전에는 마감 후 랭킹이 `available: false` 로 나온다.

## 쓰는 쪽이 반드시 지킬 것

1. **`items` 가 비어 있을 수 있다.** 게이트를 통과한 게 없으면 빈 배열이다.
   그때는 «만들지 않는다». 억지로 채우면 그게 거짓말이 된다.
2. **`available` 을 먼저 본다.** `false` 면 그 랭킹은 오늘 쓸 수 없다.
   `darkPool.stale: true` 는 «옛날 것을 들고 있다»는 뜻이지 «오늘 것이 있다»가 아니다.
3. **`today` 와 `baseline` 을 항상 같이 보여준다.** 「평소의 2.2배」만 쓰면
   보는 사람이 검증할 수 없다. 오늘값·평소값·배수 셋을 같이 낸다.
4. **`label` 을 그대로 쓴다.** ko/en/ja 가 다 온다. 특히 `pcr` 은
   «미결제약정» 기준이지 거래량이 아니다 — 줄여 쓰면 오보가 된다.
5. **`date` 를 확인한다.** 옵션과 다크풀의 날짜가 다를 수 있다.

## 이 엔진이 «절대 순위»를 쓰지 않는 이유

옵션 프리미엄 TOP 같은 절대 순위는 시가총액을 따라가서 NVDA·TSLA·AAPL 이
거의 매일 상위다. 답을 미리 아는 랭킹은 볼 이유가 없다.
다크풀도 같다 — 시장 전체 공매도 비중 중앙값이 약 **49%** 라서 절대값은
아무 말도 안 한다. **정보는 «그 종목 자신의 평소 대비 이탈»에만 있다.**

## 엔진이 막아둔 함정 (전부 실측으로 데인 것들)

| 함정 | 증상 | 막은 법 |
|---|---|---|
| **만기 롤오버** | 같은 날 NVDA 콜OI 가 107,121~1,985,592 로 널뛴다. 「평소의 6배」라는 22σ 허수가 나온다 | 그날 총 OI 가 가장 큰 스냅샷 하나를 대표로 쓰고, 같은 규모의 날하고만 비교 |
| **분모 붕괴** | 비교일이 서로 비슷하면 MAD→0, z 가 42σ 로 폭발 | 산포/중앙값 하한 + 순위는 σ 가 아니라 «배수»로 |
| **시장 교란** | 시장이 조용한 날엔 모든 종목이 이탈로 보인다(상위 6 중 4개가 그렇게 찼다) | 그날 시장 중앙값으로 나눠 «시장 대비»만 남긴다 |
| **날짜 혼입** | 옵션은 오늘인데 다크풀만 3일 전 → 「오늘의 랭킹」에 묵은 값이 1위 | 날짜가 다르면 랭킹에서 뺀다 |
| **죽은 필드** | ivSkew 가 실측 300행 전부 0 | 축에서 제외 |
| **라벨 불일치** | `pcr` 은 OI 기준인데 「풋콜 비율」로만 쓰면 거래량으로 읽힌다 | 라벨에 기준을 명시 |
| **생산자 분리** | 프리미엄 행과 OI 행이 달라 둘을 같이 쓰는 랭킹이 0건 | 둘 다 든 행을 찾아 쓴다(섞지 않는다) |
