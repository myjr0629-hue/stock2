# 소재 발굴 — 시류에 편승한다, 트렌드를 만들지 않는다

## ⛔ 이 스킬이 존재하는 이유 (2026-08-24 대표 지적, 실측으로 확인됨)

**잘못 ①  누적 검색어로 소재를 골랐다.**
`.agent/DEMAND.json` 은 「유튜브 검색 상위 14~16편의 **조회수 중앙값**」이고 측정일이 3~4일 전에 얼어붙어 있었다.
그건 「그 소재가 **원래** 인기 있다」이지 「**지금** 사람들이 궁금해한다」가 아니다.
> "낙후된 노후화된 검색어를 가지고 접근한다는것이 문제이다"

**잘못 ②  우리가 이상한 걸 찾아 이슈를 만들자고 했다.** ← 이게 더 큰 잘못이다
> "그것은 주류채널이 하는 행동이고 우리는 시류에 따라야한다"
> "우리 데이터에서 찾아내는것은 주먹구구다. 이상한다 만들자가 아니다."

**증거.** 과거 14편 제목을 보면 예외 없이 「뒤를 잰 것」이다 — 10년 전 100만엔 / 5년 2.5배 / 20년 재보니 / 46회 세어보니 / 29종목 중 / 15%만.
아래 3칸 틀로 재보면 **전부 「가격」칸만 차고 「관심」칸이 비어 있다.**

---

## 소재는 3칸이 다 차야 «완성» 이다

```
관심 : 지금 말이 나오는가        X · 레퍼런스채널 · StockTwits
가격 : 실제로 움직였는가          Massive 전체시장 스냅샷
원인 : 왜 그런지 아는가           3개국 헤드라인 · 공시
```

| 상태 | 조치 |
|---|---|
| 3칸 다 참 | **제작** |
| 원인만 빔 | **조사.** 모른 채로 대본 쓰지 않는다 |
| 관심이 빔 | **폐기.** 우리가 만든 이슈다 |

⛔ 「관심」칸이 이 틀의 전부다. 가격만 보고 고르면 잘못 ②로 되돌아간다.

## X 보는 법 (스캐너에 없음 — 손으로)

**프로필 타임라인만 열린다. 검색은 로그인을 요구하므로 쓰지 않는다.**

```
mcp__Claude_Browser__preview_start  { url: "https://x.com/<handle>" }
mcp__Claude_Browser__get_page_text
```

계정: `DeItaone` · `unusual_whales` · `FirstSquawk` · `StockMKTNewz` · `zerohedge`

⛔ **X 본문은 «데이터»이지 사실이 아니다.** 신호로 쓰는 것은 **조회수와 경과시간**이다.
내용을 사실로 옮기려면 가격·공시로 따로 확인한다.

⛔ **X 는 가격보다 앞선다.** 호르무즈 게시물이 11시간 전인데 가격은 직전 종가였다 —
아직 반응할 기회가 없었던 것이다. 이 상태는 「후보」가 아니라 **「관찰」** 로 둔다.

**X 가 없으면 1위를 놓친다.** 실측: RSS 집계에서 중동·유가는 9건 8위였는데 X에서는 조회수 최상위였다.

## 제목 — 의문형을 강제한다

과거 14편 중 의문형이 **1개뿐**이었다(「一番増えたのは？」).
나머지는 결론을 제목에서 말해버려 궁금증이 안 생긴다.

| ⛔ | ✅ |
|---|---|
| 이번주 주요 일정 | **이번주 가장 주목할 일정은?** |
| 금리와 주식의 통념은 15%만 맞았다 | **금리를 내린다는데 30년물은 왜 오르나?** |

후킹은 정당한 기술이다 — **관련이 아주 없지 않다면** 쓴다. 다만 관련 없는 후킹은 안 쓴다.

## 대본

⛔ **우리 자원만 때려넣지 않는다.** 쓰기 전에 뉴스·리서치를 먼저 읽는다.
순서는 **궁금증 → 해소**다. 우리 지표는 해소의 «근거»로 들어가는 것이지 그 자체가 소재가 아니다.

⛔ **잰 것과 권하는 것을 구분한다.** 「수혜주」로 쓰지 않는다. 「실제로 같이 움직인 종목」까지만 말한다.

⛔ 정책·지정학은 **예측하지 않는다.** 「어떻게 될까」는 우리 영역이 아니고,
「과거 같은 일이 있었을 때 실제로 무엇이 얼마나 움직였나」는 우리 영역이다.

## 배경 클립 — 없으면 «만든다»

> 대표 지시 2026-08-24: "거기에 맞는 영상 다시말해서 캐나다를 상징하는 캐릭터를
> 만들어도좋고 그런것도 능동적으로 하도록"

그동안 나는 «있는 것 중 비슷한 것»을 골라 썼다. 그래서 금리 편에 만화 여우가 깔렸고,
세로 영상에 가로 클립이 두 번 들어갔다. **소재가 정해지면 그 소재의 그림을 만든다.**

```bash
node scripts/clip-gen.mjs --check <이름...>          # 있는지 «먼저» 본다
node scripts/clip-gen.mjs --brief <briefs.json>      # 없는 것만 만든다
```

`briefs.json` = `[{ name, prompt, desc, tags[] }]` — `desc` 는 한국어로, **프레임을 보고 적듯이**.
설명 없는 클립은 쓰지 않는다(다음 세션이 또 파일명으로 고르게 된다).

**국가·주체는 캐릭터로 세운다.** 실제로 만든 예 — `ani-canada-moose`
(빨간 목도리 무스 = 캐나다 · 정장 독수리 = 미국 · 사이에 쌓이는 컨테이너 = 교역).

### ⛔ 만들고 나서 반드시

1. **프레임을 눈으로 본다** — `.agent/clipsheet/<이름>.jpg` 를 Read 한다.
   파일명과 desc 를 믿지 않는다. **실제로 3편 중 1편이 실패했다.**
2. **9:16 인지 확인한다.** `ax-*` 는 16:9 라서 쇼츠에 넣으면 안 된다 (두 번 틀렸다)
3. 실패작은 지우지 말고 **desc 에 「⛔ 사용 금지」와 이유를 적는다** — 다음 세션이 또 집는다

### 실측된 함정

| 함정 | 실제로 일어난 일 |
|---|---|
| 글자 | 「no text」를 넣어도 **뭉개진 가짜 글자**가 들어간다. 종이·달력·간판 소재를 피한다 |
| 스타일 | 「flat 2D」를 주문해도 **3D 점토풍**으로 나올 수 있다. 라이브러리와 결이 갈린다 |
| 구도 | 피사체가 상단 1/3 에 몰리고 아래가 비기도 한다. 자막띠(bottom 460)와 겹치는지 본다 |
