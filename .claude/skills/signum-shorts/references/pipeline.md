## 0-A. ⛔ 앱 주소 — 이걸 매번 틀렸다

**`signumhq.com` 은 «웹사이트»다. 앱 주소가 아니다.**
대표가 여러 번 지적했는데 내가 계속 사이트 주소를 넣었다. 정본은 `.agent/APP_LINKS.json`.

```
앱 주소   https://www.signumhq.com/app     ← 기기 판별. iPhone→App Store, Android→Play
사이트    https://www.signumhq.com          ← 앱 주소가 «아니다»
사이트    https://www.signumhq.com
```

| 어디 | 무엇을 넣나 |
|---|---|
| **고정 댓글** | **iOS + Android 스토어 링크** (게이트가 강제. 사이트 주소만이면 불통과) |
| 설명 첫 줄 | 사이트 주소 (유튜브가 뒤를 자르므로 첫 줄) |
| 설명 본문 | 스토어 링크도 함께 |

**모든 업로드는 고정 댓글까지 처리하고 끝낸다.** 업로드 직후에는 영상 처리 중이라
댓글 API 가 400/403 을 내므로 **12초 간격 5회 재시도**한다. 「고정」만 사람이 누른다.

## 5. ⛔ 게이트는 «4층»이다 — 영상만이 아니다 (2026-08-21)

> 대표 지시: "게이트라는것이 영상만을 말하는것이 아니다"

```
① 소재  node scripts/topic-check.mjs      ← 2026-08-21 신설
② 대본  node scripts/script-check.mjs     ← 2026-08-21 신설
③ 영상  scripts/shorts-gate.mjs (계급별)
④ 메타  제목·태그·설명·고정댓글
```

`shorts-gate.mjs` 가 네 층을 «한 번에» 돌린다. `yt-upload.mjs` 가 이걸 자동 호출한다.
계획서(plan.json)에 **`scriptTag` 와 `evidence` 가 없으면 통과하지 못한다.**

### ① 소재 층 — 이 게이트가 생긴 이유

발행 22편 제목을 측정 수요 어휘 91개와 기계 대조 → **매칭 1편(4.5%)**.
21편이 「아무도 검색하지 않는 문장」이었다. 조회 중앙 42의 구조적 원인이다.
**소급 검사 결과 22편 «전부» 불통과.**

| 항목 | 기준 | 근거 |
|---|---|---|
| 제목에 수요 어휘 | `DEMAND.json` 어휘가 제목에 그대로 | 매칭 4.5% 였다 |
| 소재 수요 | >= 5,000 | 우리 최저 2,822 · 매크로 최하위 13,082 |
| 실증 근거 | >= 1건 | 지어내지 않는다 |
| 동음이의 오염 | <= 40% | "ai bubble" 은 게임 밈 21% |
| 근거 신선도 | <= 7일 (뉴스성) | — |

### ② 대본 층 — 격차가 가장 컸던 곳

조회 32만~84만 해설 7편 자동자막 계량 ↔ 우리 대본 32편.

| 항목 | 레퍼런스 중앙 | 우리 과거 | 기준 |
|---|---|---|---|
| 훅 유형 | 선언4·**반박2·질문1** | **선언 32/32** | 질문 또는 반박 |
| 숫자 밀도 | **1.0%** | 2.6% | <= 3.2% |
| 우리·너 비율 | **3.9%** | 1.9% | >= 2.5% |
| 단어/큐 | 6.9 | 7.1 | 5.0~7.6 |

**★ 핵심 발견: 숫자는 «자막»이 아니라 «화면»이 나른다.**
조회 240만 편은 화면 텍스트행 밀도 38% 인데 말의 숫자 밀도는 1.0% 였다.
훅에는 숫자를 넣지 않는다 — 훅은 «긴장»을 만들고 숫자는 근거로 뒤에 온다.

⇒ **이 형식을 계속 만든다:**
```
3D 캐릭터로 «두 자산·두 세력»을 의인화
갈등(경쟁·등돌림·추격) → 전환 → 결말(악수·이별·추월)  한 클립 안에
밝게(130+) · 세로 · 8~12초 · 컷은 1회 이내
```
소재를 정하면 그 편의 인사이트가 「A와 B의 관계 변화」이므로, 그 관계를 그대로 연기시키면 된다.

**클립 쓰는 법**
- 특정 장면을 겨냥하려면 `bg: { kind:'video', src, loopFrames, startFrom }` — `startFrom` 은 컴포지션 프레임
- ⛔ `startFrom + loopFrames` 가 **클립 길이를 넘으면 안 된다**. 넘으면 끝 프레임이 얼어붙고 컷 수가 튄다
- ⛔ 클립을 3곳 이상 쓰면 내부 전환 + 루프 재시작으로 컷/분이 상한을 넘는다 (실제로 24.2 로 걸렸다)
- 훅에 쓰면 **프레임 0 이 곧 썸네일**이 된다 — 사람·캐릭터가 있는 클립을 훅에 둔다

**개선 요청 사항** (다음 클립부터)
- 해상도 **1080×1920** (현재 720×1280 → 1.5배 확대라 약간 물러진다)
- 코인·금괴 표면의 «글자»는 빼 달라 (AI 생성 글자가 깨져 보인다)
