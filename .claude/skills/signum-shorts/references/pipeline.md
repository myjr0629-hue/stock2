## 0-A. ⛔ 앱 주소 — 이걸 매번 틀렸다

**`signumhq.com` 은 «웹사이트»다. 앱 주소가 아니다.**
대표가 여러 번 지적했는데 내가 계속 사이트 주소를 넣었다. 정본은 `.agent/APP_LINKS.json`.

```
앱 주소   https://www.signumhq.com/app     ← 기기 판별. iPhone→App Store, Android→Play
사이트    https://www.signumhq.com          ← 앱 주소가 «아니다»
사이트    https://www.signumhq.com
```

| 어디 | 무엇을 넣나 |
|---|---|
| **고정 댓글** | **iOS + Android 스토어 링크** (게이트가 강제. 사이트 주소만이면 불통과) |
| 설명 첫 줄 | 사이트 주소 (유튜브가 뒤를 자르므로 첫 줄) |
| 설명 본문 | 스토어 링크도 함께 |

**모든 업로드는 고정 댓글까지 처리하고 끝낸다.** 업로드 직후에는 영상 처리 중이라
댓글 API 가 400/403 을 내므로 **12초 간격 5회 재시도**한다. 「고정」만 사람이 누른다.

## 0-B-3. ⛔ 제목은 과감하게. 게이트가 얌전하게 만들지 않는다 (2026-08-21)

> "제목을 과감하게 소제를 과감하게 작성한다"

근거를 다시 보니 **내가 «없는 근거»로 제목을 묶고 있었다.** 두 규칙을 풀었다.

| 규칙 | 근거 | 조치 |
|---|---|---|
| 수요 어휘 포함 | 22편 중 1편만 매칭 · 조회 중앙 42 | **유지 — 진짜 관문** |
| 동음이의 회피 | "ai bubble" 게임밈 21% | 유지 |
| 1문장 | 대비형 40 vs 그 외 104 (n=22) | 유지 |
| **Why/How 시작** | **n=3** | **해제** — 표시만 한다 |
| **물음표 금지** | **"효과 없음(|r|<=0.06)"** | **해제** — «효과 없음»은 «금지 사유»가 아니다 |

**이제 이런 제목이 통과한다:**
```
Options Trading: The Friday Trap Nobody Shows You
Why Are Tech Stocks Frozen At One Price Today?
The Max Pain Trap Behind Options Trading Every Friday
```
막는 것은 둘뿐이다 — **검색되는 말이 없는 제목**, **이모지**.

## 0-B-4. ⛔ 한 소재에 매몰되지 않는다 — 조사는 매번 새로 (2026-08-21)

> "금에 매몰되어있는 그런일은 두번다시 없어야한다. 항상 조사에는 신선함을 유지하고"

**무엇이 원인이었나 (기록):** 금 영상을 한 편 만든 뒤 계속 금으로 돌아갔다.
파보니 **수요표가 두 지표를 섞고 있었다** — 옛 항목은 «원 검색 수요»(gold 84,262),
새 항목은 «소형 채널 조회 중앙». 그래서 게이트가 금에 계속 초록불을 줬다.
**실측 소형중앙은 256 이다.** 전 항목을 소형중앙으로 통일하고 금에 경고를 달았다.

**재발 방지:**
- `DEMAND.json` 의 값은 **전부 «소형 채널이 실제로 받는 조회»** 다. 원 수요를 섞지 않는다
- 소재는 **매번 `market-wants` + `topic-radar` 를 새로 돌려서** 고른다. 지난번 목록을 재사용하지 않는다
- **같은 소재를 연속 2편 만들지 않는다.** 만들었으면 다음은 다른 축으로 간다
- ⛔ **여지 100% + 소형중앙 200 이하 = 빈 시장이 아니라 «없는 시장»이다** (AMD 株 33 의 함정)

## 0-D. ★ 하루 3편 — 슬롯 틀 (2026-08-21 신설)

> 대표 지적: "영상을 만드는것은 좋은데 그것이 «그 시점 불필요한 영상»이면 안되는것이고
>  그리고 스케쥴 틀을 잡아야 할듯하다"

```bash
node scripts/slot-plan.mjs [YYYY-MM-DD]
```

### 시간대는 «시청자»가 아니라 «소재 유효성»으로 정한다

우리 채널 실측에서 **게시 시간대 효과는 잡히지 않았다** (구간 중앙 40~86, 전부 겹침, n=2~7).
그러니 시간으로 조회를 얻으려 하지 않는다. **그 시각에 그 소재가 «말이 되는가»**로 정한다.

| 슬롯 | KST | 성격 | 무엇을 |
|---|---|---|---|
| **A** | 20:00 | **LIVE-preview** | 미국 개장(22:30) 전 — 오늘 «벌어질» 것 |
| **B** | 06:00 | **LIVE-review** | 미국 마감(05:00) 후 — 어제 «벌어진» 것 |
| **C** | 13:00 | **EVERGREEN** | 장과 무관 — 개념·구조 (검색으로 계속 들어온다) |

### 소재의 «유효기간»

| 등급 | 유효 | 예 |
|---|---|---|
| **LIVE** | 그날뿐 | 만기일 · 지표 발표 · 오늘의 옵션북(맥스페인 괴리) |
| **FRESH** | 2~3일 | 상관 부호 전환 · 변동성 극단 |
| **EVERGREEN** | 무기한 | `options trading explained` 같은 개념 |

**내려가는 순서: LIVE → FRESH → EVERGREEN.**
⛔ **LIVE 소재가 없으면 «지어내지 않는다».** 없는 시의성을 만드는 순간 그 편이
   바로 「그 시점 불필요한 영상」이 된다. EVERGREEN 으로 채우거나 **빈 슬롯으로 둔다.**
⛔ 주말·휴장일에는 A·B 가 자동으로 EVERGREEN 이 된다 (장이 안 열리는데 LIVE 가 성립하지 않는다).

### 매일 도는 순서

```bash
node scripts/topic-radar.mjs      # 오늘의 이상값을 캔다
node scripts/slot-plan.mjs        # 슬롯 3개에 배정한다
#   → 배정된 소재로 대본 → 렌더 → 게이트 → 승인 → 업로드
```

## 2. 제목 — 실측 규칙 (게이트가 검사한다)

| 규칙 | 근거 |
|---|---|
| **한 문장** | 우리 채널 n=22 — 두 문장 대비형 15편 조회 중앙 **40** vs 그 외 7편 **104** |
| **Why / How 로 시작** | Why 형식 3편 중앙 **177** («Why Your Stock Ripped 23% on No News» 202) |
| **수요 앵커 또는 피드 프레임** | 개념편은 검색 수요 800+ 문구를 앞 34자에. 당일 뉴스는 수요가 휘발이라 Why 프레임으로 갈음 |
| **동음이의어 회피** | `max pain` 은 게임 «Max Payne» 과 충돌(1위 530만). 앞 12자에 두지 않는다 |
| 물음표·이모지·전부대문자 | 교차채널 n=1,964 에서 **전부 무의미**. 넣을 이유가 없으면 넣지 않는다 |

⚠ 형식 규칙의 근거는 **우리 채널 n=22(Why 는 n=3)** 다. 교차채널에서는 형식이 무의미했다.
→ **사전등록한 가설**이지 확정 규칙이 아니다. 누적 30편에서 재판정한다.

## 6. 배경 클립 — 「인사이트를 연기하는 클립」이 가장 세다 (2026-08-21)

⇒ **이 형식을 계속 만든다:**
```
3D 캐릭터로 «두 자산·두 세력»을 의인화
갈등(경쟁·등돌림·추격) → 전환 → 결말(악수·이별·추월)  한 클립 안에

```
소재를 정하면 그 편의 인사이트가 「A와 B의 관계 변화」이므로, 그 관계를 그대로 연기시키면 된다.

**클립 쓰는 법**
- 특정 장면을 겨냥하려면 `bg: { kind:'video', src, loopFrames, startFrom }` — `startFrom` 은 컴포지션 프레임
- ⛔ `startFrom + loopFrames` 가 **클립 길이를 넘으면 안 된다**. 넘으면 끝 프레임이 얼어붙고 컷 수가 튄다
- ⛔ 클립을 3곳 이상 쓰면 내부 전환 + 루프 재시작으로 컷/분이 상한을 넘는다 (실제로 24.2 로 걸렸다)
- 훅에 쓰면 **프레임 0 이 곧 썸네일**이 된다 — 사람·캐릭터가 있는 클립을 훅에 둔다

**개선 요청 사항** (다음 클립부터)
- 해상도 **1080×1920** (현재 720×1280 → 1.5배 확대라 약간 물러진다)
- 코인·금괴 표면의 «글자»는 빼 달라 (AI 생성 글자가 깨져 보인다)
