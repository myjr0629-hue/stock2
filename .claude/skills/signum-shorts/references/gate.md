> 실제로는 개념편에만 적용하고 **브리핑 템플릿은 감사하지 않았다.**
> 문서에 적어두면 다음 영상에서 또 빠진다. 그래서 **경로에 박았다.**

## 실행

```bash
node scripts/shorts-gate.mjs .agent/plans/YYYY-MM-DD.json   # 단독 검사
node scripts/yt-upload.mjs   .agent/plans/YYYY-MM-DD.json   # 업로드 — 게이트 불통과면 멈춘다
```

## 게이트가 막는데 영상이 멀쩡해 보이면 — 게이트를 먼저 의심한다 (2026-08-22)

**하루에 게이트 «자체»의 버그를 3건 찾았다.** 게이트가 틀리면 멀쩡한 영상을 고치려다 망가뜨린다.

판정법: **같은 자로 통과한 다른 편과 값을 대조한다.** 값이 같으면 계측 결함, 다르면 영상 결함.
> 실례: jpcons 자막띠 59.6% (기준 66~82%). 통과한 jpgamma·jpearn 은 66.1%.
> 훅 4.2초를 잘라내고 다시 재니 **세 편 모두 66.1~69.6%** — 영상은 멀쩡했고 «재는 구간»이 틀렸다.

| 찾은 버그 | 증상 | 고친 곳 |
|---|---|---|
| 수요 어휘 대소문자 | 제목만 소문자화하고 표의 키는 원형 비교 → `S&P500`·`FRB`·`新NISA` 등 8개가 **영원히 매칭 불가** | `topic-check.mjs` · `title-check.mjs` |
| 자막띠에 훅 포함 | 훅의 큰 글자가 55% 아래에 또 하나의 띠를 만들고, 높이가 같으면 동점에서 위쪽이 뽑힘 | `shorts-gate.mjs` — 앞 4.0초 제외 |
| 로고 없는 심볼 강제 | `SPY` 는 배지(빨간 500 타일)로 그려지는데 게이트가 프레임0에 넣으라고 막음 | `script-check.mjs` — `AMBIGUOUS_SYMS` |

⛔ 단, **게이트를 느슨하게 해서 통과시키지 않는다.** 고친 뒤 «이미 통과했던 편들의 값이
   그대로인지» 반드시 확인한다. (위 3건은 기존 4편의 값이 전혀 바뀌지 않았다.)

```bash
node scripts/_clip-diff.mjs <클립이름> ...   # 게이트와 같은 자로 프레임간 변화량
```

  «말하지 않으면» 심볼을 억지로 넣지 않는다 — 뜻 없는 타일이 프레임0을 차지한다.
