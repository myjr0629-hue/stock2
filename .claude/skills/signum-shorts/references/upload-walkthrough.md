# 업로드 실행 절차 (@SIGNUMHQ) — "등록하자" 하면 이 순서를 그대로 안내한다

> 2026-08-11 첫 업로드에서 실제로 확인한 화면 순서다. 화면마다 걸리는 지점이 정해져 있으니
> **사용자가 묻기 전에 그 지점을 먼저 알려준다.**

## 0. 파일 준비 (내가 먼저 해둘 것)

```
E:\SIGNUM_UPLOAD\YYYY-MM-DD\
  01_FLASH_<주제>.mp4 / 01_FLASH_<주제>_thumb.png
  02_BRIEF_<주제>.mp4 / 02_BRIEF_<주제>_thumb.png
  UPLOAD_NOTES.txt      ← 제목·설명·해시태그·고정댓글·체크리스트 전부
```
완성 즉시 이 구조로 복사하고 **폴더를 열어준다**(`explorer <경로>`).
임시 스크래치패드 경로를 그대로 안내하지 말 것 — 사용자가 못 찾는다.

## 1. 업로드 시작

우측 상단 **[만들기] → 동영상 업로드** → 파일 선택.
업로드가 시작되면 자동으로 **비공개 초안**으로 저장된다.

## 2. 세부정보 화면 — 걸리는 지점 4개

| 항목 | 주의 |
|---|---|
| **제목** | **파일명이 자동으로 들어가 있다.** 전체 지우고 확정 제목으로 교체 |
| **설명** | 채널 기본값이 이미 들어가 있다. **맨 앞에 커서를 놓고** 영상별 본문을 붙여넣고 빈 줄 하나 남긴다 (기본값은 뒤에 그대로 유지) |
| **썸네일** | `[파일 업로드]` → `*_thumb.png` (전화번호 인증 완료 상태여야 버튼이 보인다) |
| **재생목록 / 시청자층** | 재생목록 건너뛰기 · 아동용 아님은 채널 설정에서 자동 적용됨 |

### ⚠️ AI 사용 신고 — 가장 자주 놓치는 곳
아래로 스크롤 → **[자세히 보기]** 펼치기 → **「AI 사용」 → 「예」**

기준 3개 중 우리는 **"실제로는 발생하지 않았으나 진짜처럼 보이는 장면을 생성"** 에 해당한다
(트레이딩 플로어·거래소 외경·해협·연준 전부 AI 생성 실사풍).

- **선택해도 화면에 아무 변화가 없다** — 사용자가 "아무것도 안 생긴다"고 묻는 지점이니 미리 말해둘 것.
  라벨은 게시 후 시청자가 설명란을 펼쳤을 때 표시된다.
- 노출·수익 불이익 없음. **미신고 적발 시에만 제재.**
- 같은 화면: 유료 프로모션 **체크 안 함**, 자동 챕터 **체크 안 함**

## 3. 동영상 요소 — 둘 다 건너뛴다

- 관련 동영상: 연결할 다른 영상이 없거나 쇼츠에선 효용 낮음
- 자막: **우리 자막은 화면에 새겨져 있어 트랙을 넣으면 겹친다.** 유튜브 자동자막이 우리 TTS를 정확히 인식한다
  (더 정확한 SRT가 필요하면 워드 타임스탬프로 만들어 줄 수 있다고 안내)

## 4. 검토

저작권 검사 통과 확인 (자체 TTS + AI 영상이라 클레임 대상 없음).

## 5. 공개 상태 — 비공개 저장이 원칙

**「비공개」 선택 → [저장]**. 그다음 사용자에게:

1. **휴대폰 유튜브 앱**에서 비공개 영상 재생
2. 확인 3가지 — ①첫 프레임이 썸네일로 잘 뜨는지 ②**우측 버튼·하단 UI에 자막/로고가 가려지지 않는지**(실기기에서만 확인 가능) ③소리 정상
3. 이상 없으면 **스튜디오 → 콘텐츠 → 해당 영상의 「공개 상태」 열 클릭 → 공개**

## 5-b. 자동 자막 덮어쓰기 — ⚠️ 방법이 «반박됐다» (2026-08-15 재실측)

**문제**(2026-08-11 실측, 유효): 우리 자막은 화면에 새겨져 있는데 유튜브가 자동 자막을
또 얹으면 **이중 자막**이 되고, 우리 하단 자막을 피해 **상단(마스트헤드 위)** 에 배치돼
제목을 가린다.

### ⛔ 폐기된 방법 — 빈 자막 업로드

`blank_captions_EN.srt`(본문이 «완전히 빈» 큐)를 올리면
**유튜브가 거부한다**: 「빈 자막은 게시할 수 없습니다 — 자막이 비어 있습니다.」
2026-08-15 업로드 화면에서 직접 확인. **이 문서에 «된다»고 적혀 있던 것은 틀렸다.**
(이전 기록은 게시 완료까지 확인하지 않고 쓴 것으로 보인다.)

### 순서 — 측정부터, 해킹은 그 다음

**① 먼저 «정말 문제인지» 재확인한다 (30초).**
자막 단계를 **건너뛰고** 비공개로 저장 → 휴대폰 쇼츠 플레이어에서 재생 →
자동 자막이 실제로 뜨는지, 마스트헤드를 가리는지 **눈으로 본다.**
- 안 뜨면 → 이 절차 자체가 불필요하다. 여기서 끝.
- 뜨면 → ②로.

**② 보이지 않는 문자 한 개짜리 자막으로 덮어쓴다.**
「빈 자막」 검사만 통과하면 되므로 본문에 **제로폭 공백(U+200B)** 한 글자를 넣는다.
화면에는 아무것도 안 보이지만 «빈 문자열»은 아니다.

| 파일 | 용도 |
|---|---|
| `E:\SIGNUM_UPLOAD\invisible_captions_EN.srt` | 1순위 |
| `E:\SIGNUM_UPLOAD\invisible_captions_EN.vtt` | SRT 가 거부되면 |

바이트 구조 (SRT · CRLF · UTF-8, 41바이트):
```
1␍␊
00:00:00,000 --> 00:00:00,200␍␊
<U+200B>␍␊
␍␊
```
큐를 **0.2초로 짧게** 두는 것이 핵심이다. 길게 깔면 본문이 안 보여도
플레이어가 «자막 배경 박스»를 영상 내내 그릴 위험이 있다.
수동 트랙이 하나라도 있으면 그 언어의 자동 자막은 생성되지 않으므로 0.2초로 충분하다.

⚠️ **②도 아직 미검증이다.** 통과/거부를 확인하면 그 결과를 여기에 바로 적는다.
③ 둘 다 막히면 자막 단계를 포기하고, 대신 **번인 자막 위치를 조정**해
자동 자막과 겹치지 않게 하는 쪽을 검토한다 (템플릿 수정이므로 마지막 수단).

자동 자막은 삭제 옵션이 없다 — 덮어쓰기만 가능하다.

## 6. 고정 댓글 (공개 직후 — 잊기 쉬움)

댓글 작성 → 자기 댓글 우측 ⋮ → **고정**. 문구는 `UPLOAD_NOTES.txt`에 미리 넣어둔 질문형.

예: *"Base rate: 51 oil shocks since 2021, S&P higher 64% of the time five days later. Would you take that bet? Why not?"*

**질문형인 이유**: 댓글 유도 = 참여 신호. 단정형 요약은 반응이 없다.

## 7. 24시간 체크포인트 (다음 영상에 반영)

분석 → 해당 영상에서 3가지만 본다:
- **조회수**
- **평균 시청 지속시간 / 완주율**
- **시청자 유지율 그래프의 첫 3초 낙폭**

첫 3초에서 크게 빠지면 → 훅(커버 문구·첫 컷) 수정
중반에서 빠지면 → 서사(인사이트 등장 시점) 앞당김
끝까지 유지되는데 구독 전환이 없으면 → 아웃트로 CTA 검토
