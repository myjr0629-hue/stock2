## ★★★ 제1원칙 — 사람은 해석하기 싫어한다

## ★ 자동 맞춤 — 겹침을 «구조적으로» 없앤 장치

대표 지적(2026-08-13): **"겹치게 나오는 것, 맞지 않는 것에 동그라미 표시가 있다."**

원인은 전부 하나였다 — **폰트 크기를 고정하고 «값이 짧을 것»이라고 가정한 것.**
`value: 'HIDDEN TAPE'`(11자)가 들어오자 200px 고정 폰트가 가로를 넘겨 두 줄로 감겼고,
세로가 두 배가 되며 위(헤드)와 아래(자막)를 **둘 다** 덮었다.

→ `fitFont(text, maxW, maxH, ideal)` 로 **대본이 뭘 넣든 칸 안에 들어오게** 폰트를 깎는다.
   제목 띠·punch·duel·meter·steps·stack·CTA 전부 적용. 가정을 없앴다.

**링(동그라미)은 숫자에만 친다** — `ringable(v) = /\d/.test(v)`.
손으로 치는 동그라미는 「이 숫자를 봐」라는 뜻이다. `HIDDEN TAPE` 같은 문구에 치면
뜻이 없고 지저분하기만 하다.

**링은 글자 높이의 1.45배** → 위아래로 각각 0.225×폰트만큼 삐져나온다.
그 여백(`pad = 폰트×0.27`)을 라벨·서브 양쪽에 잡지 않으면 둘 다 덮는다.

## 검수는 «전수»로 — `scripts/frame-sweep.mjs`

```bash
node scripts/frame-sweep.mjs out/x.mp4 2 10
```
2초 간격으로 전 구간을 뽑아 5열 컨택트시트로 만든다.
**프레임 몇 장만 뽑아 보는 검수로는 겹침을 못 잡는다** — 겹침은 «특정 비트의 특정 값»
에서만 터지기 때문이다. 짧은 값 비트만 보면 멀쩡해 보인다. 발행 전 필수.

## 실패에서 나온 10가지 (전부 실측)

1. **밝기를 올리면 흰 글자가 씻긴다.** 그림자로는 부족하다.
   → **두꺼운 검정 외곽선**(`outline(px)`)이 유일한 해법. 카드를 다시 넣으면 다큐로 돌아간다.
   자막 11px · 헤드 9px · 대결값 10px · 루프 12px.

2. **자막을 비트당 한 장으로 띄우면 시각물을 덮는다.** 26자 기준 4줄이면 66px 초과.
   → 문장 경계 → 쉼표 경계 → 단어 순으로 쪼개 «카드 여러 장»으로 순차 표시.
   **진짜 해법은 대본에서 한 문장 ≤ 52자를 지키는 것.**

3. **마커 링 세로 비율은 폰트의 1.45배 이상.** 1.16으로 잡았다가 링이 숫자를 관통했다.
   가로는 글자당 0.66em. `ringSize(chars, fontSize)` 사용. 위치는 반드시 중앙 정렬
   (`left/top:0` 이면 아래 줄을 덮는다).

4. **대결 색은 «부호»가 정한다.** 좌=민트/우=코랄로 고정했다가 `-1.13%`가 초록으로 나갔다.
   부호 없는 값($91.9M, 79%)일 때만 좌/우로 대비.

5. **형광펜 범위는 문자 위치로 잡는다.** 줄 안에서 문자열을 찾으면 강조 구간이
   줄바꿈에 걸릴 때마다 조용히 사라진다.

6. **폰트 고정 금지.** 값이 길어지는 순간 감겨서 위아래를 덮는다 → `fitFont` (위 참조).

7. **제목 띠도 감기면 안 된다.** 92px 고정으로 뒀더니 「green.」한 단어가 3번째 줄로
   흘러내렸다. 띠는 «줄 수가 곧 높이»다 → 각 줄을 한 줄로 못 박는다.

8. **절 안에서 끊을 땐 기능어 «앞»에서.** 가운데를 자르면 앞 카드가 말이 안 된다.
   ✕ `Consumer discretionary was the only / sector to close red,`
   ○ `Consumer discretionary was the only sector / to close red,`
   (`BREAK_BEFORE`: to, of, in, for, and, that, which, where …)

9. **루프 화면 — 문장은 «위 정렬», 배지는 그 아래 고정.** 문장을 가운데 정렬해 두고
   배지를 고정 y 에 뒀더니 문장이 3줄이 되며 배지 자리까지 내려와 겹쳤다.

10. **아웃트로도 외곽선.** 골드 터널 배경이 밝아 앰버 「SIGNUM HQ」가 씻겼다.
    본문 규칙이 CTA 에도 그대로 적용된다.

## 만드는 순서

```bash
node scripts/tts-beats.mjs DUEL813
npx remotion render src/remotion/index.ts CasualDUEL813 out/x.mp4
```

대본은 `scripts-casual.ts` 에 `SCRIPT_<이름>` 으로 (tts-beats 가 `scripts.ts` 의
re-export 를 통해 찾는다). Root.tsx 등록은 `CasualXXX` / `CasualXXX-tt` / `-reels`.

⚠️ `scripts-casual.ts` 는 `scripts.ts` 를 import 하지 않는다 (순환). A/B 대조판처럼
기존 대본을 재사용할 때는 Root.tsx 에서 조립한다.
