## 0. 조회 0 을 만나면 — 만듦새를 고치기 «전에» 이 순서로 잰다

**틀린 순서**: 화면이 이상한가 → 목소리가 이상한가 → 고친다
**맞는 순서**: **보여지긴 했는가** → 보여졌는데 안 눌렸는가 → 그때 만듦새

```bash
SIGNUM_YT=jp node scripts/_diag-video.mjs <videoId>   # 배포 가능 상태
SIGNUM_YT=jp node scripts/_diag-reach.mjs <videoId>   # 노출 vs 클릭
```

`_diag-video` 가 보는 것 — 하나라도 걸리면 «만듦새는 원인이 아니다»
| 항목 | 나쁜 값 | 뜻 |
|---|---|---|
| `madeForKids` | true | 피드 배포가 사실상 죽는다 |
| `privacyStatus` / `uploadStatus` | private / failed | 애초에 안 나갔다 |
| `regionRestriction` | 있음 | 일본에서 안 보인다 |
| `defaultAudioLanguage` | 비어 있음 | 일본 시청자에게 안 맞춰진다 |

**애널리틱스가 「0」이 아니라 «행 자체가 없으면»** = 집계될 만큼도 안 나갔다는 뜻이다.
그건 만듦새 문제가 아니라 **시드가 없다**는 뜻이고, 답은 하나다 — **편수**.

> 1호 실측: 차단 0건. 애널리틱스 행 0개. 채널에 영상 1개·구독 0.
> 레퍼런스 채널은 하루 5.7편, 우리는 1편 올리고 멈춰 있었다.

## 2. 길이 — 일본은 «짧을수록» 유리하다. 단 15초는 아니다

일본 쇼츠 247편(1년 이내·구독자당 조회 기준):
**스피어만 rho = −0.208 · t = −3.32 · n = 247** → 유의하다.

| 구간 | 편수 | 구독자당 조회 중앙 |
|---|---|---|
| 0~15초 | **4** | 745.6 ← **2편이 TV광고**. 오염 |
| 15~20초 | 4 | 5.37 |
| 25~30초 | 10 | 0.032 |
| 30~35초 | 16 | 0.005 |
| 35~45초 | 47 | 0.042 |

⇒ **ja 길이창 = 20~32초** (`scripts/shorts-gate.mjs` 의 `SEC_RANGE_BY_LANG`)
⛔ 31~38초는 «미국» 535편으로 정한 값이다. 일본에 그대로 씌우지 않는다.
⛔ 「15초로 압축」은 따르지 않는다 — n=4 이고 그중 2편이 광고다. 25~45초 안에서는 데이터가 구분을 못 한다.

## 4. 아웃트로 — 일본판은 «뺀다» (`noOutro: true`)

1호의 23초 프레임이 통째로 「SIGNUM HQ FREE · iOS & Android」 **정지 카드**였다.
쇼츠에서 정지 화면은 시청자에게 「끝났다」 신호이고, 그 순간 스와이프된다 — 루프가 끊긴다.

```ts
noOutro: true,        // 마지막 비트가 «곧바로» 루프백으로 이어진다
```
⛔ 미국 채널은 앱 유입이 사업 목적이라 **기본은 켠 채로 둔다**. 끄는 것은 채널 판단이다.
⛔ `noOutro` 대본은 `outro` 블록 자체를 쓰지 않는다 (타입에서 선택 항목).

## 5. 화면 위의 언어 — 영어 한 줄도 남기지 않는다

```ts
disclaimer: '教育目的のみ。投資助言ではありません。',
```
기본값이 영어(`Educational only. Not investment advice.`)라 일본 영상에 그대로 나갔었다.
영어 한 줄이 박혀 있으면 「외국산 자동 생성」으로 읽힌다.

⛔ 낭독에서 **한자 오독**을 피한다. `板` 은 いた/ばん 로 갈린다 → `数字` 처럼 모호하지 않은 말로.
⛔ 직역투 금지 — 「今夜、その株はここにいます」 같은 문장은 영어를 기계 번역한 티가 난다.
⛔ 화면 문구의 숫자는 **아라비아 숫자**, 낭독용 텍스트는 **한자 표기**로 나눈다
   (썸네일에서 「七百六十八」은 한눈에 안 읽힌다).

## 8. 이 과정에서 «게이트 자체»에서 찾은 버그 3건 (전부 수정됨)

기록해두는 이유: 게이트가 틀리면 «멀쩡한 영상을 고치려다» 망가뜨린다.

| 버그 | 증상 | 수정 |
|---|---|---|
| 수요 어휘 대소문자 | 제목만 `toLowerCase()` 하고 표의 키는 원형 비교 → `S&P500`·`FRB`·`新NISA` 등 **8개 어휘가 영원히 매칭 불가** | `topic-check.mjs` / `title-check.mjs` 양쪽에서 키도 소문자화 |
| 자막띠에 훅 포함 | 훅의 큰 글자가 55% 아래에 «또 하나의 띠»를 만들고, 본문 띠와 높이가 같으면 동점에서 위쪽이 뽑힘 → 멀쩡한 영상이 59.6% 로 나옴 | `shorts-gate.mjs` 에서 앞 4.0초 제외. 대조: 훅 제외 시 3편 모두 66.1~69.6% 로 일치 |
| 로고 없는 심볼 강제 | `SPY` 는 로고 파일이 State Street 마크라 «빨간 500 타일»로 그려지는데, 게이트가 프레임0에 그걸 «넣으라»고 막음 | `AMBIGUOUS_SYMS` 로 제외 (SPY·QQQ·DIA·GLD·IWM·TLT·VIX·SOX 등) |

⛔ **교훈**: 게이트가 막는데 영상이 멀쩡해 보이면, **먼저 게이트가 무엇을 재는지 확인한다.**
   같은 자로 통과한 다른 편과 «값을 대조»하면 영상 결함인지 계측 결함인지 바로 갈린다.

## 9. 일본 편 만들 때 순서 (요약)

```bash
# 1) 소재 — 문(DEMAND_JA) × 이상값(사전등록 검정) × 시의성
# 2) 대본 — scripts-jp.ts. 배경은 «실사»에서, 지뢰 클립 회피
# 3) 낭독 — SIGNUM_VOICE 를 «반드시» 붙인다
SIGNUM_VOICE=LIisRj2veIKEBdr6KZ5y node scripts/tts-beats.mjs <TAG>
# 4) 길이 — 20~32초 안인지 «렌더 전»에 확인 (렌더는 5분 걸린다)
node scripts/_len.mjs <TAG>
# 5) 렌더 → 마감
npx remotion render src/remotion/index.ts Briefing<TAG> <out.mp4> --log=error
node scripts/finish-video.mjs <out.mp4>
# 6) 계획서(lang:'ja') → 태그 500자 → 게이트 → 업로드
node scripts/tag-fill.mjs <plan.json> --write
node scripts/shorts-gate.mjs <plan.json>
SIGNUM_YT=jp node scripts/yt-upload.mjs <plan.json>
```
⛔ 업로드는 **비공개+예약**까지다. 개시(공개)는 대표가 한다.
⛔ 고정 댓글은 예약 상태에서 403 이 난다 — 공개 후 대표가 단다.
