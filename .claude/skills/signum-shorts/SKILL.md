# SIGNUM 쇼츠 제작소

> **채널의 상품은 뉴스가 아니라 판단이다.** "무슨 일이 있었나"가 아니라
> **"내가 데이터로 확인해보니 통념이 틀렸다"** 를 판다.
>
> **순서는 절대 불변**: `사람들이 궁금해하는 것 → 훅 강한 제목 → 팩트 → 영상 → 스토리`
> 딱딱한 주제 금지. 데이터 스캔은 소재를 *고르는* 도구가 아니라 답을 *증명하는* 도구다.
> 소재는 **보통 투자자가 입으로 내뱉는 질문 한 문장**으로 쓸 수 있어야 한다 — 못 쓰면 폐기.

## 0-A. ★ 실행 순서는 `references/daily-run.md` 하나로 끝난다

**영상 제작 요청을 받으면 먼저 `references/daily-run.md` 를 읽는다.**
캡처 → 우위스캔 → 대본 → 음성 → 클립발주 → 후처리 → 배선 → 검수 → 출고 8단계와,
**각 단계에서 실제로 당한 함정**이 붙어 있다. 매번 다시 발견하지 말 것.

특히 반복해서 잊은 것 4개:
1. Flow 프롬프트는 **초가 첫 단어** (`6s. ...`), 길이는 **비트 길이보다 길게**
2. 워터마크는 **상단-좌 0.9 크롭**으로 제거 · 같은 클립은 **zoom 변형**으로 재사용
3. 캡처의 **TOP MOVERS·SECTOR HEATMAP 은 시간외** — 개별 수치는 Polygon 종가로 다시 잰다
4. 배경은 **금융·테크·산업 소재만** — 추상 소품(볼베어링·구)은 시장을 말하지 않는다

## 0-B. 「라이브러리 업데이트」 — 배경 클립이 추가됐을 때

사용자가 **"라이브러리 업데이트"** (또는 "클립 추가했어" / "영상 넣어놨어") 라고 하면
되묻지 말고 아래를 그대로 실행한다. 원본 폴더는 **`E:\SIGNUM_UPLOAD\video`**.

```bash
node scripts/bg-scan.mjs            # ① 새 파일만 찾아 규격 재고 검토 프레임 추출
```

② **검토 프레임(`public/shorts/bg/.review/`)을 내가 하나씩 «본다».**
   파일명이 UUID라 내용을 알 수 없다 — 자동 분류하지 말고 반드시 눈으로 확인한다.

③ `.agent/BG_LIBRARY.json` 의 새 항목에 네 칸을 채운다:

| 칸 | 뜻 |
|---|---|
| `slug` | 파일명이 될 이름 (`fiber-one-lit` 처럼 «무엇이 보이는지») |
| `role` | **서사 역할** — 소재가 아니라 «어떤 문장에 붙는가» |
| `light` | `bright` / `mid` / `dark` — 게이트 밝기 하한(25) 관리용 |
| `desc` | 한 줄 설명. «이 그림이 말하는 것»을 적는다 |

**role 목록**: `open`(장 시작) · `close`(마감) · `chips` · `energy` · `money` · `institution` ·
`signal`(하나만 다르다) · `hidden`(안 보이는 층) · `conflict`(깨졌다·어긋났다) · `depth` ·
`capex` · `calm` · `robotics` · `space`

```bash
node scripts/bg-scan.mjs --build    # ④ 라벨 붙은 것만 굽는다
node scripts/bg-scan.mjs --list     # ⑤ 역할별로 확인하고 사용자에게 보고
```

굽는 과정에 **워터마크 상단-좌 0.9 크롭 · `-g 15` · 오디오 제거**가 자동으로 들어간다.
`loopFrames` 도 자동 계산되므로 대본에는 그 값을 그대로 쓴다.

**보고할 것**: 새로 들어온 개수 · 역할별 분포 · «문장을 실제로 말하는» 클립 지목 ·
**비어 있는 역할**(다음 수확 우선순위).

## 8-C. ⛔ 인사이트는 «선택»이 아니다 (대표 지시 2026-08-21)

> "강력한 인사이트를 줘야 무엇인가 얻어가지 상황설명만 하는것이 아니라
>  **모든 쇼츠에 그점을 강력하게 박아라** 우리자원을 활용해도 되고
>  니가 자체 분석을 해도되고 그것이 너의 능력이지"

**인사이트의 정의 — 넷을 다 갖춰야 인사이트다. 하나라도 없으면 상황설명이다.**

| | 왜 |
|---|---|
| ① 우리가 «계산»한 수치 | 남이 발표한 숫자를 옮긴 건 인사이트가 아니다 |
| ② 비교 기준 | 수준값만으로는 «드물다»를 말할 수 없다 |
| ③ 표본 크기 n >= 20 | 소표본 결론 금지 |
| ④ p < 0.05 또는 백분위 <=10/>=90 | 평범한 값은 인사이트가 아니다 |

그리고 **그 문장이 자막에 그대로 나와야 한다** (`saidAs`). 안 나오면 시청자는 못 얻는다.

**실례 (GOLD821)**: "왜 금이 오르나" 에 답하면서 «달러 때문»만 대고 끝내려 했다.
대표 지적 — "왜 오르는지에 대한 인사이트도 넣어줬어?" 다시 재보니:

| 검정 | 결과 |
|---|---|
| 달러 링크가 최근 강해졌다 | −0.39 → −0.60, **p=0.212 — 유의하지 않다. 주장 금지** |
| **금↔비트코인 결합** | 0.23 → 0.62, **z=2.81 · p=0.005 · 94백분위** ← 이게 인사이트 |
| 달러+비트코인 설명력 | 연간 19% → 최근 50% |

⇒ 「공포 헤지」가 아니라 「통화 헤지」로 성격이 바뀌었다. **아무도 안 하는 말이고 우리가 계산했다.**

## 8-D. ⛔ 함정 — cutFor 가 «결론»을 통째로 잘라먹는다

`variants.ts` 의 `cutFor` 는 길이 상한(yt 40초)을 맞추려고 **뒤에서부터** 비트를 버린다.
결론·인사이트는 대개 마지막에 있다 → **가장 중요한 한 마디가 소리 없이 사라진다.**
렌더는 정상이고 영상 게이트도 통과한다. 2026-08-21 에 실제로 당했다.

- `role: 'verdict'` 는 이제 자동으로 prio 1 (절대 안 버림)
- 인사이트 비트에는 **`prio: 1` 을 직접 붙인다**
- `cut-audit.mjs` 가 매번 검사한다
