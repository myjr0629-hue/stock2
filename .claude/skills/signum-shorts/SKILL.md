# SIGNUM 쇼츠 제작 표준 공정

> 채널 성격: **뉴스 설명이 아니라 인사이트.** 우리가 파는 것은 "무슨 일이 있었나"가 아니라
> **"내가 데이터로 확인한 결과, 통념이 틀렸다"** 이다. 이 규칙이 모든 단계를 지배한다.

## 0. 두 템플릿 (성격이 다르다 — 섞지 말 것)

| | **MARKET FLASH** | **RESOURCE / DEEP BRIEF** |
|---|---|---|
| 키커 | `MARKET FLASH` | `RESOURCE BRIEF` (소재별 변경 가능) |
| 길이 | 28–35초 | 45–55초 |
| 비트 | 7–8 · 간격 0.30s | 9–12 · 간격 0.42s |
| 카드 | 3–4장 | 5–7장 |
| 분기점(날짜) | 1개 | 2개 |
| 영상 톤 | 실사 다큐 | 심볼릭·판타지·미니어처 |
| 쓰는 때 | 오늘/어제 사건이 있을 때 | 구조적 주제(자원·AI·수급) |

## 1. 소재 선정 (하루 1개)

우선순위대로 훑고, **"통념과 데이터가 어긋나는 지점"이 있는 소재를 고른다.**
어긋남이 없으면 그 소재는 버린다 — 설명형 영상이 되기 때문이다.

1. WebSearch로 당일 미국 시장·매크로·자원 헤드라인
2. 각 후보에 대해 자문: *"뻔한 해석은 무엇인가? 그 해석을 검증할 데이터가 우리에게 있는가?"*
3. **날짜가 있는 분기점**(지표 발표·실적·회의)이 붙는가? 없으면 시청 가치가 낮다

## 2. 팩트 검증 (예외 없음)

- 화면에 나갈 **모든 숫자**는 게시 당일 1차 출처로 실검증. 검증 못 하면 그 숫자는 뺀다.
- 종목·지수·ETF 수치는 **Polygon 직접 조회**(`scripts/baserate.js` 참고, 키는 harvest와 동일)
- 추정·전망은 반드시 `analysts estimate` 같은 귀속 표기
- 검증표(수치·출처·조회일)를 보고에 첨부

## 3. 인사이트 엔진 — 이 스킬의 핵심

`references/insight-engine.md` 필독. 요약: 뉴스에 **우리만 할 수 있는 계산**을 붙인다.

- **베이스레이트**: "이런 일이 과거 N번 있었고, 그 뒤 실제로 X% 확률로 Y였다" — `scripts/baserate.js`
- **자원 데이터**: XS 스코어·옵션플로우·다크풀·13F 등 우리 파이프라인 실측
- **교차 도메인**: 자원↔AI capex↔금리처럼 서로 다른 뉴스면을 하나의 인과로 묶기
- **정량 메커니즘**: "영향이 있다"가 아니라 "+10% → +0.4pp" 수준으로
- **반증 조건**: "이 수치가 깨지면 내 판단이 틀린 것" — 인사이트이자 컴플라이언스 안전장치

**금지**: 뉴스 요약만으로 끝내기, 남의 애널리스트 코멘트 재인용으로 인사이트 대체하기.

## 4. 대본 (레퍼런스 아키텍처 + 인사이트 반전)

```
① 훅(1문장, 첫 프레임 = 썸네일)   "The rally just blinked."
② 사실 즉납(숫자 2–3개)          기록·급등·급락
③ 뻔한 해석 제시                  "패닉이 말하는 것"
④ ⭐ 우리 조사 공개               "We ran every X since 2021. 51 of them."
⑤ ⭐ 반전 결론                    "The scare was never the trade. The rotation was."
⑥ 분기점(날짜·시각)               "Tomorrow 8:30 AM ET."
⑦ 정리 = 볼 것 1–3개
```

- 나레이션 문장은 짧게(평균 12단어 이하), 숫자는 **말로 풀어서**(`fourteen thousand`)
- 자막 = 나레이션 **전문**, 워드 타임스탬프로 싱크 (요약 자막 금지)
- 컴플라이언스: `references/compliance.md` — 매수/매도·목표가·수익 보장 금지, 베이스레이트·조건부 서술만

## 5. 후킹 문구 / 제목 / 썸네일

- **커버(첫 1.45초)**: 나레이션 첫 문장 + 핵심 수치. 이것이 사실상 썸네일이다
- 제목 공식: `<반전 주장>. <검증 근거>` 예) *"Oil Spiked 5%. History Says Buy the Rotation, Not the Fear."*
- 썸네일 문구: 3–5단어 + 숫자 1개. 붉은색은 리스크, 초록은 시장
- 설명란 하단 고정: 면책 + signumhq.com

## 6. 클립 발주서 (사용자가 생성)

`references/clip-briefs.md` 문법대로. 핵심 규칙:
- **초를 프롬프트 첫 단어로 명시** (`6 seconds.` — Flow는 4/6/10초)
- **텍스트·간판·읽히는 화면 전면 금지** (달력 오타 사건)
- 실사 vs 심볼릭 배분을 의도적으로 (현실=신뢰, 판타지=욕망)
- 재사용 라이브러리 우선 (NYSE·연준·화이트 스튜디오는 재생성 불필요)

## 7. 조립 (`scripts/build-video.js` 패턴)

1. `gen_vo.js` — ElevenLabs `Adam (SIGNUM narration)` + 워드 타임스탬프 JSON
2. 비트 타임라인 = VO길이 + 간격(템플릿별), 아웃트로 = 나레이션 종료 + 2초
3. 샷 컷팅(비트당 1–3컷, zoom 변형으로 같은 클립 재사용), 룩별 컬러그레이드
4. 오버레이: 커버 → 마스트헤드 → 카드 → 카라오케 자막 → 브랜드 락업
5. **레이어 순서 규칙**: 자막·카드는 ASS(합성 단계), 그 위에 얹을 로고는 **합성 후 오버레이**
   — 반대로 하면 카드가 로고를 덮어 흐려진다 (실제 발생한 버그)
6. 정지 이미지 오버레이는 `-loop 1 -t <총길이>`로 스트림화 (중간 드롭아웃 방지)
7. 브랜드 플레이트에 **면책 한 줄** 상시 표기: `NOT INVESTMENT ADVICE`

## 8. QC (발송 전 필수 — 사용자에게 먼저 묻지 말 것)

`scripts/qc.js` 실행 + 결과 육안 검수:
- 규격 1080×1920 / 24fps / 목표 길이 / 오디오 2ch
- 비트별 오디오 레벨(무음 구간 0)
- 비트별 프레임: 자막 프레임 내부·카드 겹침 0·로고 선명·날짜 선명
- 첫 프레임이 썸네일급인지
- 꼬리 묵음 없는지 (쇼츠 즉시 루프)

결함을 찾으면 **고친 뒤에 보고**한다. 발견/수정 내역을 보고에 포함.

## 9. 게시 세팅

- 제목·설명·태그: `references/publish.md`
- **합성 콘텐츠 공개 체크 필수** (실사풍 AI 생성)
- 첫 게시는 비공개 업로드 → 실화면 확인 → 공개

## 절대 금지

- 검증 안 된 숫자 노출 · 인사이트 없는 요약 영상 · 매매 권유 표현
- 장면 안에 글자 생성시키기 · 자막을 요약해서 나레이션과 어긋나게 하기
- QC 없이 발송
