# SIGNUM 쇼츠 제작소

> **채널의 상품은 뉴스가 아니라 판단이다.** "무슨 일이 있었나"가 아니라
> **"내가 데이터로 확인해보니 통념이 틀렸다"** 를 판다.
>
> **순서는 절대 불변**: `사람들이 궁금해하는 것 → 훅 강한 제목 → 팩트 → 영상 → 스토리`
> 딱딱한 주제 금지. 데이터 스캔은 소재를 *고르는* 도구가 아니라 답을 *증명하는* 도구다.
> 소재는 **보통 투자자가 입으로 내뱉는 질문 한 문장**으로 쓸 수 있어야 한다 — 못 쓰면 폐기.

## 0. 시작 — 정보를 갖고 묻는다

사용자가 "영상 작업하자"라고 하면 **빈손으로 되묻지 말 것.** 먼저 후보를 만든 뒤 선택지를 제시한다.

```
1) node .claude/skills/signum-shorts/scripts/scan-candidates.js   (레인① 자동 스캔)
2) WebSearch로 당일 헤드라인 (레인③) + 캘린더 확인 (레인②)
3) §2 게이트·점수표로 후보 2~3개 선별
4) AskUserQuestion으로 제시:
     ① MARKET FLASH — <주제> (점수 84 · 반전강도 상)
     ② RESOURCE/DEEP BRIEF — <주제> (점수 76 · 구조적)
   (사용자가 "1번으로" 처럼 먼저 지정하면 질문 생략하고 바로 진행)
```

## 1. 두 트랙 (성격이 다르다 — 섞지 말 것)

| | **① MARKET FLASH** | **② DEEP BRIEF** |
|---|---|---|
| 키커 | `MARKET FLASH` | `RESOURCE BRIEF` 등 주제별 |
| 길이 | 28–35초 | 45–55초 |
| 비트 | 7–9 · 간격 0.30s | 9–12 · 간격 0.42s |
| 카드 | 3–5장 | 5–7장 |
| 분기점 | 1개 | 2개 |
| 영상 톤 | 실사 다큐 | 심볼릭·판타지·미니어처 |
| 쓸 때 | 오늘/어제 사건 | 구조적 주제 |

## 2. 소재 선정 — 감이 아니라 깔때기

`references/topic-selection.md` 전문 필독. 요약:

- **소싱 5레인**: ①시장 이상치 스캔(자동) ②캘린더 ③헤드라인 ④우리 파이프라인 ⑤구조 테마 뱅크
- **하드게이트 5개** (하나라도 실패 = 폐기): **청중 욕구(한 줄 질문 테스트)** · 계산 가능성(표본 30+) · 통념 존재 · 시청자 이해관계 · 검증 가능
- **점수표 100점 · 70점 이상만 제작**: 청중욕구 25 / 반전강도 25 / 시의성 15 / 규모·친숙도 12 / 시각화 12 / 자원 독점성 6 / 신선도 5
- **4축 로테이션**: 지수·매크로 → 자원·에너지 → AI·기술수급 → 시장구조. 같은 축 연속 2회 금지
- **즉시 탈락**: 소형주 추천처럼 보임 · 정치 논쟁 · 검증 불가 루머 · 표본 30 미만 · 7일 내 동일 각도

## 3. 팩트 검증 (예외 없음)

화면에 나갈 **모든 숫자**는 게시 당일 1차 출처로 실검증. 못 하면 그 숫자는 뺀다.
시세·성과는 **Polygon 직접 조회**, 추정치는 `analysts estimate` 귀속 표기.
검증표(수치·출처·조회일)를 보고에 첨부한다.

## 4. 인사이트 엔진 — 이 스킬의 핵심

`references/insight-engine.md` 필독. 뉴스에 **우리만 할 수 있는 계산**을 붙인다.

- **베이스레이트**(1순위): `scripts/baserate.js` — "이런 일이 N번 있었고 실제로는 X%였다"
- **우리 자원**: Polygon·XS 스코어·옵션플로우·다크풀·13F
- **교차 도메인** / **정량 메커니즘** / **반증 조건**

**자기검증**: 이 영상의 주장 한 문장을 말할 수 있는가? 그게 통념과 다른가? 내가 계산했는가?
셋 중 하나라도 아니오면 그건 요약 영상이다 — 소재를 바꾼다.

## 5. 대본 구조

```
① 훅 1문장 (첫 프레임 = 썸네일)     "The rally just blinked."
② 사실 즉납 (숫자 2–3개)
③ 뻔한 해석 제시                    "패닉이 말하는 것"
④ ⭐ 우리 조사 공개                  "We ran every X since 2021. 51 of them."
⑤ ⭐ 반전 결론                       "The scare was never the trade. The rotation was."
⑥ 분기점 (날짜·시각)
⑦ 정리 = 볼 것 1–3개
```

문장 평균 12단어 이하, 숫자는 말로 풀어서(`fourteen thousand`), 자막은 나레이션 **전문**.

## 8. 조립

1. `scripts/gen-vo.js` — ElevenLabs `Adam (SIGNUM narration)` + 워드 타임스탬프
2. 비트 = VO + 간격(트랙별), **아웃트로 = 나레이션 종료 + 2초** (쇼츠 즉시 루프)
3. 샷 컷팅(비트당 1–3컷, zoom 변형) + 룩별 컬러그레이드
4. 오버레이 순서: 커버(0~1.45초) → 마스트헤드 → 카드 → 카라오케 자막 → 브랜드 락업
5. **레이어 순서 규칙**: 카드/자막은 ASS(합성 단계). 그 위에 얹을 이미지(티커 로고 등)는
   **반드시 합성 이후 오버레이** + `-loop 1 -t <총길이>`로 스트림화
   (반대로 하면 카드가 로고를 덮어 흐려지고, 정지 이미지는 중간에 사라진다 — 둘 다 실제 발생)
6. **화면 문자는 ASCII 안전 문자만** (`·` 는 검증된 예외. `−` `≠` 등 유니코드 기호 금지 — 깨짐 사고)
7. 브랜드 플레이트에 면책 상시: `NOT INVESTMENT ADVICE`

`scripts/build-newsflash.js` / `scripts/build-brief.js` 를 복제해 내용만 교체한다.
