# 모델 정책 (2026-09-18 실측 기반 · 대표 지시: Opus 주력)

| 작업 | 수단 | 근거 |
|---|---|---|
| 집계·게이트·원장·검사·측정 | **스크립트(모델 0)** | 0 토큰·결정적. `mkt-plan.js`·`audit-*`·`mkt-clicks.js`·`hud/collect.js` |
| 사이클 운영·판단·수정·배포 검증·보고 | **세션 모델 = Opus 5** | 같은 작업 실측: 정확 3/3·10.1초(최단)·Fable 의 절반 비용 |
| 코드 읽기·추출·의존성(병렬) | `reader`(sonnet) | 3/3 정확, 본 세션 컨텍스트 보호 |

**위임 규칙**: 도구 호출 1~3회짜리 짧은 일은 위임하지 않는다(스폰 고정비 5.3~7.2만 토큰 실측).
큰 출력물을 만드는 일은 반드시 위임한다(본 세션 컨텍스트를 지킨다).
여러 모델을 동시에 돌릴 때는 `Workflow` 로 단계마다 `model`·`effort` 를 명시한다.
