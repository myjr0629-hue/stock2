# 토큰 위생 — 비용은 «컨텍스트 크기 × 턴 수»다 (실측: 전사 534MB 중 도구 결과 202MB)

1. 도구 출력은 파일로 쓰고 `tail`·`grep` 으로 «필요한 줄만» 본다. 큰 파일 통째 읽기 금지.
2. 독립적인 작업은 한 턴에 묶어 호출한다(턴 수가 비용이다).
3. 반복 조작 스크립트는 `/tmp` 에 새로 쓰지 말고 `scripts/ego/` 의 검증본을 재사용한다.
4. 사이클 끝에 관제 콘솔에서 «턴·도구 호출·모델별 토큰» 을 확인하고 이상하면 원인을 적는다.
5. 서브에이전트에는 «압축 요약만» 돌려받는다(전문 반환 금지).
