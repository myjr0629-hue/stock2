# 최초 설정 조회 지연·유실 관문 수리

## 결과 요약

기준 브랜치 `feat/gift-share-step3`, 시작 커밋 `5748514ca`. 시작 시 미커밋 변경 없음. 기존 지시·수리 문서와 이번 관문 전문을 읽었다.

원인은 두 경로의 결합이다. `useGiftShare()`가 설정 캐시의 공용 코드로 링크·선물 문구를 먼저 만들고, `payload()`는 최초 상태 `enabled=false`를 확정된 꺼짐으로 취급해 그 객체를 그대로 반환했다. 설정 응답 전·유실 뒤에는 서버 예약 요청이 없어도 이 링크가 외부로 나갈 수 있었다.

최초 미조회·조회 중·실패는 `enabled=null`로 구분한다. 재조회 시작에도 미확정 상태로 바꾼다. `payload()`의 꺼짐 조기 반환을 제거해 모든 발신 호출이 `issueToken()` 하나를 통과한다. 이 판정은 기존 서버 예약 성공 기록·플랫폼·기기·기한·장부 표식을 검사한다. 예약 응답이 성공한 토큰만 URL에 넣는다.

기존 공용 코드 링크 생성 함수와 발신 호출을 제거했다. 선물 입구는 예약 성공 전에는 기존 일반 안내를 사용한다. 종목·랭킹·추천 공유는 선물을 발급할 수 없으면 원래 페이로드 객체를 보존한다. 화면 라벨·JSX·CSS·문구 상수·플래그 값은 변경하지 않았다. 외부 공유에서는 최초 조회 전·지연·유실·꺼짐의 선물 전용 입구가 일반 안내로 바뀐다.

커밋·push·병합·배포·운영 데이터 쓰기·브라우저 접근을 하지 않았다. 환경 파일과 실제 코드 파일을 읽지 않았다.

공유 함수의 운영 인스턴스는 `giftPreparation` 하나이며 `usePreparedGift()`가 세 호출자에 전달한다.

- `ShareButton`: 종목·랭킹. 미예약 시 원래 종목 설명·주소를 보존한다. WIM 등 기존 비활성 경로는 유지한다.
- `useInviteShare`: 오늘 볼 것·관심종목 AI 한 줄·실적. 미예약 시 기존 설명·추천 주소·ref를 보존한다.
- `useGiftShare`: 설정·`GiftDashButton`·`GiftAnnounceSheet`. 설정 캐시가 있어도 미예약이면 일반 안내를 보낸다.

제거한 링크 함수의 운영 호출자는 `useGiftShare()` 하나였고, 시험 호출자는 `gift.test.ts`였다. 수신자 쪽 `withGift()`·랜딩·QR은 받은 토큰을 전달하며 새 토큰을 발급하지 않는다. 서버·예약 API·Lua·공유 전송기는 변경하지 않았다.

## 돌린 시험과 결과

무거운 명령은 모두 `/usr/bin/lockf -k /tmp/signum-heavy.lock`으로 직렬 실행했다. 기존 오프라인 실행기가 환경 파일 읽기·외부 통신을 차단한다.

- 수정 전 추가 관문 4개가 모두 실패해 공용 코드 링크 우회를 재현했다.
- 최종 신규 관문 5개 통과. 한·영·일 × iOS·Android·웹 × 설정·대시보드·안내창 × 설정 지연/유실의 54조합을 검사했다. 조회 시작 전 클릭, 조회 대기, 유실 뒤 클릭, 늦게 도착한 설정 뒤 예약 응답 전 클릭은 일반 공유이며 성공 응답 뒤에만 토큰 링크다.
- 설정 꺼짐·설정 불명·예약 실패/불명/유실, 기존 예약을 가진 문서의 재조회 지연/유실도 검사했다.
- 동일 기기 9탭 동시 준비에서 예약 응답 전 선물 0, 성공 응답을 받은 1탭만 선물 링크를 발급했다. 기존 서버 예약 통합 8개도 통과했다.
- 소스 grep 검사: 신규 발신 토큰 URL 생성은 `client.ts` 한 곳이며 단일 판정과 실패 반환 뒤에 있다. 공용 코드 생성 함수 참조는 0이다. 수신 토큰 전달용 생성 3곳과 `withGift()` 호출자 목록도 고정해 새 생성 지점이 추가되면 실패한다. 발신 호출자 3곳과 예약 성공 뒤 확인 기록 저장도 검사한다.
- 관련 20개 시험 파일 전부 통과: 선물 9파일과 초대·랜딩·Android 인앱·쿠폰·iOS 인앱·구독·데스크톱 전달·스마트 배너·스마트 링크·링크 미리보기 11파일. 클라이언트 15개, 자정·장부 관문 22개, 예약 통합 8개, 기존 선물 22개 통과. Lua 모의·대조군 15개 통과, 실제 Redis 1묶음은 로컬 실행 파일 부재로 건너뜀.
