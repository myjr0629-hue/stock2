# SignumHQ Replicate & Flux Visual Strategy Audit

This document defines the strict usage guidelines for AI-generated assets (Replicate, Flux) within the SignumHQ Shorts Engine.

## 1. The Core Rule
**AI is for Atmosphere, NOT for Data.**
Never use AI generation for elements that require exact precision, readability, or brand authority.

## 2. Permitted Use Cases (Atmosphere & Metaphor)
Replicate/Flux models are **ONLY** permitted for:
- **Hidden Wall Atmosphere**: Dark, cinematic environments that suggest hidden structures or deep market mechanics.
- **Pressure Compression Fields**: Abstract visual metaphors of tension, glowing energy, or sparks behind the procedural UI.
- **Structure Layer Reveal Environments**: Background plates used when transitioning from the "Normal Chart" to the "SignumHQ Layer".
- **Background Metaphor**: Any non-intrusive backdrop that increases hook lock-in without distracting from the data.

## 3. Forbidden Use Cases
Do **NOT** use Replicate/Flux for:
- SPY price or any other numeric data.
- 1.3% or any gap/distance metrics.
- Call Wall, Put Floor, Gamma Flip labels.
- SignumHQ Logo or wordmark.
- Real dashboards or fake UI interfaces.
- Fake text or random numbers.
- People silhouettes (distracts from the data-thriller aesthetic).

## 4. Model Policy
- **Prefer Flux 2.0** if it provides better or equal quality to Flux 1.1 at a comparable or cheaper cost.
- **Do not default to Flux 1.1** without comparing speed and clarity.
- **Reject Muddy Output**: If the generated asset looks compressed, blurry, or "muddy," reject it. The thriller aesthetic requires crispness.
- **Negative Space**: All generated backgrounds must have clean negative space (e.g., top/center) to allow crisp procedural SVG text to overlay without visual collision.

## 5. Replicate Asset Quality Gate
An AI-generated asset only passes if:
- [ ] It improves first-frame viewer lock-in.
- [ ] It has clean negative space for text overlays.
- [ ] It does not fight or visually collide with procedural text.
- [ ] It does not become muddy after YouTube/TikTok mobile compression.
- [ ] It contains NO people.
- [ ] It contains NO fake text, charts, or numbers.
