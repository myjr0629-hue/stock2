# 실적 검증 영수증 MVP

## 결과 요약

- 독립 공개 경로: `/en/receipts/earnings`·`/ko/receipts/earnings`·`/ja/receipts/earnings`.
- 기본 언어는 기존 라우팅의 en, 기본 주는 직전 완료 ET 달력 주. `?week=YYYY-MM-DD`는 실제 월요일만 허용한다. 최근 18주와 직접 요청한 유효한 주를 선택할 수 있다.
- 기존 확정 일정 전체를 대상으로 저장 기록을 읽는다. 결측·시각 미공지는 행을 제거하지 않고 이유를 표시한다. 일정 자체가 등록되지 않은 주는 빈 표 대신 이유를 표시한다.
- 종목별 발표 날짜·시각(알려진 경우만), 예상폭·세션·만기·capturedAt, 실제 반응의 두 종가·거래일·계산 시각·대조 상태를 공개한다. 각 행에 기존 종목 상세 링크가 있다.
- 발표 전 기록과 사후 보강·시점 확인 불가를 구분한다. 요약의 범위 안팎 개수에는 완전한 사전 기록만 포함한다. 사후 보강 행의 안팎은 참고 비교로 명시한다.
- 기존 설치 안내를 페이지 하단에서 재사용한다. 스마트링크는 `/app?from=receipts&l=<언어>`. 기존 공유 비콘은 영수증 방문에 전송하지 않는다.
- 주별 메타데이터·canonical·3언어 대체 링크·기본 en·OG 카드와 사이트맵 허브 3개를 추가했다. 기존 robots의 `/` 허용 규칙으로 접근 가능하며 robots 파일 수정은 없다.

## 원인과 처리 기준

기존 성적표는 완전한 예상·실제 쌍만 반환하므로 누락된 종목과 실제 기준 종가를 공개하는 화면에는 정보가 부족하다. 또한 예상 세션이 발표 이전인 것과 저장 시각이 발표 이전인 것은 별개다. 기존 API를 확장하거나 의미를 바꾸지 않고, 같은 확정 목록·실적 기록 키·공유 순수 규칙을 읽는 영수증 전용 서비스를 추가했다.

읽기 경로는 기존 `earnings:actuals:v1` 키에 대한 MGET뿐이다. 기존 주간 서비스는 갱신·보강 경로를 포함하므로 호출하지 않는다. 기존 actuals 서비스의 쓰기·크론·벤더 함수도 호출하지 않는다. 페이지 열람 통계의 운영 쓰기도 추가하지 않았다.

- 출처가 `eod-chain`이면 관측 시각과 무관하게 사후 보강이다.
- 실제 발표시각이 알려지면 그 이전 저장만 사전 기록이다. 발표시각 이후 저장은 사후 보강이다. 통화시각은 사용하지 않는다.
- 정확한 시각이 없으면 장전은 발표일 00:00 ET 이전, 장후는 해당일 정규장 마감 이전만 사전으로 인정한다. 같은 날 그 뒤의 값은 확인 불가, 다음 ET 날짜 이후 저장은 사후 보강이다. 서머타임·조기폐장을 기존 거래일 규칙으로 처리한다.
- 예상 세션·만기·원본 출처·시각과 실제 종가·기간·계산시각·변동률 일치를 검증한다. 예상만 없더라도 유효한 실제 반응은 남긴다.
- 실제 변동률은 저장 정밀도인 소수 4자리까지 표시해 `3.0001% > 3.0%`의 경계가 반올림으로 감춰지지 않도록 했다.

## 공유 코드 영향

`ShareLanding`에 기본값이 `share`인 선택 인자 `from`을 추가했다. 기존 4개 호출자는 수정하지 않았다.

| 기존 호출자 | 유지한 동작 | 검증 |
|---|---|---|
| `flow/[ticker]/page.tsx` | 종목 공유 카드·문구·링크·비콘 | 3언어 HTML을 HEAD 구현과 바이트 비교 |
| `rankings/[id]/page.tsx` | 랭킹 공유 카드·문구·링크·비콘 | 동일 |
| `undercurrent/layout.tsx` | UC 공유 띠·문구·링크·비콘 | 동일 |
| `wim/layout.tsx` | WIM 공유 띠·문구·링크·비콘 | 동일 |

`buildSitemap` 호출자는 `app/sitemap.ts`와 `app/sitemap-ko.xml/route.ts` 두 곳이다. 전체·한국어 사이트맵에 영수증 허브만 추가한다. 기존 URL은 유지하며 새 허브에는 근거 없는 lastModified를 넣지 않는다. 전체 URL 수 시험값은 +3, 한국어는 +1로 수정했다.

기존 설치 안내 4개 호출 형태 × 3언어의 렌더 HTML이 HEAD 구현과 바이트 단위로 같았다. 기존 주간 웹·앱 실적 화면, 주간/actuals/scorecard 서비스, scorecard 규칙/API, robots 소스도 HEAD와 바이트 단위로 같았다. 기존 API 시험에서 응답 키·상태 코드·캐시 기간·기존 생성기 연결을 검증했다.

OG는 en·ko·ja 경로 모두 실제 PNG(1200×630) 본문과 200 응답을 확인했다. 이때 외부 글꼴 요청을 차단해 영문 대체 경로를 검증했다. 데이터 있는 주와 결측 주의 영문 PNG도 시각 확인했다. 운영 쓰기와 공급사 호출은 0회다.

전체 타입 검사와 최종 회귀 묶음은 각각 전역 잠금을 걸어 1회 실행했다. 다른 작업의 잠금이 해제될 때까지 대기했으며 잠금 우회·다른 작업 종료는 하지 않았다.

규칙 시험은 날짜 경계·결측 주·사후 보강·확인 불가·정확한 발표시각·통화시각 배제·조기폐장·0%·등호·오염 기록을 검사한다. 렌더 시험은 3언어·가격과 시점·주 선택·종목 링크·설치 경로·메타데이터·기존 소스와의 비교·사이트맵·robots·실제 PNG 응답을 검사한다.

## 남은 위험과 운영 측정

- 확정 일정은 현재 저장소의 큐레이션 목록이며 미국 시장 전체나 영구 고정된 주별 모집단이 아니다. 수동 추가·정정이 가능하다는 한계를 페이지에 공개했다.
- 저장 기록은 120일 보관이며 수정 이력 전체를 제공하지 않는다. 영구 불변 장부로 표현하지 않는다.
- 기존 MGET은 전체 장애도 null 배열로 반환할 수 있다. 이런 경우 미보관·보관 만료·저장소 응답 불가를 구분할 수 없다고 표시한다. 예외가 전파되면 읽기 실패로 표시한다.
- 정확한 발표시각이 없는 행은 사전 인정 기준이 보수적이다. 실제로 발표 전 저장된 행도 확인 불가로 남을 수 있다.
- 예상은 옵션 만기까지, 실제는 한 정규장 반응이다. 기간 차이·가격 정정·독립 공급사 미대조를 페이지에 공개한다. 안팎 개수를 예측 정확도나 투자 성과로 광고하지 않는다.
- 한·일 OG 글꼴을 외부에서 받지 못하면 내장 영문 글꼴 카드로 대체한다. 3언어 본문과 메타데이터는 유지된다. 외부 글꼴 정상 응답·실제 브라우저 화면·운영 데이터는 이번 작업에서 검증하지 않는다.
- `from=receipts`는 기존 설치 이동 경로의 귀속 태그다. 스토어 이동 클릭은 신규 설치가 아니다. 페이지 사람 방문·공유 성공·수신 열람·스토어 설치·첫 가치 경험·D1을 새로 측정했다고 주장하지 않는다. 신규 설치와 D1 확인은 운영 세션의 별도 보고가 필요하다.
- 잠정 실험 목표(14일 설치 30건·D1 30%·공유/복사 30회)는 승인 문서의 가설이며 실측 결과가 아니다. D1 100명 미만은 참고치로 취급한다.
- 커밋·push·main 병합·배포·운영 쓰기는 수행하지 않는다. 환경 파일은 읽지 않는다.
